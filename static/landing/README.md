# 首页参考素材

来源：用户指定的 [松伴首页](https://songban-hackathon-preview-20261030.social-cat-4573.chatgpt.site/#/login)，于 2026-10-31 读取其公开页面与静态素材，按用户“接入项目”的要求用于本项目首页。

- `songban-cn.png`、`songban-en.png`：原页面品牌标识。
- `pine-mascot.png`：原页面小松树；首页以它的透明轮廓作遮罩，眼睛使用 CSS，支持轻量指针跟随和减少动态效果设置。
- `projects/*-thumb.webp`：六张概念卡片缩略图（640×400）。
- `projects/*-cover.webp`：对应概念预览图（1600×1000），点击卡片时加载。

卡片名称、类型、简介沿用参考页：问号工坊、晚饭有谱、方寸小屋、小摊计划、叶脉档案、云上邮局。这些是概念设计，页面预览明确标注，不作为真实参赛作品或平台已实现功能。

素材随应用同源提供；首页不依赖远端图片、远端脚本或 iframe。不导入参考站的本地演示账号、任务存储或业务状态。来源记录不构成额外的第三方版权或再分发许可声明。
