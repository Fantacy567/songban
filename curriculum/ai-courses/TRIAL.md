## 首课：我的角色介绍卡

入口为 ai-tools 的老师对话。先确认页面清楚标记模拟/真实模式；静态开场始终是事先编写的示范。模拟体验可用于观察操作，不能用于评价真实模型的理解与修改质量。真实调用由主会话在既有授权预算内执行，本材料不增加调用授权。

1. **先看一次示范。** 小芽展示“请给月亮蜗牛写三行角色介绍卡”的要求及名字、爱好、本领三行固定示例。观察孩子能否找到输入框，不先问 AI 定义，也不要求先做排序。
2. **提出要求。** 可说“请给会潜水的小狐狸写三行角色介绍卡”，也可以换自己喜欢的角色。只想看示范或没想法时，先提供可修改草稿，避免连续提问。观察提示建议是否能帮助起步。
3. **查看回复。** 让孩子看看出现了什么，是否符合刚才要求。示例卡不是自动保存的个人作品；如果任务失败，观察输入是否保留、提示是否能理解。
4. **追问修改。** 可说“把本领改成给海星讲笑话，保留名字和爱好”。观察是否能表达想改什么、能否发现多改/没改；如果原文已经满意，也允许直接保存，不为收集数据强迫改动。
5. **检查保存。** 由孩子在成果区读一遍、修改文字并点击保存；以版本与回读结果确认持久化。观察能否分清回复出现与保存成功。不得替孩子点击记录确认或宣称已经学会。
6. **兴趣发散。** 邀请“这个角色可以去哪里，遇见谁，或者做一个什么游戏？”允许换方向、继续想或休息。想象课可以接着混合几个火花；无需通过考试才能前往。

可复用的固定角色卡（教学素材，非实时输出、非孩子成果）：

```text
名字：月亮蜗牛
喜欢的事：收集晚风里的故事
特别本领：把故事变成发光的路标
```

## 七课试用入口

- **工具入门 / 小芽**：用上述角色卡场景。重点观察能否发出自己的要求、看到修改、亲自检查并回读保存版本。
- **想象 / 云朵**：“我喜欢动物，但不想做工具，只想编一个奇怪故事。”观察老师是否先发散、允许混合和不落地，是否避免把兴趣写成人格结论。
- **首个项目 / 阿桥**：“让我的小狐狸点一下按钮会说一句台词。”在已有工作台试运行并只改一句；若环境不可用，保留“待运行”记录。观察文本代码是否被误当成成功预览。
- **插件 / 齿轮**：读书卡重点高亮开→关。观察孩子描述的实际变化；问“浏览器真的装好插件了吗”只作开放讨论，不设答对门槛。
- **模型 / 星镜**：使用老师开场共同提醒任务的固定 A/B 示例，允许两份都改或换任务。观察是否混淆示例比较与真实多模型实验；可用“这些回答从哪里来”作自然追问。
- **API / 小邮**：在本站实验发送虚构昵称“小鲸”，观察实际 request/response，再自愿尝试空白输入。聊天请求草稿不能算已发请求，网络失败不可记录为成功。
- **作品增强 / 织光**：让角色卡能展示一句故事开头，用正常输出与空输出固定样例走两条路径。观察是否给出可手写回退，是否清楚说明文字/配图的真实配置未验事项。

## 教师审阅工作单

由实际审阅者自行填写日期与结论，当前空白表示未审。核对术语是否准确、首课阅读负担是否合适、示范是否足够、建议是否真正可选择、失败提示是否可懂、幻想是否被不当评分。针对发现的问题，记录具体课程、原句、建议改写和理由，不以“整体不错”代替证据。
