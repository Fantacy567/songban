# 松伴 · 通用团队插件 1.0

一个服务、多种工具；不读取工具内部私有聊天库。需要Python 3.10以上。

## 安装

1. 网页登录松伴，创建/加入队伍，在“连接个人工具”生成本人连接凭证并下载插件。
2. 解压到自己的电脑。支持MCP的工具：在工具的MCP设置中添加Python命令，参数为 bridge.py 的绝对路径和 mcp；配置 SONGBAN_URL、SONGBAN_TEAM_ID、SONGBAN_TOKEN。参考mcp.example.json。不要将填过凭证的配置提交Git。
3. 让个人工具读取 skills/songban-team/SKILL.md；有技能安装入口的工具可将该技能文件夹复制到它的项目技能目录。不同工具的安装入口不同，不能通用覆盖其配置。
4. 先问“读取松伴中我当前的任务”，再说“同步一条本项目重要进展”。工具实际返回报告ID后才算同步成功。

## 不能使用MCP的工具

在项目目录运行 `python3 /绝对路径/bridge.py connect`，按提示填地址、队伍ID、隐藏输入的连接凭证。配置写到当前项目 `.songban/connection.json`，目录内自带忽略规则。

运行 `python3 /绝对路径/bridge.py watch`。让个人智能体按技能说明更新项目里的 songban-update.json（参考update.example.json）。监听器默认每2秒检测变化并上传，同时每5秒取回共同方向和本人任务，写入 `.songban/team-state.json`，供个人智能体开始下一轮工作时读取。不需要反复粘贴；停止监听后不会自动同步。

命令行：`context`读取团队方向和进展，`tasks`读取本人任务，`sync --file songban-update.json`同步一次，`flush`补传断网队列。队列按连接区分，切换团队不会错传旧队列。

## Codex自动触发（可选）

在具体版本支持的Stop Hook中运行 `python3 /绝对路径/bridge.py hook --file songban-update.json`。先按官方说明审阅并信任Hook。不需要也不应修改模型配置。它仍只同步个人工具明确写出的共享文件，不解析加密思考或整个历史。

## 支持边界

- 共用MCP/命令行能力，不代表所有工具都安装验收过。Codex和WorkBuddy及其他客户端需各自在实际版本测试。
- 实时含义是重要进展生成后自动上传；不是旁路监听所有聊天，也不是每个字符都上传。
- MCP支持工具主动调用；自动调用依赖工具遵守技能。文件监听能确定捕获已写出的共享文件，不能保证AI每次都写。
- 连接仅限本人和指定队伍，30天有效，可在网页暂停/撤销。
- 没有独立检查的证据仍标“个人自报”。不同AI观点不能保证事实正确。
- 未上传的私人聊天、模型密钥、其他项目不应共享。内置常见密钥过滤仅作补充，分享前仍应检查范围。
- 团队模型在服务器单独运行，使用服务端配置和费用，不会自动继承个人工具的订阅额度。

补传遇到旧任务版本、无效输入等确定拒绝时，该记录会移到本机 `.songban/rejected`，并输出原因；更正后用新事件ID提交，不让它堵住后面的进展。断网、暂时限流和暂停连接仍保留队列等待恢复。

## 更简单：本机网页一键安装

在松伴的“连接个人工具”页选择Codex、WorkBuddy或Cursor，填写当前工作项目目录，点“一键安装到所选工具”。系统会安装程序、生成本人连接、合并项目MCP配置、保留原配置备份，并实际取回一次团队任务检查连接。不需要手动复制密钥。

只允许本机地址（例如127.0.0.1）操作；通过远程网址访问时不能替访问者改电脑配置，继续使用通用安装方式。安装只改项目内配置，不改全局模型、provider或自动切换设置。Codex项目可能需要信任；各工具可能需要重新打开项目后才会加载连接。

“安装成功”和“桥接连接检查通过”不等于工具客户端已经启用；网页会如实提示这一点。失败会回退本次配置、撤销新凭证。原配置备份保存在项目 `.songban/install-backups`，该目录不应提交Git。
