# 松伴连接器 · 只记录

用户选择本插件的回合，只使用 songban_sync_selected_turn 上传；无需先读取团队上下文，也不调用团队统筹工具。

参数：selected=true；event_id为本轮稳定标识；user_message保留当前用户发言原文；assistant_summary仅提取回复中的关键结论，例如回复确认成功时只写「已上传」；model_name填写宿主提供或已核实的当前实际模型名称。不知道就留空，不按用户举例猜测模型，不以UI模型名替代实际provider。注册姓名由服务器从当前账号取得，不自行编写。

不上传思考过程、额外分析、完整智能体长回复、其他会话或密钥。用户原话仅对密钥密码做脱敏，不再改写为工作分析。上传不会自动触发团队分析。

只在工具返回synced=true且包含note_id后报告「已上传」。失败时明确说未上传，不能把预期成功当事实。用户未选择或未授权本对话持续记录时不上传；用户暂停则停止。没有宿主消息hook，不保证绕过agent的后台捕获。
