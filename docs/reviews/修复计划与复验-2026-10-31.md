## 闭环缺口的处理边界

- **GAP-01 短信**：保留配置检测与准确失败提示；真实送达需要服务商凭据和授权测试号码。不能从其他目录复制私人密钥或虚构配置成功。
- **GAP-02 单人验收**：保留禁止本人冒充同伴验收的规则，提供明确邀请评审/队友的出口与提示；单人完成、外部评审属于后续验收策略，不能用直接放开自验收代替。
- **GAP-03 模型不可用**：明确保存现有记录、补充信息和配置/重试的出口；完整手工任务计划需要独立的编辑、依赖、版本及确认交互，作为下一阶段产品能力。
- **GAP-04 活动关联**：活动目录仍为样例，明确进入现有团队或新建团队的动作；真实活动绑定、规则快照和报名状态需要独立数据契约。
- **GAP-05 正式回执**：交付页面及导出继续准确标明未获官方确认。正式回执记录和核验是后续产品能力，不将团队验收改写成主办方收件。
- **GAP-06 个人复盘/学习产品**：当前复盘仍保存为团队可见进展。个人档案、家长/学习者身份、课程、实验额度、家长报告及权益按现行规划实施，不能通过本轮修缺陷宣称已完成。

本轮目标是关闭已复现的软件缺陷、恢复可运行的测试链，并改善已有流程的阻塞提示；新增业务域和外部服务验证另列明确的验收条件。

### 安装与复验命令

使用 Python 3.12。运行依赖安装 `requirements.lock.txt`；测试与 QA 服务安装 `requirements-test.txt`。开发者安装 Playwright 并准备浏览器；本机可用 `NODE_PATH` 指向现有包，并以 `PLAYWRIGHT_EXECUTABLE_PATH` 指定 Edge。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-test.txt
$env:SONGBAN_CORE_ONLY='0'
$env:PYTHONIOENCODING='utf-8'
.\.venv\Scripts\python.exe -m unittest discover -s tests -v

# 自动创建独立测试服务和 HOME，不使用正常业务数据库：
node scripts/core_e2e.cjs
node scripts/core_install_e2e.cjs
node scripts/core_native_plugin_e2e.cjs
node scripts/core_selected_turn_e2e.cjs

# 统一前台与资料测试：单独终端启动默认 8894 的隔离服务
.\.venv\Scripts\python.exe scripts/qa_full_audit_server.py
# 另一终端：
$env:SONGBAN_QA_URL='http://127.0.0.1:8894'
node scripts/e2e_unified.cjs
node scripts/e2e_materials.cjs
node scripts/audit_closure_browser.cjs
.\.venv\Scripts\python.exe scripts/audit_core_closure.py
.\.venv\Scripts\python.exe scripts/audit_mcp_loop.py
```

审计探针的修复后结果默认写入 `.browser-cache/materials/fixes-20261031/`，可用 `SONGBAN_AUDIT_OUTPUT` 改目录；不会覆盖原审计证据。
