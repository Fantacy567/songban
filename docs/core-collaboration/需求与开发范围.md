# 松伴 · 个人智能体与团队总智能体 · 首版

本轮唯一主线：成员在自己的工具工作 → 插件同步重要进展和必要对话摘录 → 团队保存来源、观点、受阻情况 → 总智能体比较并提出安排 → 队长确认 → 成员工具读取统一方向与本人任务 → 新进展再次同步。

## 必须实现

- 沿用现有手机号登录和团队身份；支持创建/加入核心团队，现有成员可直接使用已有队伍。
- 同一后端提供通用 MCP 工具及 Python 命令行；MCP 客户端无需另写一套业务。不能宣称支持所有工具的内部会话读取。
- 可携带重要对话摘录的结构化同步：当前任务、进展、证据、问题、观点和观点所针对的问题。来源和检查状态分开；不把AI自报标成验证成功。
- 连接凭证绑定本人和单个团队，只保存摘要值；可暂停、撤销、有效期；不能更改方向或确认计划。
- 自动路径：个人技能指导工具更新本地进展文件，通用监听器发现文件变化后上传；未正确写文件时显示未同步，不虚构成功。支持手动同步作为补救。
- 团队方向、比赛要求、评分依据、成员优势/意愿/可用时间、当前正式任务和最新进展都进入统筹输入。
- 比较不同成员对同一问题的观点，保留冲突和待核实事项。多AI不等于事实正确，不做多数即正确的投票。
- 总智能体输出来源引用、取舍理由、待核实事项和任务草案；严格校验引用、成员和依赖。模型不可用时保留同步，不冒充模型生成。
- 保存草案时检查输入版本；确认时再次检查。队长确认才发布新方向和任务，旧版本留档；成员可领取本人任务，完成进度来自后续报告。
- 同步自动刷新工作台；模型自动统筹可开关，重要更新后去重、短暂合并再处理，失败可见，不自动无限重试。
- 非主线导航和旧页面默认封锁；保留旧代码与资料，不删除用户数据。

## 界面

四个页面：团队现场、统一方向、连接个人工具、成员与设置。旁列锁定的找比赛、素材库、复盘培训、办赛入口。

## 验收

两个独立成员连接通用插件 → 真实请求同步进展及互相矛盾的观点 → 团队看到来源与冲突 → 模型协议测试生成带引用的草案 → 队长确认 → 两个工具读回对应任务及相同方向 → 更新状态并同步 → 撤销凭证后拒绝访问。额外覆盖跨队伍越权、重复上传、过期草案、恶意模型输出、断网补传和重启保留。

真实付费模型调用和协议测试分别记录。真实客户端未安装验收时不声称已经通过。
