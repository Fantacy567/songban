# 核心协作 · 本轮验收（2026-10-28）

## 已交付的使用链路

1. 现有手机号登录，创建或加入团队。
2. 队长填写共同方向、赛规、评分依据、暂不做的事；成员填写优势、意愿和可用时间。
3. 本人生成绑定单队的连接凭证，下载通用插件。
4. 个人工具通过MCP提交重要进展和必要摘录；或将授权内容写入共享文件，由监听器自动上传。
5. 团队空间每5秒刷新，保留来源、个人自报标记及不同观点。
6. 团队模型按已知资料生成带来源、取舍理由、待核实问题和负责人/依赖/检查方法的草案。
7. 队长确认后发布新版本；其他成员和插件不能越权发布。
8. MCP读取本人新任务；文件监听器也会每5秒把共同方向和本人任务写回本机文件。
9. 后续进展按任务编号和计划版本更新；撤销凭证后下一次访问被拒绝。

## 不能扩大宣传的范围

通用的是MCP/命令行/共享文件能力，不是绕过各工具限制自动读取一切。尚未在实际Codex、WorkBuddy及其他客户端逐款安装验收。个人工具需要真实调用MCP或写出共享文件，且读取取回的方向；技能提示不能保证每个工具每轮都执行。

最近80条进展进入统筹，当前任务状态单独读取持久历史，不因移出最近窗口丢失。资料过长会拒绝，不假装已经完整阅读。证据目前由成员提供，没有独立运行队员代码；多个AI可能同时犯错，来源引用校验不等于事实校验。

新任务会取代当前正式任务，旧确认版本和进展保留。模型失败不会清空记录或悄悄改用规则冒充总智能体。
