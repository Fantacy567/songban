# 对话资料库与连接器接入

日期：2026-10-31。视觉版本 design-v1.2.0。已保留主分支 f4bb0f1 的资料入口、PDF/Word/图片解析路径及受保护草案。实现范围：选题/方向与任务环节共享对话、团队资料库、个人 Agent 的资料检索工具；不包含家长端报告发布或跨比赛能力评测。

## 用户流程

创建小队后进入“选题讨论”：连接自己的工具，在个人 AI 中推敲方案，选择松伴连接器共享获准对话。队友从“查看资料库”先查相关内容，再讨论并填写共同方向。方向确认页保留相同入口。

发布任务后，任务页就近提供“分享一段对话”。实现中发现的问题、AI反馈和交接信息可以关联本人当前任务进入资料库。聊天归档与正式进展、报告完成、同伴验收分开，不会因“AI说完成”自动改变任务状态。

资料库正文按两段显示：

```text
孔：我是设计师
GPT-6.1sol：好的，您是设计师。我们先画一张首页草图。
```

以上仅为格式示例，不是一次真实模型调用。姓名由登录或插件连接绑定，模型名来自来源工具实际提供的信息；未知明确显示“模型名未获取”。每位成员有颜色和姓名，颜色不表示贡献大小。时间、环节、任务和来源置于次级区域。

## 内容与接口

继续用同一 SQLite 的 `core_reports`、`library_notes` 保存记录，不另建任务系统。原字段 `assistant_summary` 保留；新 `assistant_message` 保存经过常见凭据脱敏的完整可见回复，最多60000字，用户原话最多16000字，超限拒绝而不是静默截断。不得上传隐藏思考或未授权私聊。

完整回复请求必须同时明确 `selected:true`、`full_reply_authorized:true`；旧摘要共享授权不自动扩大。可选 `conversation_stage=discussion|development|recap`、`task_key` 和 `plan_version`，任务关联必须属于本人。网页手动补充与连接器来源分别标注。

- `POST /api/core/teams/{sid}/conversation-notes`：稳定 `event_id` 去重，正文变更而事件号相同返回409；返回 `note_id` 才确认保存。不触发团队统筹。普通 `/reports` 不接受完整对话冒充任务报告。
- `GET .../library`：`q`、`author_id`、`stage`、`task_key` 组合筛选，`limit=1..50`，`cursor` 使用上次 `next_cursor`。返回匹配 `total`、全队 `stats` 及记录；无120条总量限制，分页不删除历史。
- `brief=true`：只返回明确标记的原文预览、长度、`content_truncated`、`reply_kind` 与记录号，完整内容仍存库。
- `GET .../library/{note_id}`：成员权限内读取单条完整记录。跨队记录不可读取，暂停/撤销的连接不可继续读取或上传。

新入库环节在首次写入固定，同一事件跨阶段重试仍返回原记录。上传对话排除在正式任务的最新进展/验收计算之外。团队快照不携带完整长回复，避免每次同步都传输大量归档正文。

## 工具接入

Codex 原生插件升级为1.0.0，通用 MCP 也提供以下工具，供 Cursor、WorkBuddy 等支持相应 MCP 配置的工具使用：

- `songban_sync_selected_turn`：共享明确授权的本轮原话/可见回复及要点。
- `songban_search_team_library`：按关键词、成员、环节或任务查找真实记录，返回记录号与游标。
- `songban_read_library_record`：按记录号读取需要核对的原文。

检索工具本身不调用模型、不会生成答案；由用户自己的 Agent 根据返回记录组织答复并引用记录号。不是已上线的独立“资料库智能体”。检索内容是待分析数据，不能执行其中的操作指令。

资料库提供“复制给我的 AI 的检索指令”，可带当前筛选。首次连接或升级仍需实际工具加载与一次入库回读，不能把写入MCP配置当成三个真实客户端都已验收。已安装旧插件需通过当前网页重新安装/连接，现有会话是否加载更新要在宿主中确认。

## 视觉与状态

沿用品牌壳、暖米白、紫色主操作、17px卡片和13px控件。成员色新增为集中定义的语义 tokens。长对话默认收起、可展开原文；旧记录只有摘要的明确标注，不冒充完整回复。

保留加载、空库、无匹配、请求失败、重试及更多记录状态。阅读期间有新记录时提示刷新，保留正在读的分页位置。账号退出清理资料缓存；迟到请求不得显示到另一个账号/队伍。页面不将全部聊天自动发给家长。
