# 赛事碎片资料与关键信息提取

确认比赛 → 导入本场主办方资料 → 提取关键信息并核对 → 组队。既有队伍不回退阶段，仍可从辅助入口查看/补充资料。

每场比赛独立材料空间，复用现有网址抓取、文件读取、OCR、原件保存、来源版本及访问控制。已确认的公告自动保留；支持分批添加文字、多行网址、PNG/JPEG、PDF、DOCX、TXT。抓取和文件读取的失败、部分读取与OCR警告单独显示，不把失败说成未找到。

Agent 按关键时间、地点、赛道、奖金、办赛理念、评分、提交要求分类引用。模型只能返回来源ID、段落ID与连续原文；服务端校验后直接展示原文，不接受模型编写的金额、时间或理念说明。缺失字段显示“未找到（仅指本次已读取资料）”。不同通知的表述并列保留，不自动裁定冲突。来源自称主办方不等于独立核验。

资料在提取期间或之后变化，拒绝覆盖或标记结果过期。提取失败保留原件和上一版结果；请求号幂等，不在网络不明时自动重放。十分钟仍在运行的记录标为结果未知，允许用户明确再次提取。已核对当前版本后可组队，未知字段无需用猜测补齐。

演示版按导入正文的明确字段标签读取，明确标注虚构演示且未调用真实模型；没有预填奖金、赛道或理念。真实版使用服务端已配置模型。测试替身不会被计为真实模型成功。

验证：298项全量；新增门槛、缺失、逐字引用、TXT补充、不同地点并列、伪造引用拒绝、模型失败保留、提取中资料变化、重启持久化和账号隔离。专用浏览器脚本 scripts/browser_contest_brief.py；原完赛流程 scripts/browser_unified_flow.py。真实模型合成测试已返回时间/地点有效引用，缺少的奖金/赛道/理念保持未知。

## 演示资料预置

演示页面预填虚构补充公告、两个保留域名 demo.songban.invalid 的示例网址，以及一个由浏览器生成的 TXT 示例文件。进入页面自动将对应的虚构原文保存到当前演示会话的本场资料空间；无需准备材料或手动上传即可直接提取。输入仍可修改，也可演示“保存并读取”。

示例网址对应预置正文，不伪装成真实网络抓取；记录名称、材料性质和提示均标为虚构。再次进入不重复添加，主动撤回的示例不自动恢复。只有 window.SONGBAN_DEMO 为真才预填和导入，真实入口的空白与未知判断不变。
