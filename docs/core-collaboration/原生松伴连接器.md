# 原生松伴连接器 · 0.9.0

## 本次失败定位
2026-10-29用同一个旧技能脚本执行只读 context：普通受限执行失败；获准访问本机的同一请求成功。8886服务正常，因此已证实旧版shell上传方式受执行环境网络边界影响。截图上的“失败，本轮未同步”本身没有足够信息判断，不能一概说是后端报错。

## 改造
- 松伴本机网页 → 连接个人工具 → 默认“松伴连接器 · Codex原生插件” → 一键连接松伴。
- 插件清单、中文名称、composerIcon、MCP工具、技能打包在一起，使用官方 `codex plugin marketplace add` 和 `codex plugin add` 注册安装，并查询 installed/enabled。
- 安装源位于 ~/.codex/plugins/songban-local/catalog；私有绑定在其外的 private/connection.json（0600），不会随插件源/缓存复制。不是把密钥写入插件manifest。
- 保留其他插件、其他市场、model/model_provider及全部无关设置；只更新自己的插件配置。绑定失败回退文件、撤销新凭证。备份在插件目录backups。
- 原有同名独立技能的 SKILL.md 改名为 SKILL.md.retired，保留恢复来源，避免重名和继续走shell脚本。

## 用户操作与真实边界
在输入框加号的插件入口搜索“松伴连接器”；若当前会话未刷新，先新建对话并查看已安装插件目录。已验证注册启用不代表当前对话已加载。Computer Use禁止操作Codex自身，所以未实测原生加号菜单，不能宣称已出现。未重启Codex应用。

插件工具负责读取方向和上传获准的本轮摘要。只有拿到note_id才报告成功。可以明确授权本对话持续共享，也可以暂停；由agent遵守范围并调用工具。当前没有宿主消息hook，不承诺独立于agent的每条消息后台自动捕获，不会扫描全部私人聊天。自动统筹开关与队长确认流程保持原样。上传资料不等于已进行模型统筹。
