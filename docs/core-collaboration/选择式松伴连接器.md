# 松伴连接器 · 用户显式选择的回合

用户明确要的是：输入框加号/技能选择器中附带“松伴连接器”，这一回合的项目关键内容上传团队资料库，供团队总智能体读取；不是仅按目录连接或后台监听。

## 当前实现

- 标准技能 plugins/songban-connector，显示名“松伴连接器”，机器名songban-connector。
- agents/openai.yaml设置allow_implicit_invocation:false。技能指令要求检查当前回合显式选择，历史曾用过不等于后续授权；没有自动Hook、聊天库扫描或监听。
- 脚本context/send要求--selected；发送只接受本轮摘要、观点、必要摘录、依据等限定字段，常见凭证过滤；只有返回note_id才报告同步成功。
- POST /api/core/teams/{sid}/conversation-notes要求selected:true，原子保存报告与library_notes；重复请求去重，身份由本人连接确定。这里的selected由调用方声明，不是宿主提供的不可伪造选择凭证，仍需个人智能体遵守技能范围。
- 网页新增“团队资料库”，GET .../library读取；总智能体输入显式包括team_library及真实来源ID。开启自动统筹时新记录触发，否则下一次统筹读取。
- 本机一键安装默认安装该技能，项目MCP作为兼容方式保留。旧项目技能已调整为手动调用，避免隐式共享。

## 本机状态

技能已安装到 ~/.codex/skills/songban-connector，私有binding.json指向用户先前安装的桌面松伴连接，不复制密钥到技能正文或Git。绑定只读验证通过，当前未附带技能的真实对话没有被上传。

官方支持显式选择技能，桌面可通过技能列表/@搜索，CLI/IDE可用$或/skills。当前Computer Use禁止操作ChatGPT自身，故不能亲眼核对用户加号里的菜单项；不能把文件安装成功说成已验证菜单出现。若当前列表未刷新，用户可新建对话后搜索“松伴连接器”或显式使用$songban-connector，无需重启应用。

## 下一步使用

在当前回合选择“松伴连接器”，提出正常项目问题。个人智能体完成后同步本轮关键内容，并显示实际记录号；打开松伴“团队资料库”核对。没有附带的回合不应主动上传。技能是由智能体执行的工作流，不是宿主级强制日志系统，失败时须如实显示未同步。
