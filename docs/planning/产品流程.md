# 松伴 AI 学习平台产品流程

共同约束见[项目宪法](../../.specify/memory/constitution.md)，范围及里程碑见[整体规划](整体规划.md)。工程交付见[前端开发与交付](前端开发与交付.md)、[后端开发与交付](后端开发与交付.md)；呈现与资源交付见[美术设计与交付](美术设计与交付.md)。

新学习域行为对应的拟议接口见[前后端接口规范](前后端接口规范.md)，前缀统一为 /api/learning/v1；旧 /api/learn 示意由其替代。接口规范与宪法中的强制契约共同约束实现，不能把这份草案当作基线已有接口。

## 1. 流程的边界与角色

### 1.1 用户定位

家长不会 AI，也不知道孩子能用 AI 做什么；家长选择与付费，孩子实际学习。孩子可以完全零基础，不要求已有编程、模型账号、API Key 或插件。

旧团队协作和机构优先材料属于历史。当前流程不要求先选比赛、建队、等队长确认或安装个人工具连接器。

### 1.2 角色与权限

- 访客：查看经许可的公开介绍和明确标注的样例；首版不匿名保存学习记录或调用真实 API。
- 家长：建立本人家庭、创建学习者、允许真实调用、查看家庭报告、决定开通、退款或暂停。
- 孩子：在本人受限会话内调整自选基础、操作任务、申请提示、实验、检查、解释、保存作品；年龄段与展示名更正由家长完成。孩子不能购买、扩大预算、管理家庭或读取真实密钥。
- 教研：维护固定课程、素材、提示、测试、推荐规则与迁移任务；发布版本和处理教学复核。
- 运营／支持：核验试点开通、处理服务异常和未知运行、收集真实反馈与成本；管理操作需要实际权限与审计。
- AI：提供限定范围的解释、提问、分级提示和反馈建议；不是权限主体，不能自行收费、改目标或宣布孩子全面掌握。

首版建议一个家长管理一个学习者。家庭关系和登录身份不是平台已核验监护身份或教师资质的证明；正式运营所需核对另行明确。

### 1.3 以行为验收，不固定界面形态

以下是业务步骤，不是页面编号。设计可以改变布局、风格、导航、呈现顺序与视图拆分，前端也可以自定组件名称。

不能省略的是：当前任务能理解、角色和模式可辨认、主动作有出口、失败能恢复、数据和帮助有来源、用户不会被假成功误导。旧三栏、旧导航、历史页面与组件名称均非强制。

## 2. 全链路与数据主线

主链路：

家长了解 → 建立家庭 → 年龄与自选基础 → 短任务校准 → 推荐项目 → 学与做 → 模拟／真实实验 → 比较与修正 → 检查与平台内迁移 → 提交同版本作品 → 家长理解 → 继续、暂停或开通。

数据主线：

家庭及学习者 → 课程发布版本 → 本人尝试与输入版本 → 运行及帮助记录 → 候选作品快照 → 绑定快照的检查与解释 → 成果提交 → 家庭报告及反馈 → 权益与下一任务。

这些关系由后端验证，不能由前端传一个“已完成”覆盖全部状态。每个步骤均应保留可继续的位置与明确的未完成原因。

## 3. 了解与进入体验

### 用户动作

家长了解适合谁、这次孩子能尝试什么、交付是什么、需要什么设备、会获得何种帮助及支持。查看样例后选择注册或登录。

### 系统行为与数据

- 匿名仅提供公开信息和明确标注的样例，不创建可直接访问真实模型的匿名学习身份。
- 示例人物、作品、测试、数据及回放须标明用途；不冒充真实孩子成绩、付款或实时实验。
- 家庭数据用途和试点范围要可查；没有正式定价时不能显示虚构原价、购买人数或效果百分比。

### 出口与恢复

进入家长认证后，再建立本人学习记录。介绍内容加载失败显示读取失败，不显示假进度或假作品。家长暂不进入时可退出，不强制先提交孩子隐私。

### 验收

不熟悉 AI 的家长能说清体验内容、孩子需要做什么和帮助边界；能找到开始方式。看懂介绍不计作实际购买。

## 4. 家长认证、家庭与孩子会话

### 用户动作

家长注册或登录，建立本人家庭与孩子昵称，确认适用的数据说明，再进入孩子学习。

### 系统行为与数据

- 复用认证基础但适配家长场景，不要求填写工作技能，也不伪造旧 profile／skills 通过校验。
- 已有用户进入家庭引导时不覆盖其历史协作账号、画像或团队资料。
- 由服务端建立家庭归属、学习者及受限会话，保存同意版本和必要记录。
- 新学习会话采用 HttpOnly、Secure、SameSite=Lax 会话 Cookie；所有有副作用请求（包括匿名认证写请求）执行来源与 CSRF 校验，前端不得向 localStorage 或日志复制会话秘密及 CSRF token。具体认证、续期与错误契约按接口规范执行。
- 进入孩子模式时，服务端必须撤销当前浏览器的家长管理会话并轮换 Cookie，不能只隐藏管理按钮；多标签页旧管理请求同样失效。回家长管理必须重新认证并撤销原学习会话，前端切换身份时清缓存并丢弃旧响应。
- 按家庭、学习者、尝试逐个验证归属。昵称相同不代表同一人，年龄也不决定权限。

### 出口与恢复

注册失败保留必要的非敏感输入，密码、验证码和真实密钥不做不当缓存。短信限流与失败给出准确原因和重试条件。认证失效先终止受限读写，重新认证后恢复本人的已保存位置。

### 验收

孩子无需手机号或 API Key 即可继续；孩子会话访问购买、其他学习者或家庭管理被后端拒绝；切换身份不显示上一个人的私有输入或迟到响应。

## 5. 年龄、自选基础与短体验校准

### 首次设置

家长在家庭引导中选择服务端配置的合法年龄段 age_band，用于用语、材料和操作方式；不收集精确生日。首轮具体年龄段选项由产品在试点前统一确定，前端不能自行增加选项或由生日推算能力。

选择“我是小白”“我有一点基础”“我是大神，想挑战”。兴趣与本次目标可选，首次填后可更正，不必每次登录重填。

自评 self_level 是起点偏好，取值为 beginner／some_experience／advanced，不是证书或终身等级。家长协助填写时记录实际录入者；不要将家长评价自动当孩子实际操作表现。孩子会话只允许更正 self_level；age_band 与 display_name 由家长更正。不猜测缺失年龄，也不允许匿名主体为跳过引导创建校准。

### 短任务

孩子表达一个目标，查看 AI 输出，指出一个需要检查的问题，并尝试修改一次。任务使用非私人、可核对的短材料，避免一上来要求配置服务商。

保存：

- 任务、材料与推荐规则版本。
- 孩子的实际输入、修改、判断和解释。
- 固定提示、AI提示、完整参考和真人帮助。
- 服务错误、退出或未完成原因，和学习表现分开。

### 推荐与调整

推荐从哪一项任务开始，并说明依据。允许进入基础路线、尝试挑战或回补某项操作；不能因自称“大神”自动通过课程、增加调用额度或获得家长权限。

推荐规则由教研维护并版本化。AI可以解释和建议，不得将短体验称为科学能力、智力、天赋或升学测评，也不能从一项失败永久定级。

### 出口与恢复

服务不可用时给固定示例或暂停入口，标明模拟／材料演示；不得把服务故障记成能力不足。中断后可继续同一尝试，重做保留新的尝试记录。

### 验收

同年龄不同表现可获得有理由的不同建议；用户能更正自评并理解推荐。推荐不会改写历史成绩或权限。

## 6. 推荐项目与开始课次

### 用户动作

孩子查看当前可以做的项目、为什么推荐、需要完成什么、最后产出什么，再开始或继续。家长如需开通，在家长权限内确认购买范围。

### 系统行为与数据

- 读取已发布的课程及固定版本、先修条件、本人可继续的尝试、权益与额度摘要。
- 解释进入条件：缺基础、课程未开放、未开通、已到期和模型暂停要分别处理。
- 一项推荐并不保证所有高阶内容适合当前孩子。必需课次、可选挑战和允许回补路径由课程定义明确。
- P0只提供一条完整文本项目；未开发的下一课可写待开放或给可执行补练，不能做可点击却无内容的入口。

### 出口与恢复

课程更新后，新尝试绑定新版本；旧尝试可按原版继续或按明确策略重新开始，不能静默换规则。读取失败不显示为未购买；锁定项应给实际能做的替代练习或联系支持。

### 验收

孩子知道现在做什么；权益、先修、年龄表达和自评不会被混成一个等级；未开通课次不能通过客户端改状态绕过。

## 7. 固定课程骨架与 AI 辅导

### 每课闭环

说明目标 → 短例子 → 亲自操作 → 查看结果 → 按规则检查 → 按需提示 → 修改 → 新条件任务 → 保存证据。

具体呈现可以自由设计，不需要固定栏位、控件或组件名。

### 学习内容逐步深入

1. 基础：输入输出、保存、核对，认识 AI 会出错。
2. 表达：任务、背景、条件、格式与迭代。
3. 类别：根据任务理解文字、图像、语音等适配；首版仅文字实操。
4. 比较：控制其他条件，观察模型或配置差异。
5. 接入：理解服务、模型、认证概念、请求响应、状态与额度。
6. 实验：设计测试、查失败、修改复测、在新资料或约束下减少依赖。

### 保存与帮助

输入、操作、提示、解释、输出及版本保存到本人的学习尝试。保存成功返回 revision、input_version 和 input_hash；revision 是并发版本，input_version/input_hash 是已保存模型输入快照的版本与摘要，不能混作候选作品摘要。显示正在保存、保存成功和失败；失败时保留当前草稿。不要依赖浏览器缓存作为唯一权威记录。

AI只在课次范围内辅导。P0 提示接口返回已发布的固定课程提示，来源标为 course 并记录帮助级别；动态 AI 提示后续启用时须走受控运行和成本规则，不能通过提示接口绕过额度。完整参考、成人演示、共同操作、成人代录要与孩子独立操作分开。

### 出口与验收

孩子能亲自作出有后果的选择，解释一次变化，遇到错误可以回到具体步骤。AI生成结果或孩子点击完成不能自动通过课次。

## 8. 模拟、真实调用与运行恢复

### 三种模式

- 教学模拟：按课程演示请求、响应或错误，不向真实上游发起该模拟请求。
- 真实调用：服务端向获准服务商执行请求，保存实际结果和可取得的元数据。
- 历史回放：读取已有运行，显示原始时间与来源，不冒充本次生成。

三种模式在操作、运行详情、检查和报告中保持一致。用于显示“调用模式”的标签不能自行决定真实或模拟，后端执行路径必须对应。

### 真实调用条件

学习会话有效、课次允许、课程权益有效、家长允许真实调用、模型可用、输入与参数合法、额度足够，全部满足后才执行。

孩子选择平台受控模型标识与允许参数，不提交任意服务网址或真实服务商密钥。后端保存真实秘密，教学凭据不等于真实秘密。

### 创建运行

先保存输入，使用服务端回执中的 attempt_id、input_version、input_hash，以 Idempotency-Key 创建平台运行，并绑定课程、材料及允许的模型和参数。服务端读取已保存输入，不接受另一份游离 prompt。相同键和相同内容返回原资源；相同键不同内容拒绝，不覆盖。

平台运行与上游请求分开记录。界面禁重复点击有助体验，最终仍由后端防止重复平台运行和重复额度记账；不能承诺上游在所有网络故障下绝对只执行一次。

### 运行状态与结果

区分排队、运行中、成功、已知失败和结果待核对。展示实际请求／响应模型标识、耗时、截断情况、用量与用量来源；未知值保持未知。

正常失败给出可理解的原因和下一动作，保留输入。服务故障不计入孩子学习失败；截断结果不能当成完整作品。

### 超时未知

未知结果优先查询原运行，不直接再发请求。记录核对期限，超过窗口进入运营队列；若服务商无可靠查询能力，不以重新调用代替核对。

运营依据可信日志或服务商记录确认结果；无法确认时，run.status 仍为 unknown，reconciliation.status=closed、resolution=unresolved，供应商实际成本仍为 null。用户预占额度按事先明确的政策释放或调整，操作者与依据有审计。关闭核对不表示执行成功、失败或免费；重新运行必须是明确的新实验，不静默重试。

### 刷新、退出与权限变化

关闭页面不取消已创建运行或上游请求；重新进入有效会话后查询原记录，不新建第二次运行。权限到期或退款后不接受新的真实请求，已接受运行按已确认的在途处理规则保存结果与结算，不能把权限变化改写成学习失败。P0 不提供取消运行接口或取消状态，也不因退出、超时或退款自动补发。

### 验收

重复点击、刷新、超时、服务重启、额度不足、模式切换和权限变化均有可核对结果。未知不填零费用，模拟成功不等于真实接入成功。

## 9. 同条件比较、测试与修正

### 用户动作

孩子选择两次适合比较的运行，指出差异，写出选择理由，改变一项因素后再次测试。

### 系统行为与数据

- 保持任务、资料、问题和测试版本一致，记录实际变化因素。
- 有两种真实可用模型时才称模型比较；同一模型改提示或参数称配置比较。
- 展示实际输出、失败、耗时及可得用量，不用模型名或价格生成永久排名。
- 同配置重复运行也可能变化，应保留运行次数与观察范围。
- 资料内问题、资料外问题、易误解问题与格式要求分别留测试结果。

### 出口与恢复

比较条件不同则说明不可直接比较，允许重新选择，不偷偷替换资料。一个服务不可用时，可改为诚实命名的配置比较或暂停；不可用模型不能用模拟结果伪装。

### 验收

能从记录还原比较条件、差异、修改与复测；孩子的说明对应实际结果，不只选择最漂亮的答案。

## 10. 候选作品、检查、解释与迁移

### 正确顺序

1. 保存输入，取得 input_version/input_hash，再由服务端读取该输入、选用运行、孩子说明与贡献记录创建不可变候选。
2. 候选以 artifact_id、artifact_version、content_hash 三元组定位；content_hash 由后端按候选内容计算，不等于也不能替代 input_hash。
3. 检查请求引用相同候选三元组和规定迁移作答；服务端选择该课次全部必需检查。孩子解释关键选择，所用帮助如实保留。
4. finalize 请求提交同一候选的 artifact_version、content_hash、check_ids 和所属 Attempt 的 expected_revision。候选错配或检查尚未就绪时拒绝，不悄悄改用新内容或旧检查。
5. 提交接收时，服务端在同一事务核验候选与必需证据，保存提交事实并计算 attempt_status=passed|needs_practice|pending_review。artifact.stage=finalized 仅表示该版本已提交；三种课次结论均保留提交事实，不能只为通过者保存作品。

finalized、passed 和报告 ready 是三种不同事实。内容变更必须新建候选并重新检查；新候选不能带旧检查提交。

文件名、存储表和接口路径由技术契约确定；上述行为顺序与版本一致性必须保留。

### 检查类型

- 客观规则：由后端按固定规则验证格式、已知输入输出或资料边界等。检查作业 status=queued|running|completed|failed，学习 verdict=passed|needs_practice|pending_review|null 分开保存；执行异常时 status=failed、verdict=null，不判孩子未通过。
- AI反馈：标为建议，不能自行产生最终通过。
- 孩子解释：保留本人陈述与所用帮助，不等同于外部认证。
- 人工复核：由获准的真实人员对具体内容提出意见，有来源、时间和范围；普通点评不自动改检查状态。

### 平台内迁移

更换资料或条件并减少步骤提示，记录孩子实际完成、错误和求助。它只能支持当次平台内任务观察；外部工具迁移列为后续验证，不能据此声称孩子已独立掌握所有 AI 工具。

### 出口与恢复

学习结论 needs_practice 时指出具体检查项和回补位置；旧失败保留，复练与旧记录关联。pending_review 要有实际责任人和处理出口；迟到的旧候选复核只进历史，不覆盖当前 submitted_artifact 对应的结论。不能为了赶进度把模型调用成功、抄参考答案或无解释成品当掌握。

### 验收

作品内容、检查、解释和迁移证据能够互相对应；修改会使不适用的旧检查失效；帮助程度在报告中如实出现。

## 11. 成果、个人贡献与家长报告

### 孩子提交

命名作品，选择候选版本，说明自己作出的选择、修改和困难，以及 AI／真人分别帮助了什么。成人代录时保存实际记录人与信息提供者，不冒充孩子操作。

### 报告生成

在版本一致、访问合法的来源上生成家庭只读报告，保存所依据的作品三元组、检查、尝试及生成时间。报告 status=pending|ready|failed，与提交及学习结论独立；报告失败不撤销已保存成果。重建基于原成果事实，不重跑实验，也不补造学习进步。后来复核或修改须生成可追溯的新报告版本，不静默改写旧报告。

报告需要覆盖：

- 起点与本次目标：来自自评和实际任务，非科学测评。
- 做出的作品：可查看版本和前后变化，缺少演示明确说明。
- 孩子的具体选择：实际改了什么、怎样判断与修正。
- 获得的帮助：固定提示、AI、成人演示／共同操作分别说明。
- 检查与局限：哪些通过、失败、待复核、未观察到。
- 下一步：一项确实可提供的补练或挑战，以及适合的家庭支持。

### 事实边界

保存链接不等于运行验证；作品可运行不等于孩子掌握；负责人不等于独立完成；没有帮助记录不等于没有帮助。团队成果也不能全部归给一个孩子。

本人自述、系统事件、实际观察、人工检查和 AI 建议分别标明。数据不足写未记录或未观察到，不生成能力总分、个人贡献百分比、升学结论或“全面独立掌握”。

### 访问与反馈

家庭报告接口仅供关联家长访问；孩子通过本人尝试与作品读取自己的过程及检查，不借报告接口取得家长权限。家长管理需重新认证，默认看到经选择的作品与过程摘要，不自动获得所有原始私人对话或模型配置。

家长反馈是否理解、哪里困惑、是否愿意继续。把家长满意与孩子实际表现分开，不用好评改写学习结论。

### 验收

家长能说清孩子做了什么、获得何种帮助和下一步。每项学习表述有对应证据或明确的陈述属性；跨家庭不能读取，导出不带真实密钥、手机号或无关聊天。

## 12. 开通、继续、到期与退款

### 两类控制分开

课程权益决定可进入的项目与课次；真实调用额度决定可使用的模型预算。自评、年龄和课次通过不自动授予额外额度。

### 建议规则，报价前必须确认

- 未开通：可看公开样例；注册并建立学习会话后可做指定校准和体验课，不可真实调用。
- 试用有效：只开放试用范围，默认不开放真实调用；若单独授权，必须有家长允许与独立上限。
- 正式权益有效：在所购范围学习；真实模型还须服务可用、家长允许与额度足够。
- 课程有效但真实额度用尽：可继续获准的非真实调用练习，保存草稿；真实实验等待补足或下一安排，不计完成。
- 权益到期：停止正式课次新操作与新真实调用；已保存作品、报告和草稿按购买时确认的保留规则只读，续期后按版本恢复。
- 退款确认：P0 仅登记已有人工完成凭据的全额退款，撤销该订单授予的正式权益，其他独立有效权益不受误伤；按已声明规则只读保留历史作品、报告及已存草稿，不伪造学习历史。部分退款与支付渠道自动退款留待后续规格。

上述为统一产品规则草案，尚未生效。成果保留承诺必须与实际数据保留、删除政策一致，不能默认永久保存。

### 人工开通

家长查看课程范围、支持、期限、额度和退款规则，提交申请。运营核验真实收款或试点授权后，服务端一次性发放对应权益，记录依据、操作者和时间。

未到账、待核验、被拒绝或已关闭均不显示开通成功。重复核验与未来重复支付回调不重复发放。孩子会话不能购买、伪造到账或修改权益。

### 继续学习

开通后进入可继续的本人尝试；已到期的版本按确定策略恢复。下一项目未提供时明确待开放，不销售未定义的内容。孩子可暂停，家长可选择不继续，不把持续使用当作唯一成功标准。

### 验收

界面状态、订单、权益、额度与实际允许操作一致；到期、退款与在途请求有确定处理；实际付款和口头意愿分别计数。

## 13. 共用异常与恢复要求

- 读取失败：保留已知内容并说明失败，不画成没有课程、没有作品或未购买。
- 保存失败：输入仍在，明确未保存；重试沿用同一操作语义，冲突时对照最新版本。
- 登录失效：停止写入，回到认证，恢复本人已保存位置；不能泄露旧家庭缓存。
- 越权：服务端拒绝并提供合法返回方式，隐藏按钮不代替权限。
- 课程或输入冲突：拒绝静默覆盖，保留可恢复草稿，明确当前版本。
- 真实服务失败：保留输入和运行事实，分清配置、限流、暂停、额度与网络错误；不扣学习能力。
- 截断响应：显示不完整，允许收窄任务或按课程范围调整，不当作完整成果。
- 未知运行：查询原运行并进入核对流程，不能用无限重试保证“成功”。
- 检查不通过：指出具体依据和回补任务，不抹掉失败或自动贴低能力标签。
- 证据缺失：写未记录／未观察到，给可执行补充，不由 AI 编造。
- 权益不足：说明是范围、到期还是额度，显示仍获准的动作；不迫使孩子自行购买。
- 模型暂停：已有记录与非真实调用学习可按权限继续，明确高级步骤尚未完成。

每个恢复动作都要说明保留了什么、接下来做什么和是否会触发新调用。实际支持人员与处理期限在试点前确定。

## 14. 教研与运营流程

### 教研

起草目标与材料 → 定义步骤和提示 → 写客观检查与解释要求 → 设计平台内迁移 → 人工试讲 → 正常／失败样例核对 → 固定版本发布 → 抽查真实尝试 → 更正并发布新版本。

课程定义需要足够支持实现：适用基础、必需／可选步骤、材料版本、允许操作与参数、提示来源、检查条件、复核责任与退出标准。不得只交“AI带孩子学”一句需求。

### 运营

明确目标家庭与体验范围 → 告知交付和数据用途 → 协助开始但记录帮助 → 处理异常与待复核 → 家长读报告 → 核验实际购买／退款 → 记录支持与获取成本 → 决定维持、调整或扩展。

首版可以使用最小内部工具，不要求完整管理系统。涉及权益、额度和复核的操作仍要鉴权、幂等和审计，不能直接改数据库而无依据。

### 内容与服务问题分流

学习困难交教研补练，基础操作困难补引导，服务故障交开发／运营恢复，支付与权益交获准运营核验。一个人可以承担多个职责，但任务必须有人负责，不能让孩子长期停在“等待老师”或“结果待核对”。

## 15. P0 全链路验收与后续边界

P0采用一页虚构资料问答项目。用同一学习者完成家庭进入、首次设置、校准、课程、模拟、真实实验、比较、修正、候选检查、迁移、提交、报告与开通／续学状态。

验收至少包含：

1. 零基础无需建队、插件或真实 Key，能完成首次有效操作。
2. 家长可更正年龄段与展示名，孩子可更正自评，不篡改历史证据、不升权；匿名主体不能创建校准。
3. 同一年龄不同表现可以获得有理由的不同起点。
4. 草稿、提示和运行在中断后可恢复；跨家庭与跨学习者拒绝。
5. 模式标识与实际执行一致，重复操作不重复建平台运行或额度处理。
6. 真实错误、截断、暂停、额度不足和未知状态有出口，不判学习失败。
7. 比较条件与变化因素可核对，配置比较准确命名。
8. 运行绑定 input_version/input_hash，检查与提交绑定 artifact_id/artifact_version/content_hash；修改后重检。finalized不等于passed，解释和迁移不由前端自报通过。
9. 作品与报告能说明个人选择和实际帮助，缺证据不补造。
10. 家长能理解报告；实际购买、退款与继续购买另行记录。
11. 原协作数据和锁定行为兼容保留，学习记录不自动上传团队资料库。
12. 内容、交互、前后端数据与权限以及运营恢复共同验收，不用一张成功截图代替全链路。

完整外部工具迁移、图像／语音真实流程、多人项目、更多家庭成员、公开社区及复杂订阅均为后续能力；是否扩展由真实家庭表现、交付成本和购买证据决定。
