## 使用方式与文档关系

负责人先读整体规划和产品流程，前端、后端、美术分别阅读自己的职责文档，再共同对照接口规范与宪法。每次将一个完整用户故事转为具体功能规格、实施计划、任务与验收，不将全部远期想法一次性塞进首版。

交付约束用户行为、业务状态、数据、素材和验收。统一前台采用已采纳的 `design-v1` 时，页面壳、tokens、一级导航和状态覆盖遵循[统一前台视觉宪法与 UI 契约](视觉宪法与%20UI%20契约.md)；未纳入统一前台的探索仍保留设计选择空间。界面自由不免除真实状态、可操作性和权限隔离。

宪法负责原则与强制接口规则，接口规范负责详细字段，其他文件解释产品与分工。发现差异时同步修正文档，不能各取一版。实现时补充对应 OpenAPI 与验证证据。
