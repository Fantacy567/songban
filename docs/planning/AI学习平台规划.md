## 1. 产品定位与设计原则

目标家庭是家长缺少 AI 经验、不了解孩子能尝试什么的家庭。付费者是家长，使用者是孩子。平台从零开始提供有顺序的实践与反馈，再逐步进入模型选择、真实 API 接入、比较和测试。当前规划以这一家庭使用关系为目标。

在现有协作和模型调用底座上，新建从零开始的学习入口、任务课程与 AI 实验工作台。家长付费，孩子使用；年龄、自评和实际任务表现共同影响学习路径。

| 原则 | 设计要求 |
| --- | --- |
| 从零开始 | 初次学习不要求 API Key、安装插件或已有编程知识；必要时补充文件保存、输入输出等基础操作。 |
| 年龄与基础分开 | 年龄调整用语、素材与操作方式；自评只推荐起点，学习路径再由具体任务表现校准。小白和大神不是永久能力标签。 |
| 作品串起课程 | 先明确要完成什么，再引入模型类别、效果比较、API 接入与测试；每一课都有可检查的任务。 |
| AI 引导与课程规则分开 | 课程目标、素材、步骤和验收由作者设计并版本化；AI 解释和逐级提示，不能自行改变验收标准或直接宣告掌握。 |
| 过程与帮助可追溯 | 保留学习者选择、输出、失败、修改和 AI/真人帮助；接口成功、作品可用和学习掌握分别判断。 |
| 模拟与真实分开 | 每次实验标明教学模拟、真实调用或历史回放；教学凭据不等于真实服务商密钥，回放不伪装成新实验。 |

## 2. 首次登录与学习入口

| 环节 | 体验 | 实现边界 |
| --- | --- | --- |
| 1 家长进入 | 复用家长手机号/密码登录，新增创建孩子学习档案的流程。首版聚焦一个家庭、一个孩子；数据归属预留多档案空间。 | 现有登录可改造；家庭关系与学习权限新建。 |
| 2 首次学习设置 | 孩子或家长协助填写展示名、年龄或学段、自评水平；兴趣和目标可选。首次填写，以后可调整，无需每次登录重填。 | 保存实际录入者和更新记录；年龄不作为模型或计费管理权限。 |
| 3 水平入口 | 我是小白 / 我有一点基础 / 我是大神，想挑战。分别推荐零基础、基础巩固或挑战任务。 | 自评不自动授予通关；选择大神也不解除调用限额。 |
| 4 起点体验 | 做一次短任务：表达目标、查看 AI 输出、指出一个问题、尝试修改。记录所用提示与实际操作。 | 属于路线推荐，不能称为科学能力或天赋测评；可返回基础路线。 |
| 5 进入课程 | 显示现在做什么、为什么学、会产出什么；中途退出后继续本人的练习。 | 不要求先创建团队、填写工时或等待队长确认。 |
| 6 家长查看 | 查看自己孩子的作品、独立选择、帮助记录、检查结果和下一步；学习入口不暴露密钥、账单或家长管理能力。 | 家长会话与孩子受限学习会话必须区分，不能仅用前端身份按钮切换。 |

## 4. 从零开始的学习路径

以下是长期递进方向。首版只实操一条文本项目路线；图像、语音等先作为概念素材，不承诺已接入全部模型类别。年龄调整教学表达，具体操作表现调整学习起点。

### 0 认识AI与基本操作

- **学什么**：AI的输入输出、用途与可能出错；必要的保存、上传和文件操作。
- **做什么**：完成一次提问，指出一项需要核对的内容，并保存结果。
- **怎样检查**：能说明自己问了什么、结果是什么、为什么仍需检查。

### 1 表达需求与修改

- **学什么**：目标、条件、上下文和结果要求。
- **做什么**：做出一个小作品，亲自补充限制并修改一次。
- **怎样检查**：能指出自己的修改带来什么变化，而非只点击生成。

### 2 认识模型能力

- **学什么**：文字、图像、语音、多模态等能力与适用任务。
- **做什么**：为具体任务选择一类模型并解释理由；首版只实操文本，其余用概念素材。
- **怎样检查**：选择理由对应任务；不把模型名字、大小或价格直接当作质量排名。

### 3 比较效果

- **学什么**：同一任务、相同输入、可观察标准，以及质量、速度和成本的取舍。
- **做什么**：比较两种实际可用文本模型；资源不足时明确改为同一模型的配置比较。
- **怎样检查**：能指出具体差异与失败例；配置比较不宣传成双模型比较。

### 4 API接入与调试

- **学什么**：服务地址、模型标识、请求、参数、响应和错误。
- **做什么**：在受限工作区完成一次请求，修改参数并修正一个配置问题。
- **怎样检查**：能解释输入输出如何对应；真实调用有服务端执行记录，模拟错误明确标注。

### 5 实验与独立项目

- **学什么**：设计测试、检查失败、修正、复测与迁移。
- **做什么**：完成小项目，更换资料或条件后在减少提示的情况下完成新任务。
- **怎样检查**：记录是否自主完成、用了哪些帮助；功能通过和学习结论分别呈现。

### 每课的固定循环

说明目标 → 看一个例子 → 自己操作 → 按规则检查 → 根据错误逐级提示 → 修正再试 → 做一个不同条件的小任务。AI可以解释、提问和提示，课程作者维护目标和验收；单凭AI说“你会了”不能升级为掌握。

## 5. AI 实验工作区

| 区域 | 作用 |
| --- | --- |
| 任务区 | 当前目标、素材、操作步骤和验收要求；随阶段调整语言与展示复杂度。 |
| AI引导区 | 解释与逐级提示；记录使用了哪些提示或完整参考答案。 |
| 操作与配置区 | 入门只填需求；进阶逐步开放模型、受限请求体、参数和教学凭据。 |
| 结果与作品区 | 输出、可保存版本和固定模板预览；首版不执行任意代码或提供完整终端。 |
| 实验与测试区 | 请求状态、错误、实际请求耗时、上游返回的用量、测试结果和比较记录。未知用量不填0，费用估算注明依据。 |
| 学习记录区 | 尝试、失败、修改、提示/真人帮助和讲解；家长报告从获准的结构化记录生成。 |

核心是可操作的学习工作台。首版提供受限配置、请求、响应和测试，不需要复刻完整操作系统。浏览器中的“测试密钥”只用于教学；真实服务商密钥保留在受控后端。

## 6. 首版项目与范围

| 范围 | 内容 |
| --- | --- |
| 项目 | 用平台提供的虚构短资料，制作一个资料问答助手。主题可选，首版不用真实个人资料、文件知识库或向量检索。 |
| 首次体验 | 家长登录、创建一个孩子档案，填写年龄与自评，做起点体验并推荐路线。 |
| 做出初版 | 在现成模型配置下提问，再补充目标和输出要求，保存可比较的初版与修改版。 |
| 比较方案 | 相同资料和问题比较两种模型或两种配置，保留实际输入、输出、版本和差异说明。 |
| 接入一次 | 逐步展示请求配置，经受控后端执行真实文本API；教学模拟和真实请求分别记录。 |
| 测试与修正 | 检查资料内问题、资料外问题、易误解问题和格式要求；修正后复测。格式自动检查，内容质量首批人工抽查。 |
| 迁移与反馈 | 换一份资料或约束，减少步骤提示；记录真实帮助程度，给家长一份作品与学习过程报告。 |
| 范围边界 | 首版不做完整桌面、任意终端/代码执行、全模态实操、课程商城、复杂机构后台、公开作品社区或自动能力排名。 |

小白路线从认识输入输出、表达和检查开始；有基础者可挑战后进入同一项目更深入的环节。首轮用虚构资料和已知检查标准，减少素材复杂度。

路演可展示首次设置、一次实验失败与修正、一次模型或配置比较，以及家长报告。演练资料、模拟响应和真实调用都应明确标识，不作为真实用户效果或付费证据。

返回当前真实会话角色与可访问档案；不依赖前端自报家长身份。

#### `POST /api/learn/learners`

家长创建本人孩子档案；写入年龄/学段、自评和可选兴趣。孩子学习凭据单独签发。

#### `GET /api/learn/courses 与 POST /api/learn/attempts`

读取获准课程，创建绑定学习者、课次和版本的尝试；可继续本人未完成记录。

#### `POST /api/learn/attempts/{id}/actions`

保存允许的操作和提示事件；后端核验归属、事件ID与尝试版本，防止覆盖和伪造通关。

#### `POST /api/learn/attempts/{id}/runs 与 /checks`

后端校验参数、额度与模式后执行实验，检查端读取真实结果而非前端自报成功。

#### `GET /api/learn/learners/{id}/report`

仅关联家长与授权学习者读取相应报告；导出前选择内容并预览脱敏结果。

上述名称用于明确职责，可在实现时调整。本次未创建这些业务模块；学习尝试与团队计划分开保存，避免把孩子的单人学习套进组队、队长确认和同伴验收流程。

## 8. 必要的实现约束

| 边界 | 实现要求 |
| --- | --- |
| 入口与旧功能 | 先增加 /learn 和明确的学习模式开关，再根据试用决定是否切换首页。旧协作数据、接口和锁定行为保持兼容。 |
| 模型调用与预算 | 只允许服务端核准的地址和参数；每次实验设输出、次数、并发和预算边界。额度检查在后端，失败不自动无限重试。 |
| 重复与未知请求 | 重复点击复用已记录事件；请求超时且上游是否执行未知时如实标记，不盲目重发或声称没有费用。 |
| 可复现与记录 | 实验保存课程/资料/配置版本、模式、实际模型标识、输入输出和检查规则。模型输出可变化，历史成功不能自动替代新实验。 |
| 教学与安全边界 | 用户资料作为内容而非系统指令；首版不提供任意网址代理、系统命令或模型输出自动执行。必要的错误演练用明确标注的模拟响应。 |
| 隐私与展示 | 只收学习需要的信息，年龄不公开；成果默认家庭可见，完整聊天、密钥、手机号和私人路径不进入报告。真实案例分享需确认相关展示许可。 |

资料长度应显式校验并提示，不能像旧通用聊天接口一样默默截取实验输入输出。用量和费用的口径要区分上游返回值、平台估算值与未知值。

## 9. 实施顺序与验收

### 9.1 实施阶段

| 阶段 | 交付 | 验证 |
| --- | --- | --- |
| A 确定一个教学任务 | 写明适用基础、目标、虚构资料、各级提示、客观检查和人工抽查方式；人工带一次，观察孩子在哪卡住。 | 目标家庭能开始并实际操作；确认AI与真人各需提供什么帮助。 |
| B 建立单人学习闭环 | 学习档案、独立会话、首次设置、起点体验、版本化课次、学习尝试与恢复。 | 新手不建队、不装插件也能完成并继续自己的练习。 |
| C 接入实验能力 | 模型选择、受限请求配置、模拟与真实模式、运行记录、额度、比较与检查。 | 可核对真实调用、保留失败，能够完成一次修正与复测。 |
| D 形成家庭可读证据 | 作品版本、提示/帮助、迁移任务和家长报告；少量目标家庭试用并记录付费。 | 分别评估技术通过、学习表现和家长购买；按真实结果决定扩展课程与模型。 |

### 9.2 首版验收清单

| 场景 | 验收条件 |
| --- | --- |
| 首次设置 | 首次填写年龄与自评，以后可修改；选大神只推荐挑战，不直接生成已掌握或无限调用权限。 |
| 单人流程 | 孩子无需手机号、API Key或创建团队；家长会话与学习会话分离，学习者只能进入获准的本人档案。 |
| 年龄与基础 | 同一年龄允许不同路线；年龄或自评变化不篡改既往课程记录与检查结果。 |
| 尝试恢复 | 退出重进仍保留本人输入、作品与提示；重复事件不重复计入成果，其他档案无法读取。 |
| 课程版本 | 作者更新课程后，旧尝试仍按原版本追溯；不能套用新版规则伪造历史已通过。 |
| 真实与模拟 | 界面、实验详情、报告均一致标明模式；模拟成功不计为真实接入成功，回放不计为新调用。 |
| 真实请求与额度 | 无效参数、受限地址、鉴权、限流、余额或超时失败有清楚状态；后端额度生效，连点和未知请求不盲目重发。 |
| 实验比较 | 可核对相同资料与问题、不同模型或配置、实际输出与检查；未知用量不显示为零成本。 |
| 学习评价 | AI给参考答案后完成的任务仍记录帮助；代码或接口通过不自动写成掌握；迁移任务能保留再次求助。 |
| 家庭报告 | 家长能找到作品、具体选择、修错、帮助与下一步；导出不泄露原始密钥、手机号或无关聊天，不产生能力总分。 |

先验证一个年龄与基础相近的小群体，再扩大课程。不预设开发工期、课程数量、效果百分比或营收；先用真实体验验证课程和支持成本。旧团队协作可在未来团队项目阶段继续使用。

## 10. 技术、学习与商业分别验证

| 验证 | 看什么 | 结论边界 |
| --- | --- | --- |
| 技术验证 | 登录、隔离、恢复、真实调用、错误处理、额度、记录和导出正常。 | 只能说明功能链路可用。 |
| 学习验证 | 孩子是否愿意操作、能否判断结果、修正问题，并在新任务中减少依赖。 | 需要真实孩子任务表现和人工抽查，不能由接口成功代替。 |
| 商业验证 | 符合定位的家长实际购买，认为反馈有用，出现继续购买；支持工时和获客投入可记录。 | 先验证具体项目体验；暂不假设订阅、提价、续费率或低获客成本成立。 |

家长报告展示孩子做出了什么、独立作出哪些选择、怎样修正问题、用了哪些帮助、迁移任务表现与下一步建议。年龄、手机号和完整私人对话不进入公开成果。
