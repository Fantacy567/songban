# H6 交付准备与待核验项

日期：2026-11-02。主会话协调三个子会话实施 H0–H5，本文交给实际产品、教研及运维人员。本文不记录或代填真人试用结论，不开启收费。

## 当前交付边界

- 统一演示保留虚构家庭、孩子、老师和五人比赛小队。示例账号只注入演示页面。
- 三个一级入口共用现有服务；比赛状态机、学习身份和课程记录继续使用原接口。
- 全程松伴按当前身份与页面取上下文；学习工作区仍使用原课程对话。新平台实时模型需要显式配置与调用上限，本轮没有新增真实文本调用。
- 图片供应商按用户决定采用豆包；没有收到密钥或模型配置。本轮只校验模拟协议和本地原创图片的自动保存，不能称真实豆包出图验收。
- 作品默认私有。作品封面不替代实际成果、孩子的操作或比赛提交，自动保存不表示作品公开。

## 交给实际人员的核验

1. 教研：阅读首门邀请卡课程和“认识黑客松”的故事；记录适用年龄、需要成人解释的词、每一步是否有真实产出。可用已有 experience/pilot 资料记录，不代填签署。
2. 试用：确认真实监护关系和用途后，观察孩子能否选入口、读懂两卡、完成一次修改、找回作品及理解松伴提示。记录卡住或退出，不能只登记完成者。
3. 支持：确定实际接单人、可联系渠道、响应时间和替补，演示老师不是线上支持承诺。
4. 模型：提供服务器私密配置文件路径、选定模型及明确的调用上限。图片另需合适的用途授权、私有目录和图片额度；不能沿用已经消耗的文本测试许可。
5. 现场：实际手机、网络、输入法与辅助功能仍需现场验证。浏览器模拟窄屏不能替代真实设备观察。
6. 公网：当前只有本机服务；目标域名、HTTPS、cookie、来源白名单、备份恢复和存储权限需要在明确目标后验收。没有公网部署或新开售。

## 运维与恢复

统一演示的私密 resume.json 保存原比赛身份和导入的学习元数据，不能提交源码或对外发布。启动使用 scripts/run_demo.py 的 `--resume`，不能重新造一批演示身份覆盖旧记录。旧源数据库保持保留，回退前先停止目标进程并保全新产生的数据，不把切回旧库当作无损回退。

新平台由 PlatformSettings 显式安装。暂停新写入可关闭 enabled；关闭 navigation_enabled 仅隐藏新导航。已保存作品/图片仍按有效授权读取。未知模型请求不能通过换编号或重启来重复派发；图片已经返回而保存失败时，只恢复保存。未知结果的后台核对必须有供应商实际证据。

豆包字段、预算和部署注入方式见 [图片后端接线](H02-H4图片后端接线.md)。本机路径及 PID 的最终证据由 [主会话验收报告](../H5-主会话验收报告.md)记录。
