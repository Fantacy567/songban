# H2 作品集

状态：统一私人作品集已实现，含学习/比赛关联/外部作品、版本和当前封面投影；域与HTTP权限检查通过，浏览器结果见[主报告](../H5-主会话验收报告.md)。原估算4–6有效人日。依赖：HG0、HG1及作品/资产引用契约；可与H3并行。负责：作品集会话，中央注册，独立验收。

## 输入

[作品集与数据衔接](../04-作品集与数据衔接.md)、[UI层级](../01-UI层级与页面规范.md)、学习作品及版本、比赛成果和本人贡献事实、H0的身份/可见性/资源引用契约。图片生成还未接入时使用已保存的真实产物截图或有来源的回退，不假装已出图。

## 输出与专属范围

1. 大图、无外层卡片边框的作品列表和可访问的标题/操作；进入详情看真实产物、本人说明、贡献、来源和版本。
2. 学习作品在本人明确保存后可被收录；比赛展示团队成果并标注本人贡献；外部工具作品通过受控登记进入同一目录，不宣称平台实际运行了外部工具。
3. 同一作品在列表只显示一件，修改保留版本。封面、实际产物、过程证据及报告分别引用；删除展示条目不隐式删除原课次/团队成果。
4. 默认本人和已授权家长可见；公开展示另有显式选择和权限。团队共享链接不自动授权读取孩子完整作品集或聊天。
5. 保存、重复操作、冲突、刷新、重启、链接失效、图片缺失和撤回有实际回执与恢复；资产ID留给H4接入。

本会话拥有H0登记的作品领域、页面、增量迁移和专属测试。原`WorksPage.tsx`或比赛/报告域需适配时先列消费者，由中央登记所有者后串行合入；不重写原完成规则、不与H3/H4共改聊天或资产注册。

## HG2

三类作品均能按本人权限保存/读取/恢复，团队贡献准确，版本不覆盖历史；封面不冒充实际成果。外部作品来源和未核实状态可辨认。另一孩子/团队ID、未授权家长、已撤回链接等拒绝正确。大图无边框在390/768/1440和键盘操作下仍可使用。

## 失败、回退与交接

新聚合投影失败时保留原学习/比赛作品入口，不用空列表覆盖原数据。关闭作品集入口或新写入时保留合法历史回读和撤回；不得为了回退删除源作品、贡献记录或版本。迁移只新增，不编辑旧checksum。

交付作品身份、来源引用、可见性、版本/封面绑定、错误状态与资产接入点，交给H3/H4使用最小投影；原文聊天不得随作品详情一起无限加载。
