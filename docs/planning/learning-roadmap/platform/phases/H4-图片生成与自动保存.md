# H4 图片生成与自动保存

状态：豆包适配、私有保存、自动归档、任务恢复和预算工程已实现并通过MockTransport/样例检查；无真实凭据和预算，HG4真实供应商部分未验。见[图片交接](../handoffs/H02-H4图片后端接线.md)。原估算4–7有效人日工程工作；外部配置等待另计。依赖：HG0、HG2、HG3的最小授权、归属和上下文接口。负责：图片会话，中央账本/迁移/配置接线，独立验收。

## 输入

[松伴与图片边界](../03-全程松伴与图片数据边界.md)、[作品引用](../04-作品集与数据衔接.md)、H0资产/任务契约，三种用途分别是课程封面、作品封面、作品内插图。当前尚无已验收的图片供应商、图片预算或正式存储；已有文本调用额度不能继承到出图。

## 输出与专属范围

1. 服务端校验当前用户、用途、目标课程/作品及revision，创建有幂等号的持久任务；普通浏览与松伴展开不触发生成。
2. 已授权的生成请求成功后自动保存文件与资产元数据，并归档到目标资源，无需孩子再下载上传或重复点击“保存图片”。真正保存回执出现后才显示已保存。
3. 生成、文件持久化、数据库归档、选用/替换封面、作品保存、课程发布及公开展示分别留痕；自动归档不自动授予课程发布权限或替孩子交作品。
4. 保存来源、用途、提示/模型/素材版本、真实响应信息、内容校验和引用、生成时间及候选/选用版本。封面明确来源，真实成果截图仍保留。
5. 显示排队、生成、保存、已保存、失败与unknown等实际状态；供应商已返回但存储失败时优先恢复现有结果，不重发出图请求。潜在已派发的超时保留预算与核对，不自动换编号重试。
6. 未配置/无预算时提示当前不可用；离线fixture与有来源的本地素材用于工程检查，不写成真实AI生成。

本会话拥有登记的新图片任务、供应商适配、存储/资产模块与专属测试。共享预算、迁移注册和配置由中央接；H2只读取资产投影，H3发起授权意图，不各建一套图片后台任务。

## HG4

三种用途的权限、目标归档、幂等、版本、刷新/同库重启及保存失败恢复都有实际工程证据；无授权课程封面、他人作品、撤回/变更目标不能错误绑定或泄露。

真实供应商验收另要求明确供应商与服务器凭据来源、虚构资料、请求次数/输出上限及额度、实际响应与用量、保存回读及异常证据。上述外部条件未具备时，工程可完成并标记真实路径未验；不得把fixture改个模式名后宣称HG4全部通过。新调用预算由实际任务明确提供，不从历史额度推断。

## 失败、回退与交接

暂停新生成时保留已保存图片、选用版本、unknown及人工核对出口。归档冲突保留产物与目标版本供恢复，不静默覆盖孩子编辑。回退读投影可继续使用旧封面/实际截图，不删除原资产、把未知费用归零或重跑旧作品。

交付生成与存储配置、资产/任务状态、预算边界、调用计数、幂等/恢复证据及模式标记；私密key和二进制测试数据放批准位置，不进公开源码。
