# 松伴三入口平台规划

版本：platform 1.0.0；日期：2026-11-02；约束版本：[项目宪法2.0.0](../01-项目宪法.md)。

本轮将已确认的规划分会话落到代码。目标固定为“AI 教学大厅、黑客松教学大厅、作品集”三个一级入口，同一个松伴贯穿全程，课程封面、作品封面与作品内插图可以按授权生成并自动保存。实现与实际验收状态以[主会话报告](H5-主会话验收报告.md)为准，不能把计划或模拟结果当作真实供应商及真人验收。

## 1. 已写定的界面层级

1. 公共入口：品牌首页、登录、必要的身份准备；短访谈确认后可以直接开始首作，回访优先继续。
2. 一级导航：AI 教学大厅、黑客松教学大厅、作品集。家长、老师和运营入口按权限放在账号或辅助区域。
3. 大厅内容：AI大厅按阶段展示带图课程卡；黑客松大厅首屏固定两张带图卡片“认识黑客松”“跟松伴开始一次实践”。第一次先被引导认识黑客松，已有实践直接继续。
4. 学习与实践工作区：学习沿用步骤、松伴对话、作品预览；比赛沿用现有活动、组队、选题、确认、投票、任务、提交和复盘。旧链接仍可恢复，不能重建比赛流程。
5. 作品与操作：作品集用无外边框的大图展示学习、比赛及外部工具作品，进入详情再看真实产物、本人贡献、过程与版本。全程松伴是跨页陪伴能力，不占第四个一级导航；工作区不再叠加第二个聊天框。

详细层级、页面状态和响应式规则见[UI规范](01-UI层级与页面规范.md)；完整用户故事见[关键路径](02-关键用户路径.md)。

## 3. 分期顺序

H0核对现有代码、信息层级和必要契约增量；H1完成三入口、两大厅与单一演示入口；H2接通作品集；H3把已有松伴对话扩展为全程陪伴；H4实现图片生成与自动归档；H5验证跨模块完整故事；H6由真实参与者执行教学与试点验证。

已完成的P1–P4及E0–E4底座继续复用。H编号用于本次平台增量，与原P5收费、P6比赛衔接及P7机构复制不是同一套状态；H6通过也不自动批准收费或全国复制。

## 4. 已确认与暂定项

用户已确认：三个一级入口、阶段大图课程卡、黑客松先认识再实践的两张入口卡、作品集大图无外边框、同一松伴AI全程陪同、相关图片生成后自动保存、只保留一个演示站、分会话实施。

工程默认：延续当前技术栈和米白／紫色／小松树视觉；首门可开始课程复用已实现的班级活动邀请卡；本机演示以8895为统一入口、真实账号站8894独立；阶段先给推荐次序，暂不额外强制锁关。默认项不冒充用户逐项选择，H0可依据现有约束细化。

用户已选择豆包作为图片供应商，尚无凭据。仍需在相应门槛前确定：新增课程内容与发布标准、是否强制阶段解锁、正式图片预算／存储／审核、作品公开规则及保留期限、真实试点的参与人和时间。缺少这些不妨碍工程实现，但不能伪造可开课、真实出图或运营结论。

## 5. 当前执行状态

三个内部子会话已按依赖实施大厅与作品集界面、作品与图片后端、松伴与独立回归，主会话串行整合共享接口、导航、构建、演示和验收。代码仍在当前工作区，尚未提交或推送。本轮零新增真实模型调用，不收费、不部署公网。
