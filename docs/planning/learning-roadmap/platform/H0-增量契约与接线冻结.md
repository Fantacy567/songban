# H0 增量契约与接线冻结

日期：2026-11-02；中央与H01/H02/H03已核对实际代码。本文件记录工程选择，不改变原学习0.2.4／70操作及旧比赛规则。

## 页面与身份

同源保留原生比赛壳和React学习挂载；一级导航固定三个。学习入口 `/learning-prep#/learn/courses`，黑客松大厅 `/#/hackathon`，认识内容 `/#/hackathon/intro`，作品集 `/learning-prep#/portfolio`。学习壳支持 `#/hackathon`、`#/hackathon/intro`，孩子可直接了解，不用带受限身份调用旧比赛API。进入旧实践时按原身份边界准备，不交换管理凭据。原学习首作、作品版本、比赛哈希与访谈书签继续可用。

阶段先用推荐次序，不新增强制锁关。三个入口共用原品牌；工作区各自保留必要子导航。大厅采用纯props组件，同一组件既可在学习壳使用，也可由原生壳mount，身份变化以contextKey清理临时状态。

## 平台域与操作

新增可选 `/api/platform/v1`，平台版本0.1.0，复用同一SQLite和学习授权服务。只有实际安装后才豁免旧API拦截；平台内部逐请求验证transport、session／browser epoch、cookie写入CSRF、Bearer同源及提交前身份。受限孩子cookie优先，Bearer不能逃逸；连接器令牌不作为平台通用身份。旧接口与学习迁移checksum不改。

作品操作按 `schemas.py` 的严格请求／响应及ROUTE_SPECS注册：本人作品列表／详情、外部作品保存／版本、管理者选择本人可共享比赛来源提出关联、孩子接受／拒绝／撤回。学习者和账号ID不自动对应。家长投影需要已有有效learning和parent_summary用途；无公开接口，首版只做私人作品集。

比赛关联显示选中来源、本人贡献说明与性质，由孩子确认后加入私人集，来源失效重新鉴权。保存源作品、封面、作品集投影、检查与报告各自有版本。所有写操作携request_id、需要时expected_revision，重放前重验身份与资源，不自动发新请求。

松伴会话按当前主体和domain/resource稳定恢复；学习run实际帮助复用既有CompanionPanel和help链路。大厅和作品集在未配置新调用预算时提供明确标记的本地指引；不将其冒称真实模型。比赛上下文只读当前队伍授权资料，未分享私聊不进入团队。模型不能自动投票、过关或公开。

用户本轮已选豆包作为图片供应商，目前没有凭据。按火山方舟Seedream接口做可配置服务端适配；请求成功后自动保存受控资产并关联用途，失败／unknown不重发，未配置时如实说明。课程封面需受控内容配置权限，孩子只操作自己的作品。具体请求上限和正式凭据在真实启用前明确，本次不外发付费请求。
