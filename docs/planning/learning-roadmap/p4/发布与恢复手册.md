# P4 发布与恢复手册

更新：2026-11-02。适用于当前 FastAPI、SQLite、同源静态学习模块；本文件是交付准备，不代表已对外部署。测试结论见[S00-P4联调](../handoffs/S00-P4联调.md)。

## 运行配置

由应用工厂显式传入 `learning_settings=Settings(...)`，不通过发现.env自动开启学习或真实模型。`navigation_enabled`默认false，仅控制“AI学习／黑客松”一级切换；原比赛书签和活动/实践子导航保持。学习页路径仍为 `/learning-prep`，后台为 `/learning-prep#/learning-admin`。

`enabled`控制学习新写入；`course_enabled`控制课程新操作；`models_enabled`与完整ModelSettings控制模型工作；`mock_enabled`须显式设置；`reports_enabled/publication_enabled`分别控制整理与发布。各开关不授予账号权限、不构成课程权益、不代表真人老师在线。家庭角色、同意、服务端课程授权、分配案件、模型预算仍需分别成立。

当前运行时契约0.2.3共67个操作；P0冻结0.2.1保留。P3的3个可选Config字段之外，P4增加可选 `reports_readable`，用于停写后发现历史报告；`reports_enabled`继续表示可整理新报告。隐私读取逐次鉴权，读取能力不等于写入能力。

已有学习数据的数据库不能省略learning_settings启动。暂停应显式传Settings并关闭相应写入开关，保留旧凭据边界。新模型调用默认不配置；P3获准的3次真实调用预算已经用完。

## 备份与隔离恢复

使用 [learning_backup.py](../../../../scripts/learning_backup.py)，显式给出源和新的目标文件；脚本不读.env、不覆盖现有文件、使用SQLite在线备份，包含已提交WAL事务，检查integrity和外键。

```powershell
# 路径需替换为已确认的本次数据库及新文件；目标父目录必须已存在。
python scripts/learning_backup.py "D:\approved\application.sqlite3" "D:\approved-backups\before-release.sqlite3"
python scripts/learning_backup.py "D:\approved-backups\before-release.sqlite3" "D:\isolated-restore\rehearsal.sqlite3"
```

第二条是恢复到新的隔离副本，不是覆盖生产。验收完整性后再用明确的暂停配置启动副本，核对旧账号/团队行、迁移记录、作品版本、报告发布、用量账本及unknown责任人；重新认证，测试本人读取、跨家庭拒绝和报告撤回。副本动作不得改变源库。未核对真实目标与现有授权前，不切换生产连接。

本期已演练完整P4虚构数据库：37张学习及旧主体/团队相关表逐行一致，迁移重启幂等，暂停后家长读取报告和作品版本成功，报告撤回刷新保持。另有WAL测试确认备份包含已提交记录，不包含在途未提交记录；已有目标文件和源文件都不会被覆盖。证据在 `E:\松伴\outputs\learning-p4-20261102\recovery-results.json`。

## 迁移与回退

本期没有改M01/M02/M03冻结DDL或checksum；新增导航与历史读取能力不需要清库。当前应用对已有迁移按checksum核对；出现不一致时停止并检查版本，不能直接改checksum。

暂停顺序：停止接收新的学习/模型/报告任务，保留服务让正在派发的调用有机会落盘；若进程硬中断，由持久租约恢复unknown，不能重复外发。保留模型核对和报告撤回功能。负责人依据已录入证据处理unknown，不能用“归零”消除未知费用。

回退导航设 `navigation_enabled=False`。学习新写入暂停仍保留已保存作品、课程状态、报告及核对元数据的受权只读；已分配人工案件仍可在权限内认领/完成。不得回退到不认识学习身份的旧应用并直接连接迁移后库；旧发布包若缺身份保护/账本核对能力，先维持当前代码的暂停模式。
