# P4 老师与支持操作说明

更新：2026-11-02。仅说明已实现的操作；真实人员及值班时限尚未指定。工程测试中的“隔离测试复核员”是合成身份，不能用于对家庭承诺服务。

## 进入与处理原则

使用本人获准账号在 `/learning-prep#/learning-admin` 重新认证。后台只列实际分配的案件；关系核验、作品复核、报告校对、发布和用量核对是不同权限。不能借用家长账号或给浏览器填管理员字段获得权限。

先看案型、目标、负责人、期限、支持出口和当前版本，再认领。查看对应材料，选择本次反馈引用的来源，填写具体反馈后提交。没有足够依据时选择补充或补练，不替孩子填独立判断。发生版本冲突时保留输入，核对最新证据再决定；不直接覆盖他人处理。

## 关系与课程准备

家长创建学习称呼并声明关系，不自动获准。受控核验流程录入必要证据后，由获分配人员明确确认或拒绝。当前支持一个家庭档案对应一个学习者；另一家庭必须使用自己的账号，不能通过改URL查看孩子。

确认关系后，由家长逐项确认当前获准文本的用途。首课权益由服务端受控授权，再由本人家长认证完成报名接口；本期没有自助付费或后台开班表单。没有权益时页面保留起点问答，不谎称课程已开放。正式报名/支付和权益产品化属于P5范围。

## 作品复核

查看孩子保存版本、自查、实质修改、换材料尝试、复盘与帮助披露。M1–M4分别给出依据；只有都存在支持证据且本次人工结论明确通过，才完成这一轮审核。规则绿灯、AI候选或一次勾选都不替代人工判断。孩子改版后需重查，旧结论仍保留对应历史版本。

## 报告复核和发布

孩子生成草稿、核对事实并明确送审。复核人员逐条核对观察和来源，处理异议，可修订或退回。不要将模拟练习改称真实模型实验，不推断天赋/人格或宣称孩子完全独立。

“确认本版本复核通过”仅批准当前版本；具备发布权限的人另点“发布已批准的这一版给家长”。家长仅查看已发布快照，草稿/待审/仅批准均不可见。报告修改或证据变化需重新核对；旧批准不能发布新内容。需要时撤回并记录原因；本人有效授权撤回后报告同步失效。发布不会发送外部消息或建立公开分享链接。

## 结果未知和故障

模型unknown保留输入与预占，不重复点击生成。到“模型用量核对”查看本人分配案件、期限、预占和真实费用未知状态。供应商/财务证据须先由服务端受控录入；网页只能引用既有同案证据，选择确认收费、确认未收费或接受可验证结果。没有证据不填写0，未知费用不写免费。

报告生成失败不影响已保存作品；只依据既有事实重建，不重跑孩子实验。存储失败或回执未知时按页面核对原操作；不要换新操作号反复提交。家庭失权时重新认证/核对真实授权，不绕过权限。暂停仍保留受权历史读取、报告撤回及核对，恢复步骤见[发布与恢复手册](发布与恢复手册.md)。

真实试点前还需明确谁收关系证据、谁复核作品/报告、谁发布、谁核账、各自期限和替补联系渠道。本期只验证了这些角色的工程边界，没有替代实际排班。
