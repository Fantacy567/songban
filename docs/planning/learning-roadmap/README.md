## 产品决策

松伴服务孩子、家长和运营人员。第一阶段是独立的 AI 工具学习：了解起点、三关练习、角色陪伴、作品、检查与家长反馈。第二阶段是黑客松：活动、组队、选题、分工、交付、展示与复盘。学习不要求先建队、安装连接器或选择比赛；有经验的孩子也不必学完全部课程才能进入适合的比赛。

学习与比赛共用品牌和账号主体，分别记录进度、作品检查和权限。统一视觉不等于把所有功能塞进“实践”。现有团队流程及其确认规则继续有效。
