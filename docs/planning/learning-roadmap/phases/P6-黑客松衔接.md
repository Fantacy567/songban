# P6：从工具学习进入黑客松

依赖：G5给出继续投入依据、旧比赛链路当前可用；估算4–7有效人日，活动组织与赛事核对时间另计。执行S12，S00控制两域接线。

## 产品目标

让孩子把学过的工具用于开放项目与团队协作。学习不是参赛强制前置；有经验孩子仍可直接浏览适合活动。推荐只给理由、可调整，不用年龄/自选等级冒充主办方资格认证。

## 交付

黑客松入口整合原活动与团队实践；活动明确样例/正式、信息来源和更新时间。接入真实赛事前核对资格、日期/时区、地点、费用、赛道、作品规则与提交方式，缺失写待核实。真实报名、对外提交若无集成，只显示明确外部操作和成员录入的回执性质。

孩子主动选择学习作品的确切版本及分享范围，形成带来源的参赛idea草稿。私人学习聊天/家庭报告不自动进入全队；共享学习经历不是团队完成任务。队长与全员仍按原规则决定方向、分工、领取及检查。

角色在参赛场景切回现有团队适配职责，不能将学习的自动建议作为正式团队决定。连接器继续作为可选工具，只有宿主真实加载、上传有note_id并能读回才说成功，安装检查不等于聊天窗口已经可用。

## G6 验收

学习/比赛导航范围清楚；旧书签、历史消息和任务可用；作品带来源不串权限；跨家庭/队伍/私聊访问拒绝；学习过关与团队进度独立；方向确认、投票及人工动作未被Agent代办。正式赛事信息和外部提交另有核验记录。

## 不包含与回退

不承诺自动赛事报名、所有Agent加号自动安装、无人值守提交或完成认证。回退切断导入/推荐入口，保留既有参赛草稿和其来源说明；撤销未来分享不能谎称追回队友已读副本。
