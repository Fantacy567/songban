# P7：学校、社区与多班期复制

依赖：学习及至少一轮服务交付有证据，合作方与负责人员明确；若合作包含比赛，还需G6。准备能力估算5–8有效人日，线下培训与观察周期另计。执行S13，具体需求按第一个合作点收口。

## 范围

在一个合作点复制现有课程包，而非先造复杂机构SaaS。活动包包含内容版本、三关任务、工具卡、所需设备、老师说明、支持方式、作品检查、授权流程、报告和故障预案。

后台支持班期/名额、教师分配、签到与支持待办、课程绑定、报告审核及汇总。机构、班期、家庭、孩子、教师作用域明确；学校管理员不自动获得全部家庭私聊或未授权报告，老师离岗/学生转班可撤销访问。

## 交付与G7

换一位受训老师可按说明开展活动，知道卡点处理、何时升级、谁复核报告。合作点完成一轮从报名授权到反馈的服务；记录准备时间、每孩子支持量、完成与退款/投诉、内容变化和复制成本。

共享模板版本与机构个性配置分开，不能改一张教学卡就影响其他班正在进行的课程。多节点/多机构上线前按实际并发、存储和备份要求验证数据库与对象存储，不把开发SQLite试点能力当无限扩展承诺。

合作费用、合同、公开展示授权、学校/社区适用要求由负责人员针对具体合作确认；本规划不代替协议、不自动签约或发布儿童作品。

## 回退

暂停新班报名，保留已报名服务与数据处理渠道；撤销机构/教师访问不得误删家庭作品。一个合作点失败先修课程和运营，不通过增加更多渠道掩盖履约问题。
