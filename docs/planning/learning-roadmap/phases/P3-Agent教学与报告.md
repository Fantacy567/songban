## 范围与用户故事

孩子按任务获得主向导、工具向导、创作教练、检查复盘教练的帮助；工具卡在当前步骤出现，生成结果保存在尝试中。需要时老师接手；孩子完成反思后生成学习报告，审核后家长只读查看。

## Agent 与教学交付

学习专属角色注册、提示词版本、来源投影、必要历史、标签检索和有限建议动作；保留旧工作台角色。逐级提示、示例标记、当前产出引用及帮助事件。不得依靠角色对话数或同模型“多专家同意”判定通过。

模型真实调用接现有服务端传输；课程权益、监护授权、来源访问和预算先校验。预占/结算/unknown核对有持久账本和责任人。错误保留输入及作品；上游结果未知不自动重复生成。fixture、live与replay分别展示。

## 人工待办与报告交付

老师待办含问题、本人任务、获准查看的必要材料、当前版本、认领人、处理期限和反馈。案件可认领/转交/结案，超时能升级。实际值班人员与处理时间未确定不能启用承诺。

报告从作品、检查、修改、解释与帮助生成草稿；每条观察有有效引用。复核人员可退回/修订并保留记录，发布后家长查看不可变快照；可撤销。模型失败不撤销学习成果，重建不重跑孩子实验。私聊和其他孩子信息不得出现在家庭报告。

## G3 验收

四角色职责/读取权限正确；模型资料注入不执行；预算不足/超时/重复请求不重复扣额；实际模型未知不编造；报告引用不存在来源则拒绝；跨家庭和未发布报告不可访问；人工工作与自动检查来源可分辨；报告撤销有效；角色/工具卡更新不修改历史。

运行一条使用虚构资料、真实配置供应商的链路并记录结果，限制调用预算；需已有有效配置和明确可用预算，没有则明确真实联调未通过，不能用fixture补足。未确认模型费用不记零。
