# P1：家庭身份、授权与起点

依赖：G0通过；估算3–5有效人日。执行：S04后端、S05前端，S00串行认证与壳接线。

## 范围与用户故事

家长用现有账号进入管理，建立一个孩子档案和授权；孩子进入受限学习状态，填写年龄段、经历、兴趣、帮助偏好并做一次小尝试。已有信息只补缺失，允许调整建议。原参赛账号与记录不受强制入门影响。

首轮一个家长管理一个学习者即可跑通，但资源仍按家庭/学习者隔离。家长声明、人工核验依据及确认状态分别保存；不声称系统已核验法定关系。真实儿童试点须按已确定流程完成关系/授权，虚构开发数据不用冒充真实记录。

## 实现与交付

后端交付新增关系/同意版本/受限会话/起点数据及增量迁移；前端交付简短起点步骤、草稿恢复、推荐解释和返回管理。复用原兴趣资料仅在合法本人范围，参赛访谈无需重复做。

进入孩子模式撤销该浏览器现有家长管理授权，其他标签旧凭证不能继续管理；前端清旧缓存、停旧轮询并丢弃迟到响应。返回管理需重新认证。无效/过期授权提供可理解恢复，不把清本地状态当服务端撤销。

年龄推荐只影响内容/帮助，不自动形成资格判定。模型问答不可用时保存已填资料，使用明确的保守建议或转人工，不伪造模型评估。

## G1 验收

两个家庭互不可读写；孩子不能购买、核款、改关系或读取队友私聊；角色字段篡改无效；进入孩子模式后旧管理token、旧标签与迟到请求失效；起点刷新/重登恢复；修改偏好不覆盖已发生尝试。旧密码/邮箱登录、访客参赛及原团队入口回归。

## 依赖决策与排除

关系确认流程、授权文本和真实试点责任人在本期结束前收口。暂不做多监护人、多孩子共享、公开儿童主页、身份认证供应商和付费。仅配置“我是家长”按钮不能交付。

## 回退与交接

关闭学习入口保留新增关系与同意记录；不恢复已撤销的旧高权限会话。交接迁移版本、权限矩阵、认证入口、已验证恢复路径及未决项到S06/S07。S00记录G1证据后启动P2。
