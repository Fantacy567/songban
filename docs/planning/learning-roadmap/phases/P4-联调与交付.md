# P4：新旧系统联调与试点交付

依赖：G3通过；估算2–4有效人日，真实试用等待另计。执行S10独立验收、S00集成与修复。

## 范围

将独立学习模块接入统一壳，按功能开关启用“AI学习／黑客松”。保留原哈希链接、导航去向和账号数据，首次用户有起点、回访用户可继续。家长和后台使用自己的受限入口。

完成单课端到端、失败恢复、原比赛全流程回归、样式隔离、迁移/备份恢复及运营故障处理演练。真实孩子试用需先满足授权和负责人员条件，研发虚构走查不代替儿童观察。

## 交付

版本化代码/资源/内容清单、测试报告、已知问题、模型实测与未测范围、数据库迁移与恢复步骤、老师操作说明、试点名额与服务能力假设。学习开关、日志脱敏/保留、预算告警、问题联系渠道清楚可查。

报告先列真实问题，再列通过证据。不得把历史测试数字当本次全量结果；保留失败日志和修复后重跑范围。独立验收会话以报告为主，业务修复由S00分配避免冲突。

## G4 验收

一个家庭完成授权→孩子起点→三关→作品修改→检查→复盘→老师复核→家长报告；两个家庭隔离；孩子态无法使用旧管理凭证；模型失败、unknown、重复/冲突、重启均恢复；390/768/1440和200%缩放、键盘/减少动效通过；原选题、成员确认/投票、队长定向、分工发布、任务领取/检查、交付复盘未退化。

SQLite备份可实际恢复到隔离副本，旧记录可读。演示页、真实服务、临时公网/正式域名如分别存在需逐项验证，不把localhost通过称为公网已通过。生产发布需具体目标与现有授权，未获发布任务时只交付可审阅结果。

## 阻塞项

高权限残留、跨家庭、丢作品、假成功、重复扣额、无负责人unknown/人工待办、报告泄露不能带入真实试点。次要排版问题可登记负责人和修复期，但须不影响关键行动和儿童理解。

## 回退与下一期

关闭学习入口或回退应用版本，保留新增数据及必要只读/核对能力。禁止清库回退。G4通过、报价/运营规则冻结后启动P5，不宣称付费需求已经成立。
