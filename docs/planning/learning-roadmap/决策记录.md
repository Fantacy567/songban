# 决策记录与待决事项

日期：2026-11-02。

## 已确认的产品方向

D01：AI工具学习和黑客松分开，黑客松属于下一阶段，不能将两者全部堆进实践。

D02：覆盖零基础和已有AI经历的孩子；首次了解年龄并提问，小尝试补充依据；年龄不等于能力。

D03：儿童界面要口语、明确指引；每页知道做什么、怎么开始、做完去哪，保留当前品牌风格。

D04：三关四Agent作为MVP，先跑通、再验证首批付费、后复制学校社区；人工兜底，暂不追求全自动。

D05：本轮要求完整规划、宪法、UI与按工期拆文档，并分会话执行；首期开三个互不覆盖文件的P0规格会话。

D06（新增）：学习访谈结束并本人确认后，在身份和课程条件满足时直接进入为孩子定制的创作工作台，指导完成第一个小作品；已有作品优先继续。首作前不强制经过课程大厅或另一套完整问卷。

D07（新增）：AI学习和黑客松使用独立一级入口。原比赛书签及选题、确认、投票、任务、复盘流程保持可用；有经验用户可以直接参赛，不必先完成学习。

D08（新增）：后续增加带图课程大厅，课程卡展示实际支持的作品示例、目标与学习状态。当前先做首作闭环，课程数量及新的作品类型按教学内容逐步扩展。

D09（采用的设计约束）：儿童工作台以步骤、松伴对话和预览组织，孩子默认面对一个松伴，内部按任务协调四个职责。首作工程默认复用邀请卡；“类似Codex”不扩展为终端、任意代码执行或外部Agent安装。

D10（本轮交付）：用户确认“写规划宪法”，交付E0–E4分期文档及UI、兼容、会话任务。只更新文档，尚未实施新界面、启用入口或派发新会话；暂不开售和既有模型预算范围保持不变。
