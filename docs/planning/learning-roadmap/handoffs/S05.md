## 挂载接口与中央接线

ES 模块导出 `mount(host: HTMLElement, options?: MountOptions): MountHandle`；IIFE 同时提供 `window.SongbanLearning.mount`。

```ts
type Route = '#/family' | '#/learn' | '#/learn/start';
interface MountOptions {
  initialRoute?: Route;
  onRouteChange?: (route: Route) => void;
  onIdentityBoundary?: (reason: string) => void;
  onSessionChange?: (session: Session | null) => void;
  onUnmount?: () => void;
}
interface MountHandle {
  navigate(route: Route): Promise<boolean>;
  canLeave(): Promise<boolean>;
  revalidate(): Promise<void>;
  unmount(): void;
}
```

`onIdentityBoundary` 是中央旧状态清理的接点：S00 在回调中同步停止旧轮询、卸载旧工作台、清旧身份私有缓存及旧凭据。模块不读取 studio-token，更不会用它交换或恢复管理身份。回调不能承担服务端撤销/fence；后端仍须完成全部旧接口限制。`onSessionChange` 只用于清理/呈现，不能让旧壳据此自行签发权限。

`navigate` 在有未保存内容时返回用户选择结果；`onRouteChange` 只在允许导航后通知壳。壳不要先改 hash 或重建 DOM 再询问模块；外部比赛跳转先 `await handle.canLeave()`。`unmount()` 是同步强制销毁，幂等，取消请求/解绑事件/关闭 BroadcastChannel；不自动弹离开提示。壳主动卸载前应先调用 canLeave，身份失效强制卸载则立即清理。不要让旧两秒轮询重建学习根节点。

## API 消费者映射

以下均为实现中使用的**完整地址模板**，不是声称真实服务已注册；所有读 `cache:no-store`、`credentials:same-origin`、`redirect:error`，写 JSON 加 `X-CSRF-Token`，不含 Authorization。

- `GET /api/learning/v2/session-bootstrap` → `bootstrap`；取得匿名/当前绑定的 CSRF 与 browser_revision。
- `GET /api/learning/v2/config` → `config`；读取开关、可配置年龄选项和当前授权版本。
- `GET /api/learning/v2/session` → `session`；恢复、身份变更及每个私有资源响应完成后的权威复核。
- `POST /api/learning/v2/sessions/authenticate` → `authenticate`；仅 method=password，request_id/browser_revision/account/proof；密码不写持久存储或日志，不自动重放。
- `POST /api/learning/v2/sessions/enter-learner` → `enterLearner`；learner_id 与当前 session revision，先收起管理内容，结果未知先查 session。
- `POST /api/learning/v2/sessions/logout` → `logout`；当前 session revision，不恢复旧权限。
- `GET /api/learning/v2/families` → `listFamilies`；成功空列表才出现创建入口。
- `POST /api/learning/v2/families` → `createFamily`；只传 request_id；family_exists 后只读恢复。
- `GET /api/learning/v2/families/{family_id}` → `getFamily`；从本人服务端列表取得 ID。
- `POST /api/learning/v2/families/{family_id}/learners` → `createLearner`；family revision、称呼、age_band=null、关系声明。年龄由孩子起点另填；不提交 verified。
- `GET /api/learning/v2/learners/{learner_id}/profile` → `getProfile`；孩子模式仅消费 LearnerSelf。
- `GET /api/learning/v2/learners/{learner_id}/consents` → `listConsents`；读取所有游标页，以 effective_scopes 呈现现行范围。
- `GET /api/learning/v2/consent-texts/{consent_version}` → `consentText`；当前与每条历史记录的确切版本，核对 hash；不自行编写条款。
- `POST /api/learning/v2/learners/{learner_id}/consents` → `createConsent`；learner revision、确切版本、显式勾选 scopes 与 acknowledged=true。仅 verified、approved_for_pilot、acceptance_enabled 和开放开关同时满足才出现确认表单。
- `POST /api/learning/v2/consents/{consent_id}/revoke` → `revokeConsent`；本人记录 revision 和显式原因。入口关闭时仍可撤回。
- `GET /api/learning/v2/learners/{learner_id}/start` → `getStart`；服务端完整快照与推荐。
- `PATCH /api/learning/v2/learners/{learner_id}/start` → `saveStart`；仅当前主题 answers、request_id、start expected_revision。没有 PUT 或假默认字段。

当前请求数量比简单 GET 多：私有回复完成后再 GET session，即使 BroadcastChannel 不可用也不把旧身份回复放入新页面。S00 联调应评估额外读取成本；若未来契约加入可验证的响应 epoch，可另行优化，不能删掉保护后只依赖本地通知。

身份 epoch/session/id/mode/actor/learner 任一变化时清私有组件与请求代次；401 或 consent_required/child_mode_restricted 也清理并复核。BroadcastChannel 只发变更信号。pageshow（含 bfcache）和重新可见时先隐藏私有 UI 核对身份；同身份保留正在编辑 DOM，身份不同则卸载。核对失败清本地未保存内容，不承诺其可恢复。服务器已保存记录才能跨刷新/重登恢复。

### 已定位的差异

1. 实际 `GET /families` 是符合契约的 `{items:[],next_cursor:null}`。当时合成账号没有家庭，不能把失败归因于列表封装或自动新建家庭。
2. 授权版本 `fiction-only-v1` 原始哈希为 `39eb178cebdd47bfd1024f146fdba5d135fd7c814ead2a2846a11721bced81b6`。后端 `put_consent_text` 校验输入后，用通用 `canonical(...sort_keys=True)` 存储全文；响应中 `scope_purposes` 每项对象的键变成 `purpose,scope`。原前端只重建外层 `locale/title/text/scope_purposes` 的顺序，直接使用收到的内层对象，导致同内容哈希不匹配。已通过真实 API 响应复现原校验抛出 `consent_text_mismatch`；不是跳过校验或补造批准状态来修复。
3. 额外发现 `FamilyPage` 的 effect cleanup 把 `alive=false` 后，在 config.consent_version 改变或 StrictMode effect 重放时没有重置。即使读取成功，新的结果也不能落入状态。直接重新置 true 又可能接受上一代迟到读取，因此同时加读取代次。

### 修复内容

- `consent.ts`：重建用途对象为 `{scope, purpose}`，与冻结0.2.1示例一致；保留数组原顺序，仍核对确切版本、正文、用途和原 SHA-256。对象键排序不再影响校验，正文/用途/数组顺序变动仍拒绝。
- `FamilyPage.tsx`：effect 每次 setup 恢复 alive；reload 捕获读取代次，cleanup 使旧代次失效。只允许最新有效读取更新成功、错误和加载状态，防止旧配置读回覆盖新配置。
