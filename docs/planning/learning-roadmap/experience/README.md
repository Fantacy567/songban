## 已确定的体验

松伴提供“AI 学习”和“黑客松”两个独立一级入口。学习侧在访谈总结经本人确认后，进入为孩子定制的创作工作台：松伴给出一个可开始的任务，孩子边交流边完成第一个小作品。现已接入带作品封面的课程大厅，供孩子查看当前课程和继续创作；更多课程随内容验收逐步增加。

首作工作台借鉴对话与预览并排的组织方式，保留松伴的米白、紫色和小松树。面向孩子展示一个松伴，内部四个职责按任务协同。作品由孩子选择、查看、修改和确认，生成成功不自动表示学会或完成。

## 按工期实施

1. [E0 方案与契约收口](phases/E0-方案与契约收口.md)：约1–2有效人日，明确入口意图、身份衔接、对话事件及首作范围。
2. [E1 双入口与首课直达](phases/E1-双入口与首课直达.md)：约2–3有效人日，学习和比赛分别恢复，访谈不再把学习用户送去选比赛。
3. [E2 儿童创作工作台](phases/E2-儿童创作工作台.md)：约3–5有效人日，将已有课次、作品和角色帮助接成对话与预览工作区。
4. [E3 首课验收与交付](phases/E3-首课验收与交付.md)：约2–3有效人日做工程验收，儿童试用与教研反馈等待另计。
5. [E4 带图课程大厅](phases/E4-带图课程大厅.md)：约2–4有效人日做目录能力，新增课程内容制作另计，依赖首作闭环通过。

E0–E3预计8–13有效人日，含E4预计10–17有效人日。这是熟悉现有代码前提下的增量估算，不是日历交付承诺，也不把并行会话数直接换算成人数。这是实施前估算；当前实际工程结果及余下真人验收见交付报告，不能将测试运行耗时等同人日。

## 与已完成工作的关系

P1–P4的身份、三关、作品版本、模型运行、复核和报告仍作为底座；本轮不重建这些业务。新学习页已在独立开关下提供步骤、对话、预览工作区；旧布局继续保留。首课直达、合法身份和版本/报告链路已有隔离后端页面证据，详细范围见实施报告。

近期动态访谈已改为目标5～6题、上限8题，并接入提前结束及旧长访谈兼容；E1已按明确入口衔接学习。访谈原修复和P4历史通过数不计作本轮新功能验收。

P5-A服务范围保持“按已确认范围准备，暂不开售”；本轮优先推进体验，不顺带实现或开放付款。P6仍指本人作品向比赛的受控衔接，不是原比赛功能必须等到P6才可用。P7学校社区复制继续保留为后续阶段。
