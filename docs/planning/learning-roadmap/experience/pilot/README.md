# 儿童试用与教研执行资料

编制日期：2026-11-02。状态：可填写模板；尚未开展本资料对应的真人儿童观察，尚未取得教研签署，尚未落实真人排班。模板齐全不表示获准开放试用。

这套资料用于首课“班级活动邀请卡”的小范围观察和复核。孩子按自己的节奏完成作品，家长可以陪伴，观察员记录发生了什么，教研根据作品和过程决定需改哪里。首课仍是三关：说清要求、生成保存、检查改进与小迁移；不要求组队、参加比赛或安装连接器。

## 使用顺序

1. 产品和教研先填写[教研审阅清单](02-教研审阅清单.md)，确定本轮材料、表达、参与范围和观察目标。未解决项逐条给出处理人及复验条件，不先填写“通过”。
2. 现场负责人填写[真人支持排班模板](03-真人支持排班模板.md)，明确可联系的本人、获准账号、服务时段、期限和替补。按[异常升级与撤回处理](04-异常升级与撤回处理.md)完成一次成人演练。
3. 获准家长完成正式关系与用途确认，孩子愿意参加后，观察员复制一份[单次儿童观察记录模板](01-单次儿童观察记录模板.md)，存到本次批准的受限位置。每个孩子、每次尝试分别记录。
4. 家长或观察员说明“你可以求助、休息或停下来”，让孩子实际操作。记录本人原话与动作；未做、看不清和系统故障如实标记，不替孩子补出完成记录。
5. 教研对照版本和帮助记录审阅 M1–M4。需要补充就只追问具体缺口；作品通过、报告批准、报告发布分别执行。家长只查看获准发布的本人的报告。
6. 结束时说明已保存到哪里、仍待谁处理、下次联系时间、退出和撤回入口。负责人收口本次问题，再决定是否调整下一轮；不把一次试用推成教学效果结论。

## 开始真人试用前逐项核对

以下项目由实际负责人填写状态和证据引用。任一必需项缺失，保持“尚未安排真人试用”；可以继续用成人和虚构资料演练流程。

- [ ] **教研范围已确定**：本轮年龄或表达支持范围、课程/材料/rubric 版本、是否只体验样例或验证真实工具操作，见教研签署记录。年龄不作能力定级，现有候选年龄段不等于招生范围。
- [ ] **身份与同意有效**：正式关系核验流程、获准用途文本版本、家长确认、孩子当下愿意参加均可核对。声明家长身份不等于完成法定身份核验；本资料不是同意书，研发测试文本不能直接用于家庭。
- [ ] **运行环境明确**：本轮网址、部署版本、课程授权、可用设备和恢复方式已由负责人检查。现有 `8897` 是合成资料工程预览，不能直接填入真人资料；本地合成测试不等于真实网址验收。
- [ ] **模型范围明确**：记录 `mock / live / replay / 仅静态材料`。若使用真实模型，需另有获准供应商、用途、次数/额度和结果未知时的核对人；此前 P3 的三次额度已经用完。模拟操作可以观察界面理解，不能据此证明完成真实模型操作目标。
- [ ] **真人支持可接单**：关系、教学求助、作品复核、报告审核/发布、用量核对分别有权限、负责人、期限、替补和可联系出口。没有实际服务能力就不让家庭进入无人负责的等待。

## 给家长和孩子的开场说明

可按本轮真实安排说明，不能把空白项目念成承诺：

“这次用虚构的活动资料做一张邀请卡，不会真的发邀请。你可以先自己试，也可以请松伴或大人帮忙。我们想知道哪一步好懂、哪一步不好找，不是在给你打分。你可以休息或结束，不需要做完才离开。我们只按已同意的范围记录；今天的联系人是【已确认的支持人或渠道】。”

向家长补充说明本轮模式、预计可用时段、是否有录音录像、哪些内容会进入报告。任何一项没有确认，就先由负责人补齐；不得以孩子继续点击代替家长用途确认，也不以家长同意要求孩子继续。

## 资料怎样保存

仓库只保留空白模板和虚构示例。真人填写件、签名、联系方式、录屏及孩子原话放在获准的受限位置，不提交 Git，不复制到普通问题单或公开聊天。用本轮编号与化名关联记录，账号、案件和作品版本只保留完成核对所需的引用。

默认采取观察笔记；没有单独确认的采集方式不使用。记录“孩子口述、成人代录、孩子已确认”与成人给出内容的情况，避免把成人或模型的话写成孩子自己的解释。观察员不能自行决定无限期保留资料或删除正式业务记录；按已批准规则交由有权限的负责人处理，并记录回执。

## 结束时的最小交接

- 孩子实际停在哪一步、是否愿意继续、最后已确认保存的作品/练习版本。
- 本次哪些是本人决定，哪些用了提示、代录或内容帮助，哪些无法观察。
- 作品和报告各自的真实状态；未发布的报告不得说成“家长已收到”。
- 每个待处理事项的负责人、下一次联系时间和出口；退出、撤回或更正请求单独记录。
- 教研本轮结论及适用范围；不签署则仍为待审，不以工程自动化结果代替。
