# 真人支持排班模板

状态：未排班、未确认服务承诺。这里的岗位不是已指派人员；填完姓名也不等于账号获得权限。填写件放在获准受限位置，仓库不保留真人联系方式或密码。

目标是让孩子和家长在卡住、等待反馈、申请更正或撤回时，能找到实际接手的人。依据[老师与支持操作说明](../../p4/老师与支持操作说明.md)，人工求助、关系核验、作品复核、报告校对/发布和用量核对分别处理。

```text

首次回应、教学处理、作品复核、报告复核各自的约定期限：

到期前提醒方式、超时升级去向：
```

时限必须经实际人员确认后再展示，不复制研发测算的小时数。已有服务范围准备不表示开售或有人值班；不承诺“老师在线”“马上回复”而没有覆盖安排。

## 每个岗位分别填写

可以由同一人承担多个获准岗位，但逐项检查权限、容量与替补。实际不具备的职责不能靠共用管理员账号补足。

1. **现场负责人/家庭联络：**开场与结束交接、孩子暂停/退出、支持入口、未接手事项升级。证据为本轮安排及当班确认。
2. **关系与用途处理：**按获准流程核对关系、同意文本与撤回范围，不把自称家长自动视作核验通过。证据为受限核验记录与权限。
3. **教学求助/教研：**按当前任务给适当帮助，记录提示，不替孩子代交或降低 M1–M4。证据为当前材料版本和可受理的教学案件。
4. **作品复核：**核对当前证据和 M1–M4，必要时补问/补练。证据为获分配案件、版本引用和具体反馈。
5. **报告复核：**逐条核对观察、来源与限制，处理孩子/家长更正。证据为确切报告版本和复核结论。
6. **报告发布/撤回：**仅对获准的当前版本发布，必要时撤回并核对读取状态。证据为独立的发布/撤回回执及权限。
7. **技术与模型用量核对：**处理保存冲突、身份失效、未知模型结果及费用证据；不让孩子粘贴密钥或自行付款。证据为获分配案件和受控来源。
8. **资料处理负责人：**受理保留、更正、撤回/删除申请，按获准规则核对范围、权限和完成回执。证据为处理规则版本、请求编号与接手确认。

每个岗位复制一块：

```text
岗位与可处理的案件类型：
主要人员编号/受限联系记录：
本人获准账号与权限核对结果（不填密码）：
覆盖日期、起止时间、时区、可承接数量：
首次回应/处理期限及计算规则：
对家庭展示的联系人或支持渠道：
替补人员编号、覆盖范围与接手确认：
超时或无权限时升级给谁、怎样联系：
仍未覆盖的时段或事项：
主要人员确认方式与时间（未签署）：
替补确认方式与时间（未签署）：
```

## 开始前成人演练

仅用明确的成人演练身份和虚构内容，不能混入真人儿童课程成果。按真实服务角色分别登录；复核后台入口为 `/learning-prep#/learning-admin`，各人使用本人获准账号重新认证。

- [ ] **能收件：**从家庭侧找到支持出口，发送明确标记的演练请求；指定人员实际看到本人的案件。保留受限案件编号和接手时间，不把“已分配”当“已阅读”。
- [ ] **能反馈：**处理人引用相应版本给一条具体反馈，家庭侧能读到且知道下一步。只用后台登录成功不足以支持此项。
- [ ] **能交接：**主要人员模拟无法继续，替补按权限接手；核对期限、版本和此前承诺都被传递。没有替补确认则记录缺口。
- [ ] **能停下：**演练服务不可用时暂停新请求的实际做法，家庭能看到恢复或联系出口，不产生无人负责且无期限的等待。
- [ ] **能处理异常：**走一遍[异常升级](04-异常升级与撤回处理.md)中的未知结果或撤回演练；不要为了演练触发付费模型或真人授权撤销。

```text
演练模式、身份、日期：
案件与证据位置：
实际成功的动作：
失败/尚未验证的动作及负责人：
本轮是否具备接待条件、限制与理由：
现场负责人确认方式与时间（未签署）：
```

## 当班交接与收班

接班人先核对案件版本、权限、期限及当前状态，再明确接手。敏感内容不粘贴到普通排班群；交接只传获准受限引用。家庭已退出或撤回的事项优先说明，不继续生成或发布。

```text
交接时间、交出/接手人员编号：
案件编号、类型与当前状态：
当前作品/报告/同意版本：
已做操作及回执；禁止重复的未知操作：
下一项动作、权限和所需证据：
已对家庭说明的期限、下次联系时间：
新负责人接手确认：
未能接手时的升级去向与时间：
结案依据、家庭可见结果和仍需保留的事项：
```

收班前逐项核对未结案件，通知家庭下一服务时间或升级结果；不得仅因下班标记完成。无法保证后续处理时暂停新的真人试用，由现场负责人重新安排，不以工程测试队列代替真人支持。
