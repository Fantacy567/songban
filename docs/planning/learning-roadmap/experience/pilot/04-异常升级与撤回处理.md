# 试用异常升级与撤回处理

状态：执行模板，实际责任人、联系渠道、期限和数据处理规则待本轮填写。规则未确认前，不接收真人资料。这里描述人工处理步骤，不宣称已有一键删除或对外在线客服。

## 接到问题先做什么

1. 暂停受影响动作，先让孩子知道可以休息；技术故障不算学习失败。不要为留证继续展示不适合孩子的内容，也不要反复点生成、送审或发布。
2. 只记录必要信息：本轮/请求编号、时间、所在页面、最后已确认版本、操作及状态。密码、验证码、密钥、完整私聊不进问题单；截图只在获准范围内采集。
3. 按[排班记录](03-真人支持排班模板.md)找有权限的负责人，明确接手和下一次联系时间。未接手就是待处理，不能称老师已经在看。
4. 负责人核对状态和来源，说明可继续的部分、必须暂停的部分及恢复条件。到约定时间仍无进展，按本轮指定替补/升级去向处理，并更新家庭可见说明。
5. 用可验证回执收口；若结果仍未知，保留未知和下一次核对，不填“成功”“免费”或“已删除”。

## 按异常类型处理

### 孩子不愿继续、疲劳或情绪不适

当场停止任务和非必要采集，允许离开，不追问退出理由或劝其“做完才结束”。可告诉孩子“现在可以停，已经确认保存的内容会按约定处理”。由陪伴家长和现场负责人安排休息或结束；恢复必须是孩子再次愿意，且身份、用途和支持仍有效。

留证：实际停止时间、孩子愿意表达的请求、最后确认保存状态、接手人。不要作情绪诊断或把退出写成能力不足。

### 不理解任务或成人已经给出答案

先区分读不懂、找不到按钮还是需要教学提示，记录具体词句和操作。给获准层级的帮助；若成人/模型提供了具体内容，如实标注，不重置帮助历史伪装独立。教研只安排缺少部分的补问或获准新材料补练。

留证：当前任务、提示原话/等级、本人贡献、需补的 M 项及教研决定。没有补练材料时保持待补，不自动宣告过关。

### 保存失败、断网、版本冲突或回执不明

保留当前页面和允许保存的输入，先核对同一操作及服务端当前版本。不能在未保存状态下随意刷新或切换身份。版本冲突交由本人核对两份内容，不覆盖已保存的新版本；同一操作回执未知不换新操作号反复提交。

留证：最后确认保存的版本、当前未保存内容是否仍可见、同一操作的状态和恢复结果。告诉家庭“目前能确认的是哪一版”；不承诺所有编辑都已保存。涉及授权失效时先服从权限边界，不为保留输入而保留高权限会话。

### 模型失败、结果未知或预算不足

已知失败先核对原因，只有本轮授权和预算允许、本人明确选择后才创建新尝试。`unknown` 交用量核对人员查原运行和预占，不自动重发；不能把未知费用写成零。预算不足可继续看材料和已有作品，由获授权成人处理，孩子不进入付款或凭据配置。

留证：原运行编号、模式、状态、预占/用量核对案件、供应商证据引用、负责人和下次联系时间。报告重建只读既有事实，不能借重建再次运行孩子实验。没有新增额度授权不调用真实供应商。

### 身份、关系、同意失效或误见他人资料

停止敏感读取、写入和展示，转关系/资料处理负责人核对；身份恢复使用本人正常认证，不修改浏览器字段绕过权限，不借别人的账号。看到不属于本家庭的内容时不要复制扩散，技术负责人按既定机制保留必要受限证据并限制受影响入口。

留证：受影响的入口和最小记录引用、停止动作、获准核对结果、恢复条件。负责人按本轮既定程序决定后续沟通，不能把泄露风险当普通页面错误自动结案。

### 生成内容不合适或材料来源不可用

停止向孩子展示和使用该结果，保留允许保存的状态与来源引用，转教研和内容处理负责人。可以继续不受影响且获准的材料阅读；不要为“教学需要”放行被拦内容。材料撤回、丢失或版本对不上时暂停相关检查与报告发布。

留证：受限内容引用、不可用原因、已停止的后续动作和获准替代材料版本；不在普通工单完整复制不适合儿童的文本。

### 作品或报告等待过期、内容有误

先核对真实案件、当前版本、处理人和期限，再转替补或升级。规则绿灯不等于老师通过；批准不等于已经发布。家长或孩子提出事实异议时，报告复核人核对来源；如需撤回，由有发布/撤回权限的人执行并确认读取状态。修订生成新版本并重新审核，不能沿用旧批准发布新内容。

留证：案件/报告版本、原反馈、异议、当前处理人、下一次联系时间、修订或撤回回执。没有足够依据就写待核对，不用能力评价解释系统延迟。

## 退出与撤回处理

“结束今天的练习”“暂停参加”“撤回某项用途”“撤回报告”“申请更正/删除资料”影响不同。接到“不要再用了”这类表达时先停止相关新处理，再由获准负责人确认范围，不以范围尚待核对为理由继续采集、生成或发布。

1. **受理和停止。**记录请求时间、提出者角色和愿意说明的范围；原因可不填。孩子可立即停止本次活动，涉及家庭资料的正式处理由有权限人员按已批准核验流程承接，不要求孩子提交额外身份证明。
2. **说明当前状态。**核对最后保存内容、在途模型请求、待审作品和已发布报告。区分已停止的新动作、仍在核对的在途任务以及必须按规则处理的历史记录；不要承诺已发出的供应商请求可以瞬间取消。
3. **执行权限与可见性处理。**对有效用途撤回，按系统支持和获准流程使对应授权失效，停止相关后续处理并核对报告不可读；仅撤回报告时按对应报告版本执行。相关页面还可读或写时立即升级，不把页面隐藏等同后端失权。
4. **处理记录及副本。**资料负责人根据已批准的保留、删除、更正规则列清本地/服务端/备份及获准外部处理方的实际范围、期限和限制。本模板不承诺自动全量删除；不得擅自删库、改审计记录或把备份设成永久保留。已经下载的副本不能声称已远程删除，按获准程序告知相应持有人处理。
5. **反馈回执。**向获准接收人说明完成项、未完成项、原因、下一次联系时间和再次联系出口。只在实际核对后标记完成；将来的恢复或重新参加需重新核对身份、用途和孩子意愿，不复用失效同意。

只完成部分处理时保持相应待办；“已通知”“已关闭页面”或“已交给技术”不是解决回执。共用环境的暂停、恢复和备份操作由技术负责人依据[发布与恢复手册](../../p4/发布与恢复手册.md)执行，不由家长或观察员修改配置。
