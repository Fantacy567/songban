## 试用前审阅

### 1 课程目标与负担

- [ ] 目标明确到孩子的动作：选事实、区分候选与保存、找回版本、判断、修改、解释和换材料；未把生成次数、漂亮程度或对话长度当掌握。**查看证据：**当前任务卡、课程目标与通过条件。
- [ ] 本轮年龄/阅读支持范围由教研确认，年龄不自动判能力；朗读、代录和休息可用。**查看证据：**实际页面字号与措辞、拟用设备试走、帮助与代录记录方式。成人觉得容易不等于孩子理解。
- [ ] 时长作为待观察项记录，暂停不受惩罚；未把规格的时长初值变成效果或服务承诺。**查看证据：**本轮安排、开场说明、可暂停和恢复的真实操作。
- [ ] 访谈确认后能进入作品；旧记录可恢复，不再强迫完成第二套长问卷。**查看证据：**按获准身份实际入口走一遍，记录页面和缺失条件。

### 2 材料与表达

- [ ] A 为松果班故事交换会，B 为星叶班纸桥挑战；活动对象、日期、起止时间、地点和准备物品与获准材料版本一致。**查看证据：**材料卡与实际字段逐项对照；答案依据见[首课规格](../../p0/首课教学规格.md)，不把教研答案发给孩子。
- [ ] 页面说明是虚构活动，不补真实学校、电话、费用、报名链接或材料外承诺。**查看证据：**课程卡、材料、模型候选和作品预览；正文中的语义矛盾也检查，不能只看结构字段全绿。
- [ ] 示例封面、错误样例、候选、未保存编辑、已保存版本有清楚区别。**查看证据：**逐一打开对应状态，让观察员指出区别；真人理解留待观察，不先签结论。
- [ ] 邀请卡是固定纯文本模板，本课不要求孩子运行任意代码或安装外部工具。**查看证据：**任务卡和真实操作；不将“类似 Codex”误解成桌面控制能力。

### 3 提示与本人贡献

- [ ] 一个“松伴”入口围绕当前任务提示，能逐级请求帮助；内部角色、模式、来源和 H1–H3 可追溯。**查看证据：**一次实际提示及其保存记录，刷新后仍能核对。
- [ ] 首先提问或给操作骨架，局部示例明确标注，不提前提供迁移整题答案。**查看证据：**提示卡、实际帮助内容、材料投影；审阅用答案未进入孩子界面。
- [ ] 成人朗读/操作/忠实代录与提供内容分开，孩子可以确认代录；不以 H0 宣称无人帮助。**查看证据：**任务帮助披露与[观察记录](01-单次儿童观察记录模板.md)的填写方法。
- [ ] 发生具体答案提示后有可执行的补练方案：指定谁准备和审核新的版本化材料；尚无方案时保持待补，不让模型临时编题充当未提示测验。**查看证据：**补练材料版本、审核记录及使用条件，未备齐就记录缺口。

### 4 判断、改进与迁移

- [ ] 自查先保存具体字段、判断及材料定位，规则预检不会被显示成已经送老师。**查看证据：**当前自查引用、预检回执、送审状态。
- [ ] 有原/新作品、实质变化、本人理由和帮助记录；事实都正确时允许改善表达，不故意改错孩子的结果。**查看证据：**两个确切版本和修改说明，区分内容改进与只换空格/标点。
- [ ] B 重新选事实、写邀请语并解释至少两处变化；A 的旧答案和旧检查不替代 B。**查看证据：**材料 B、迁移记录的 revision、变化解释与帮助。
- [ ] 修改后只审当前证据，历史作品和反馈仍保留；服务故障单独记录。**查看证据：**当前版本、检查绑定来源与历史读取，不用错误数量给孩子贴能力标签。

### 5 人工反馈与报告

- [ ] 送审前确有获准真人、期限和联系出口，预检不派单，送审回执不明确时不称已交老师。**查看证据：**本轮[排班记录](03-真人支持排班模板.md)、真实案件/负责人/期限，不引用合成复核员。
- [ ] 老师对 M1–M4 各项记录依据，证据不足可补问或补练；没有自动按按钮全过。**查看证据：**获准复核账号的本次案件和具体反馈。
- [ ] 报告观察能定位到本人作品、解释、帮助和确切版本；模拟/回放/真实分别标识，不作人格诊断、天赋认证或年龄排名。**查看证据：**每条报告文字及其 source 引用，未知内容写未知。
- [ ] 孩子核对事实、明确送审、人工批准和发布是分开动作；家长只读获准发布的本人快照，撤回后不可继续读取。**查看证据：**对应状态与回执，复核/发布人分别确认；在演练环境验证撤回，不为检查随意撤销真人授权。

## 真人观察后的 M1–M4 复核

复核人对每项填 `supported / needs_practice / unclear`，附确切来源。下面是观察口径，不预填结果，也不代替后台获准人员签署。

- **M1 信息可用：**对照材料，活动事实正确，标题和邀请语无无依据承诺；读者能理解安排。证据为要求、当前作品、材料及相关原话。缺项时指明对应字段和材料位置。
- **M2 判断与操作：**孩子指出至少一项核对依据，能区分生成候选和已保存作品。证据为本人短答、自查、保存与同版回读；只有点击记录时补一个具体问题，不重新做长访谈。
- **M3 修改与解释：**孩子至少提出一次实质修改，理由与前后差异有关。证据为旧/新版本、本人理由及帮助；成人代录可说明，整句代写或照抄不算本人提出，不明确则保留 unclear。
- **M4 小迁移：**在 B 中重新选择事实，本人提出邀请语，解释至少两处变化及为何不能直接沿用 A。证据为 B、迁移 revision、解释与帮助；有内容帮助时如实记录，另安排获准补练。

```text
复核项 M1 / M2 / M3 / M4：
结果（待审时留空）：
本人行为与必要原话：
确切材料/要求/作品/自查/迁移/帮助引用与版本：
成人、模型、示例对结果的帮助：
本次证据支持什么；仍不能判断什么：
一个具体补问或补练（需要时）：
获准复核人确认方式与时间（未签署）：
```

规则证据齐备、M1–M4 均 supported 且获分配人员签署当前版本，才可按正式流程判本轮通过。一次本课通过不证明孩子已普遍掌握 AI；作品通过不等于报告已发布。
