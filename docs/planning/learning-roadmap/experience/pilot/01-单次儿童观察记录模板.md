# 单次儿童观察记录模板

状态：空白待填写；没有发生的动作保留“未观察”。每次试用复制一份到获准的受限位置，不把真人填写件提交仓库。由观察员记录，孩子可口述，不要求孩子填写这张表。

## 开始前

```text
本轮/本次编号：
日期、实际开始时间、时区：
孩子化名（不填真实姓名、学校或精确生日）：
本轮获准的年龄/表达支持范围；本人选择的帮助方式：
观察员与陪伴成人的受限人员编号：
设备、屏幕/输入方式、是否朗读或代录：
实际网址、交付版本、课程/材料/rubric 版本：
本次模式：mock / live / replay / 仅静态材料 / 待核对
关系与用途确认记录编号及版本：
孩子当下是否愿意参加：愿意 / 想先了解 / 不愿意 / 未确认
允许的记录方式及范围：笔记 / 截图 / 其他已明确获准方式
资料保存位置及处理规则版本：
现场支持出口、可服务时段、下一位接手人：
```

关系、用途或孩子意愿未确认时不开始收集学习过程。先按[开场说明](README.md#给家长和孩子的开场说明)告知可以求助和退出；不把录屏作为必需条件。成人试走和合成身份试验另记为演练，不计入儿童观察。

## 怎样记录每一步

先让孩子按页面尝试。若卡住，先问“你现在想做什么？”；需要帮助时记录帮助内容，再继续。不要为了完成率抢先指出正确答案，不故意篡改孩子作品制造错误。

每一步记录结果为：`本人完成 / 有帮助完成 / 尚未完成 / 服务故障 / 主动暂停或退出 / 未观察`。这些不是分数，不把“有帮助”算失败。帮助分开记：

- 系统帮助：实际显示的 H0/H1/H2/H3、提示内容与来源；未取得记录就写未知。H0 不证明没有线下帮助。
- 成人帮助：朗读、操作定位、忠实代录、提问引导、给出具体内容或不确定，可多选，并写实际说了什么。
- 本人贡献：孩子自己选择、判断或修改了什么。代录后请孩子确认意思，不能把成人组织的句子标成孩子原话。

下列动作可按实际课次顺序拆开记录；中途停止不补写后续项目。

### 1 从访谈进入作品

让孩子按当前页面进入或继续学习，观察能否理解“开始我的第一个作品／继续我的作品”。课程大厅出现时，观察能否分清示例封面与自己的作品。不要为试用重置已有访谈，或让孩子重复填写整套起点问答。

证据：孩子指出将要做什么的原话、实际进入的页面、是否重复问答、卡住位置与成人解释；不能只记“登录成功”。

### 2 说清邀请要求

请孩子读虚构材料 A，选择对象、时间、地点和准备物品，再选目的与语气并确认。能读到材料但不理解时，记录具体词句；不会打字时可忠实代录。

证据：确认要求的版本、对应材料位置、本人选择或填写的动作、预设选项和自写的区别。不能以填满所有字段推断理解。

### 3 生成候选并保存

按本轮获准模式尝试生成，观察孩子如何决定是否采用候选、如何保存。只做模拟体验时说明模拟身份；不追加未获准的真实调用。

证据：运行模式、生成输入/候选引用、孩子对“还没保存”或“已保存”的说明、保存回执和版本。请求失败或结果未知单独记故障，不要求连续点生成来完成观察。

### 4 找回同一份作品

在确认保存成功后，让孩子使用页面正常入口重新打开作品。可问“刚才保存的那一张在哪里？”不要先替孩子点到答案。

证据：打开的作品版本、本人明确确认的动作、孩子如何辨认它。自动预览、浏览器预取和观察员代点不算孩子找回。

### 5 对照材料判断

让孩子任选时间、地点或对象，指出材料哪一处支持自己的判断。事实都正确时可以说相同；需要错误样例时，只用课程中明确标记的练习卡。

证据：自查字段、判断、材料定位和原话；分清“在自己作品中发现问题”和“在预设错误样例中找到问题”。规则全绿不替代孩子解释。

### 6 亲手改一处并解释

请孩子选一处想改的内容并说明理由。若事实无误，可以把邀请语改得更具体。不要直接给出整句再让孩子照抄，若已经给了内容帮助就如实记录。

证据：旧/新版本、具体前后变化、是谁提出修改、理由和帮助来源。仅改空格或标点不记为有意义的修改；无法判断本人贡献时保留待教研追问。

### 7 换材料再试

打开材料 B，让孩子重新选择事实、写一句邀请语，说出与 A 至少两处不同。不要把 A 自动填进 B，不展示教研答案。

证据：B 的版本、迁移记录、两处差异解释与帮助。如果成人或模型已经给出答案，写“有内容帮助”；由教研决定是否另备获准材料补练，不以重复同题证明独立迁移。

### 8 检查和交给老师

让孩子保存自查、修改、迁移和复盘，区分“检查我的结果”和明确“交给老师看看”。若停在等待，查看谁处理、何时反馈以及怎样回到作品。

证据：当前版本、预检结果、真实送审状态和案件引用、页面显示的期限与支持出口。只看到检查绿灯不能记已送审；未配置真人支持就停止此项。

### 9 结束和恢复

询问孩子是否愿意再继续，或先休息。若安排恢复体验，只在已确认保存后离开再回来；不要为了测试刷新未保存输入。

证据：实际结束原因、最后保存版本、恢复后落点、找不到或丢失内容、孩子的一句感受。报告生成和发布另记真实状态，未观察到家长读取就不代填。

## 逐步观察记录块

每发生一次卡点、求助或完成动作，复制填写一块。只记必要原话，不记无关家庭聊天；未获准截图时用页面名称、字段和版本定位。

```text
观察项目编号/页面/当前任务：
开始与结束时间；实际操作、等待、休息时长分别记录：
给孩子的原始指令：
孩子实际做了什么；必要原话：
结果：未观察 / 本人完成 / 有帮助完成 / 尚未完成 / 服务故障 / 暂停退出
系统模式、帮助等级、来源引用：
成人实际提供的帮助及孩子是否确认代录：
本人选择、判断、修改的具体证据：
材料/作品/练习/检查/案件引用与版本：
问题：任务看不懂 / 操作找不到 / 服务故障 / 需要教学帮助 / 其他
卡点位置和复现条件：
观察员做了什么；是否改变后续观察条件：
仍不清楚什么；交给谁核对：
```

## 暂停、退出、撤回或更正

孩子表示不想继续、明显疲倦或需要休息时立即暂停，不以“再答一题”交换退出。仅在其仍愿意且有权限时核对最后保存状态；无法保存就说明哪些尚未保存，不承诺自动恢复。家长提出撤回或记录更正时转[撤回处理步骤](04-异常升级与撤回处理.md#退出与撤回处理)，不要求孩子解释原因。

```text
状态：未发生 / 暂停 / 结束本次 / 撤回用途 / 申请删除 / 申请更正
提出时间、提出者的角色（不写额外身份资料）：
本人原话或请求范围（可不说明原因）：
已停止的采集/生成/送审/发布动作：
最后确认保存的内容；尚未保存或无法确认的内容：
受限请求编号、接手人、下一次联系时间：
权限、报告及资料处理的核对回执：
尚待处理内容与原因：
```

## 结束后交给教研

```text
本次实际观察到的内容：
没有观察到的内容及原因：
孩子本人贡献和获得的帮助：
最影响使用的一个卡点及证据：
服务故障与学习理解问题分别是什么：
孩子愿意继续/不愿意/未询问；本人原话（可选）：
作品状态、报告状态、待办负责人及下一次联系时间：
观察员记录确认方式与时间（未签署）：
教研收件确认方式与时间（未签署）：
```

教研结论另填[审阅清单](02-教研审阅清单.md)。观察员不因“流程跑完”签署 M1–M4 通过，不推断天赋、人格或总体学习成效。
