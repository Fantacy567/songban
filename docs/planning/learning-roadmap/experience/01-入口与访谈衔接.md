# 入口与访谈衔接

版本：1.0.0；日期：2026-11-02；状态：待实施。依据[宪法C1、C2、C5、C11](../01-项目宪法.md)。

## 首页与一级导航

保留现有品牌动效及统一登录。首页以两张清楚的大卡片提供“AI 学习：学着做出自己的作品”和“黑客松：和伙伴完成挑战”。应用一级导航使用“AI 学习／黑客松”，当前入口同时以文字和选中状态表示。

原活动、实践、队伍、连接器和赛事资料归黑客松上下文；学习的步骤和工具不再放入比赛“实践”的二级菜单。账户主体共用，学习作品、团队资料、家长报告的访问范围继续分别验证。

首次选择记录目的地；回访显示上次有权限继续的作品或比赛。显式点击和已有书签优先于“上次访问”，打开比赛链接不会被推荐课程强制改写，打开作品链接不会丢掉作品ID。

## 首次学习故事

1. 用户选择AI学习，确认需要的账户及学习身份准备。面向孩子的学习身份进入前，相关家庭关系和用途同意须有效。
2. 简短访谈了解兴趣、经历、想做什么和帮助偏好。已有本人信息可供确认后复用，不再强制重复全部问题。
3. 本人查看总结，可修改或暂时采用保守提示。主要按钮显示“开始我的第一个作品”；已有可恢复课次时显示“继续我的作品”。
4. 课程条件满足后进入创作工作台，打开当前任务和作品预览占位。首次不绕到课程大厅，不要求选比赛或建队。
5. 松伴介绍本次可做的作品与第一个小动作。孩子选择开始；不因进入页面便自动生成作品或消耗真实模型额度。

首作推荐必须来自已发布且当前可用的课程。只有邀请卡一个可用主题时，说明“先试着做一张邀请卡”；可改变卡片表达或稍后再做，不提供实际不存在的“随机换课”。访谈中的游戏兴趣可以用于措辞，但不能承诺本课将生成可运行游戏。

## 资料与问答复用

前一轮访谈确认和学习起点是不同记录。复用前展示要带入的本人兴趣、经历、目标与帮助偏好，孩子可更正；学习侧保留来源、版本和确认方式。年龄不自动转换为能力等级。

新版起点原有六主题仍可供主动调整，不能在访谈后再次成为整套必答问卷。小资料卡理解可作为首课第一个小任务；未回答的主题保留未知，不为打通路由写成已回答。没有足够信息时采用可修改的逐步提示。

访谈通常5～6题，最多8题，可提前结束。旧第17题等历史会话直接进入总结流程，保留已保存文字。访问页面不得自动调用模型总结；必须由本人点击结束或提交最后一题触发。

## 准备未完成时的出口

- 未认证：完成认证后回到刚才的学习目的地，保留允许保存的草稿。
- 家庭关系或同意待处理：显示具体缺项及家长/工作人员入口，不自动建立关系或同意；回到孩子态时仍需合法会话。
- 没有可用课程或权益：说明课程尚未开启、谁可帮助处理，并提供已获准的演示入口或返回；不把“点开始”当作已付款或已授权。
- 模型不可用：已准备好的教学提示和已保存作品仍可访问；模拟模式明确标注，由用户选择，不静默用假结果替代真实请求。
- 有多个有效课次：优先恢复用户指定的课次；否则展示少量“继续哪件作品”选项，不擅自开新课次。

这些准备区应集中呈现，在完成后自动回到原目的地；不能把孩子反复送回登录页或完整问卷。

## 黑客松和回访用户

显式进入黑客松继续原比赛访谈/确认、赛事、组队与协作流程，不要求先完成AI课程。学习信息只有本人选择后才用于参赛介绍；原始对话不自动进入团队资料库。

已有学习用户恢复服务端最新的可访问课次和作品版本，原检查、帮助和老师反馈同时可找回。待老师反馈时显示预计处理情况和可做的下一件事，不伪造过关。已有比赛用户继续原比赛，不因新导航强制重做档案。

从学习切到黑客松时，退出孩子受限会话及是否重新认证以现有身份边界为准。未保存作品必须提示保留/保存/取消，不能仅切导航就丢失内容。

## 路由和启用

继续复用`/learning-prep`挂载学习应用、`#/learn/run?id=...`定位课次、`#/learn/works`定位作品；`#/onboarding`、`#/interview`及现有比赛哈希不直接批量改义。入口意图和确认后去向由E0形成兼容契约，再由E1统一接线。

本机演示与真实账号服务分别配置启用范围。演示身份和比赛连接器绑定不能转换为真实家庭权限。无需为了此改造清空8894/8895的数据或新增大量常驻端口。
