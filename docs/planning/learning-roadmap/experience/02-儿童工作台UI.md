# 儿童创作工作台 UI

版本：learning-studio-ui 1.0.0；日期：2026-11-02；状态：已定产品方向，待原型和实现验证。此文替代旧UI规划中当前任务表单上下堆叠、四角色手动选择作为默认入口的目标布局；历史验收不改写。

## 孩子进入后看到什么

顶栏显示作品名、当前步骤、保存状态和退出入口。主内容围绕“我的作品”“和松伴聊”“作品预览”组织，让孩子知道现在做哪一步、作品在哪里、下一步点什么。

首次首屏由松伴给出简短欢迎和一个小任务，例如：“我们来做一张故事交换会邀请卡。先看看资料，你想邀请谁？”旁边显示空白作品结构或明确标注的示例。正式作品在孩子保存后产生，示例不进入作品列表或报告。

已有作品则优先打开当前版本和下一步建议，不重播欢迎、不清空对话、不重新生成候选。

## 桌面排版

- 顶栏沿用松伴品牌与“AI学习／黑客松”一级入口，在学习内部清楚标出当前作品。
- 左栏约占工作区18%：当前作品与三步导航“想一想／做出来／改一改”；对应现有说清要求、操作与保存、检查改进三关。完整作品列表按需展开。
- 中间约占40%：松伴对话、当前一个任务卡、输入与帮助按钮。模型原文可展开，不能把长回复直接铺满第一屏。
- 右侧约占42%：当前候选或已保存作品预览，以及与当前动作相关的编辑入口。材料作为可展开参考，不常驻第二排大型面板。

上述比例为原型起点，不是固定像素实现。工作区使用可伸缩网格；平台导航在学习工作台中收敛为顶栏或紧凑入口，避免外层左栏加内层左栏造成多重导航。家长管理和工作人员后台沿用各自页面，不放在孩子三栏里。

## 平板和手机

1440px展示三栏；宽度不足时先把作品步骤收为可展开目录。768px按实际可用宽度选择双区或切换视图，不强行保留三个窄栏。390px使用“和松伴聊／看我的作品”两个标签，当前步骤仍常驻可见。

切换标签不卸载未保存草稿；生成后提示可去查看作品，不能抢走正在输入时的焦点。输入法打开后，输入框和发送按钮可到达；不用遮住文字的固定气泡。控件触摸区至少44px，正文建议16–18px，支持200%缩放、键盘、焦点恢复和减少动效。

## 对话中的教学

孩子默认只看到“松伴”。内部根据当前任务选择主向导、工具向导、创作教练或检查复盘职责，帮助记录保留实际角色与提示版本。角色切换不要求孩子配置模型、选择Agent或重复介绍背景。

每个回合围绕一个可执行动作：提出目标、选择要求、运行工具、查看候选、修改、核对或解释。输入框附近提供“给我一点提示”“看看局部例子”“我想自己试试”；展开示例后记录帮助，不把参考示例记作独立完成。

对话可承载选择卡、局部字段编辑和操作按钮，但自由文本本身不直接写入作品、确认要求或判定过关。用户明确点击相应动作后复用既有写接口；修改前展示受影响内容，不让Agent静默改掉整张作品。

首作邀请卡仍需本人确认必要的对象、时间、地点等事实。界面可分步选择、对照高亮或局部编辑，避免一次出现全部长表单；不能为了省输入自动勾完事实、帮助声明或自查结论。

## 预览与作品保存

预览明确区分“示例”“AI生成候选”“我的已保存版本”“未保存修改”。当前固定模板只渲染允许字段，模型文字不作为HTML或脚本执行。

孩子可先预览再选择保存，随后亲手改一处并说明理由。保存成功显示服务端返回的版本；失败保留输入。回到上一版表示选择历史查看或明确另存新版本，不覆盖历史或复用旧检查。

首作继续沿用现有保存回读、自查、小迁移和复盘要求，将这些动作组织在“改一改”里。三步视觉不等于只有三次点击，聊天数量也不作为完成进度。最终送老师、老师复核、报告生成与发布分别显示实际状态。

## 每个状态都说明下一步

- 准备好开始：一个主要按钮“开始我的作品”。
- 正在生成：说明正在做什么，允许保留输入，禁止重复发送同一操作。
- 有候选：主要动作“看看这一版”，再决定保存或修改。
- 有未保存修改：突出“保存我的修改”，离开时可取消或明确处理草稿。
- 结果未知：显示“这次结果还在核对”，保留查询和支持入口，不自动再次调用。
- 无额度或真实工具不可用：说明可做的静态练习及求助入口，模拟结果保持明确标记。
- 检查需要补充：指出具体缺项与可操作位置，不把孩子标成失败者。
- 等待老师：展示真实负责人、预计时间和联系办法；没有接收成功不显示“已交老师”。
- 本课完成：展示本人作品、一处有依据的修改和下一步；家长报告是否可见以发布状态为准。

技术用量、提示词版本等详情放在必要的成人支持或可展开详情中，孩子主界面保留足够判断真实性的信息，不铺满接口术语。

## 后续课程大厅的视觉

课程大厅属于AI学习内部，工作台仍是开始后和回访时的主要目的地。每张卡由作品封面、通俗课程名、一句话目标、准备条件、预计时间和状态组成；准确时长需试用校准。

封面优先展示课程真实支持的作品示例，统一裁切比例并提供替代文字。封面损坏时显示课程名和品牌占位，不阻断进入。孩子自己的作品缩略图只按本人权限展示，不作为公共课程素材。

首版只展示已发布内容；暂停、尚未开放、无权限和继续学习要有不同的文字与按钮。课堂尚少时不增加复杂分类、排行榜或商城。收费和家庭设置在家长侧处理。
