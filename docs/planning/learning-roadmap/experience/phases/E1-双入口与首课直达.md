# E1 双入口与首课直达

状态：工程完成：双入口、首作直达、同孩子恢复及跨家庭切换已验证。见[实施与验收](../handoffs/W00-实施与验收.md)。实施前估算：2–3有效人日。负责人：W00/W02，W06复验。

## 交付目标

用户明确选择AI学习或黑客松；学习访谈确认后，在准备条件成立时直接进入已有或新的首作课次。原比赛访谈继续服务比赛。

## 工作内容

1. 接入首页两张入口卡和一级导航，把原活动/实践保留在黑客松内部。
2. 持久化必要的学习目的地和本人选择，恢复时重新鉴权，保留作品和比赛深链接。
3. 将访谈确认后的学习主行动接到首作，已有课次优先继续；不强制先经过大厅或再答六主题问卷。
4. 对缺关系、同意或课程权益的情况给出具体准备入口，完成后回到原目标；不自动批准或赋权。
5. 按E0批准范围带入本人摘要，保留来源和修改，不复制无关原始私聊。
6. 演示和真实入口分别接线，沿用隔离数据库，保留原连接器绑定及旧比赛记录。

## 验收 GE1

- AI学习选择完成后，正确进入当前学习者的课次；重复点击和刷新不会重复开课次。
- 同一账号下不能把家长访谈误记成孩子经历；跨家庭、旧Bearer和演示身份不能换取学习权限。
- 旧第17题可以结束并继续，原回答未删除；已有起点不会被默认值覆盖。
- 显式比赛入口和旧书签仍走原流程；比赛门槛不能因“访谈完成”被批量跳过。
- 准备未完成时提示缺什么、找谁、完成后去哪；页面加载失败有恢复按钮。
- 多标签身份切换、未保存退出与暂停状态仍符合既有规则。

## 发布与回退

先在隔离合成环境演练并验证原比赛，再在获准环境显式开启。可关闭新入口并恢复旧导航，但保留已有学习记录的受权恢复；不得删除学习表或用旧权限薄弱版本接迁移后的数据库。交接给E2的是可用入口和真实API回执，不只是静态按钮。
