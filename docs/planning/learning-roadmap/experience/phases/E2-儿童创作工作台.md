# E2 儿童创作工作台

状态：工程完成：步骤/对话/预览、单松伴、版本及手机草稿保护已验证。见[实施与验收](../handoffs/W00-实施与验收.md)。实施前估算：3–5有效人日。负责人：W03前端、W04教学，W00统一接线。

## 交付目标

孩子在同一工作台中跟随松伴完成第一件作品：提出想法、生成候选、保存、自己改一处、检查和解释。桌面有对话与预览，手机可以无损切换。

## 工作内容

1. 将`RunPage`重排为三步目录、松伴对话与作品预览，保留现有任务及服务端进度计算。
2. 将必要输入拆成短任务或局部编辑，材料和帮助就近出现，避免一屏全部字段。
3. 默认按任务选择内部角色，收起儿童端的角色/模型配置；每次帮助保留真实来源与等级。
4. 生成动作由孩子发起，候选需明确保存；亲手修改产生新版本，旧版本可回看，新版本重新检查。
5. 连续对话与动作回执可恢复；切手机标签、导航或身份时，保留允许保留的草稿并隔离私有数据。
6. 将回读、自查、迁移、复盘和送审融入“改一改”，保持真实检查语义，不靠聊天回合数判完成。
7. 已有老师反馈和报告入口接在适当位置，儿童工作区不塞入财务或家长管理面板。

## 验收 GE2

- 孩子首屏能指出当前要做什么、作品在哪里及下一步控件；工程可读性检查和儿童观察分开记录。
- 第一次打开不自动调用模型，不自动保存候选、确认要求或提交老师。
- 查看示例、AI帮助、成人帮助和本人修改分别记录；封面/样例不成为作品事实。
- 保存、重开、历史版本、网络失败、unknown、预算不足及冲突均可恢复，迟到回复不覆盖新作品。
- 390/768/1440、200%缩放、键盘、减少动效和输入法布局通过；单一松伴入口仍能追溯实际角色。
- 真实后端页面走通邀请卡首课，检查和报告读取使用原记录，不替换为前端演示状态。

## 范围与回退

首版仅支持现有结构化文本和固定模板，不接终端、任意HTML/JS、自动插件安装或小游戏执行。新增课程形式另做范围评审。可切回旧学习呈现，但须保留新对话/动作记录的合法查询以及未知运行核对能力；不能只回退UI导致已保存结果不可恢复。
