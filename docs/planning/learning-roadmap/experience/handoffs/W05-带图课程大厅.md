# W05 带图课程大厅交接

日期：2026-11-02。范围：E4课程目录呈现、受控示例封面和独立浏览器验证。中央已告知E3真实后端UI首课13组闭环通过，依此进入本阶段；本报告只陈述W05新增范围的实际证据。

## 新增文件与接线

- `frontend/learning/CourseHallPage.tsx`：导出`CourseHallPage({api, learnerId, config, setGuard, navigate})`，接口与学习首页一致。
- `frontend/learning/course-covers.ts`：本地课程版本到作品示例的受控映射，记录替代文字、素材版本和来源。
- `frontend/learning/course-hall.css`：页面自行import，样式全部限定在`data-learning-root`下。
- `static/learning/covers/invitation-v1.svg`：原创邀请卡模板示例。
- `frontend/learning/tests/course-hall.cjs`：14组独立合成浏览器验证。
- 本交接文件。

W05没有修改共享index、运行时契约、配置、首课页或数据库。中央在`config.catalog_enabled`有效时把`#/learn/courses`接入本页，并从学习导航提供次级入口；首次学习依旧直达首作，不绕大厅。关闭开关时本页不读取目录或私人进度，保留回到作品的出口。

## 最终行为

页面并行读取现有`/courses`和本人`/learners/{id}/home`，目录分页沿用原工具。有run时另读该run并核对本人归属、run ID和课程版本后才给课程卡显示进度。公开目录与本人资格、作品状态分别处理，一个失败不伪装成另一个成功。

仅展示接口实际返回、状态为published且已有本地呈现映射的`invitation-course@0.1.0`。没有为了填满页面添加故事、网页或小游戏假课程。卡片有作品封面、原标题、一句目标、零基础提示、准备内容、三个步骤和真实状态；不虚构时长、年龄门槛或学习完成比例。

本页只读，不生成作品或写课次。符合当前课程条件时“开始这个作品”去`#/learn/first`，由现有首作流程确认与创建；已有run“继续创作”使用准确ID。课程完成只在当前run全部关卡passed时显示；有正式作品ID则“看看我的作品”定位该作品。其他课程的run不被借用为邀请卡进度，不擅自开新课。中央需将首课入口的默认候选限制为现有邀请卡；多课程选择契约后续另行接入。

没有权益时提供家长准备入口；目录为空、目录失败、本人状态未知、run归属不匹配、学习暂停分别有可读提示。课程目录暂停仍可从已受权home恢复上次作品，读取run失败时不猜测完成。重复快速点击仅导航一次，不产生POST。
