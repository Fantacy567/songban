# 服务端管理后台

日期：2026-11-02。范围：本轮创作工作台的服务端统一模型配置、管理员入口和配置审计。本文不是现有所有 AI 模块已完成热更新的声明。

## 入口与身份

入口为 `/server-admin`，放在账号辅助位置，不新增儿童侧一级导航。HTML 只包含登录门页和空容器；实际邮箱、模型配置及审计数据均在服务端鉴权后加载。

部署方在私密启动设置中指定 `allowed_emails`，默认空名单，普通账号没有权限。邮箱必须是已有账号表中已通过邮箱注册／绑定验证码流程写入的邮箱；请求体、页面输入、请求头声明的邮箱不授予权限。发件邮箱不自动拥有权限。

已有学习会话 cookie 优先。孩子模式拒绝管理页面的数据和全部管理操作，即使同时携带管理员 Bearer 也不能突破。演示服务拒绝管理员数据，访客身份拒绝管理。每次读取、保存及序列化前重新确认身份、邮箱白名单与浏览器状态；cookie 写入复用现有 CSRF 和同源校验，Bearer 写入须通过同源校验。未登录返回 401，已登录无权限返回 403。

允许在登录门页调用已有 QQ 邮件验证码发送及邮箱登录接口。此次验收只使用虚构身份，不发送真实邮件。未注册邮箱应先在平台完成注册／绑定。

## 管理内容

1. DeepSeek：服务启停、已开通模型名称、写入或移除 API 密钥、累计调用上限、单次最大输出（128～4096 tokens）、超时（10～120 秒）和并发上限（1～8 个作业）。每个创作小步骤最多 4 次模型请求，逐次预留累计额度。实际请求限额由宿主代理执行，并发上限由持久作业调度执行。
2. 豆包：可保存模型、密钥、计划额度等配置；本轮该配置尚未动态接入现有图片服务，界面注明“配置准备”，启用操作在后端拒绝，内部运行配置保持关闭。现有图片授权、预算发放和作业状态不受此配置覆盖。
3. 运行状态：显示创作服务是否注册，明确区分配置齐全、真实供应商验证、可运行沙箱。保存不是健康请求，不自动消耗模型额度。
4. 配置记录：最近 100 条操作，包含操作者、时间、配置类型、版本、变化字段名称。没有密钥正文、请求正文或提示词输入。

模型服务地址由服务端固定：DeepSeek `https://api.deepseek.com`，豆包 `https://ark.cn-beijing.volces.com/api/v3`。不开放任意代理地址输入，避免配置成为访问服务器内网的入口。图片生成不使用文本 tokens 字段；当前仅作为未来通用配置结构保留，不能解释成图片预算已生效。

## 配置和密钥保存

配置与审计存入既有 SQLite 的独立 `server_admin_*` 表。`SA01-config` 记录迁移校验和，改动后追加迁移，不覆盖旧校验和。保存使用 `expected_revision` 和稳定 `request_id`；同请求重复提交不会再生成版本，不同内容复用请求号返回 409。

密钥正文不进入 SQLite，也不返回 HTTP。仅写入源码、静态目录之外的私密目录，数据库保存随机不透明引用。POSIX 使用目录 0700／文件 0600；Windows 撤销目录继承并只授予当前服务账号访问。备份私密目录须沿用同等访问控制。密钥文件不可通过平台静态文件服务下载。

密钥轮换生成新私密文件再事务切换引用，失败不覆盖已生效密钥。历史或失败事务留下的私密文件不自动删除，避免误删仍被任务引用的凭据；后续运维清理需核对当前引用和作业状态。API 保存失败仅返回受控错误，不输出敏感输入或私密文件路径。

## 根会话接线

服务按 `learning → server_admin → platform → creative_studio` 顺序显式注册。纯旧版启动不配置后台，兼容原行为。

```python
from pathlib import Path
from app.server_admin import AdminSettings, register_server_admin

admin = register_server_admin(api, learning_service, AdminSettings(
    allowed_emails=tuple(private_config['allowed_emails']),
    secret_dir=Path(private_config['secret_dir']),
    enabled=private_config.get('enabled', True),
))
```

私密配置采用部署机上的绝对路径，真实邮箱不写入公共默认名单。已有主机的初始配置由主会话读取，文件不在 Git 工作区。

API 前缀 `/api/server-admin/v1` 由自身校验身份，主应用的旧流程边界仅在确实注册后将此前缀加入 `managed_prefixes`。不要为未注册的相似路径开放旁路。

内部方法 `admin.runtime_config('text', con=con)` 返回当前配置和密钥，**不可序列化到 HTTP 或日志**。如果调用方已经持有该数据库事务，必须传入 `con`，避免第二个写事务自锁。没有事务时可省略。

返回字段包括：`enabled, provider, base_url, model, api_key, max_calls, max_output_tokens, timeout_seconds, max_concurrency, revision`。没有密钥、未启用、零预算时 `enabled=False` 且 `api_key=''`。消费者在任务派发时读取，向沙箱外的受控宿主供应商代理提供密钥；不要把 key 放入儿童项目、沙箱环境或模型上下文。累计上限不能随着配置版本变化而重置账本。

## 教学依据

管理页明确要求教学内容有真实来源、学习目标、可观察练习、检查方式和人工审核。管理员保存模型参数不是教研审核，也不能把 AI 草稿标记为已验证知识。游戏表现、好看的作品、奖励数不能单独证明掌握。完整的内容准入规则由本阶段教学与宪法文档负责。

## 已验证与边界

- 17 项 Python 隔离接口测试：登录、普通账号拒绝、伪邮箱拒绝、孩子身份及移除孩子 cookie 后旧 Bearer 拒绝、访客和演示拒绝、撤权、同源／CSRF、配置保存、私密密钥不回显、CAS／幂等、预算为零、密钥移除、迁移校验和、共享事务和图片未接入拒绝。
- 8 项离线浏览器契约检查：授权加载、提交携带 CSRF、配置保存、密钥字段清空、审计、桌面排版、390px 无横向溢出、撤权后清空界面。浏览器使用受控 HTTP 响应，不冒充真实邮件或供应商联调。
- 代码检查：`node --check static/server-admin.js`。
- 真实 QQ 验证码、真实模型计费调用和服务器生产部署均未在该会话执行。完整主应用接线与真实沙箱验收由主会话汇总。
