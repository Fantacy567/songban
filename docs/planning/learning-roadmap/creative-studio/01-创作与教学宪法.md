# 创作与教学宪法增量

版本：3.0.0；依据：2026-11-02 用户确认真实编程工作台、DeepSeek Harness、服务端统一 API、指定管理员邮箱以及“科学真实的教学，游戏方式呈现”。与[平台宪法](../01-项目宪法.md)共同执行。

## S-C1 真实知识与游戏呈现

每个教学单元有可观察目标、必要前置知识、概念解释、来源、练习、常见误解和检验方式。知识性结论须能对应权威技术资料、研究或可复现实验；引用支持到哪一层，结论就限定在哪一层。角色、地图、关卡和积分不能改写事实。虚构故事和虚构比赛资料必须标明，不能用虚构机构、论文、认证或效果数字包装内容。

## S-C2 从想法到真实程序

孩子说明用途、使用者和一个最小行为；松伴可创建、解释和修改实际源文件。孩子能运行、试用、修改、恢复和保存同一项目的版本。界面必须区分真实执行、静态示例、未配置、运行失败与结果未知。工作台的文件、会话、版本与作品集归属由服务端决定。

## S-C3 AI 帮助与孩子贡献分别记录

允许 AI 生成和修复代码，围绕孩子的意图开展。孩子承担选择、预测、测试、解释和至少一处有目的的改动；需要支持时允许提示和示范，不以惩罚或无限问答阻断。记录 AI 代码改动、孩子手工改动、孩子文字解释、实际运行结果及人工复核。生成数量、聊天长度、通过语法检查或外观完善都不单独证明掌握。

## S-C4 帮助随表现调整

年龄用于措辞和阅读负担，结合实际表现调节帮助。默认一次一个小目标，展示示例、共同练习，再减少帮助；允许选择自己试。不能按“视觉型／听觉型”、左右脑、固定天赋或用户自选等级作未经证实的学习诊断。访谈仍遵守最多 8 问，已有结论复用且可修正。

## S-C5 服务端控制模型与执行

密钥、供应商地址、模型、预算、超时和调用开关在服务端控制。儿童浏览器、预览程序、项目源文件和 Harness 的不可信执行环境不得获得供应商密钥。服务端后台访问和配置 API 均需验证实际邮箱身份及管理员白名单；家庭管理、教研复核和服务端管理互不自动授予。

主 Web API 不执行生成的系统命令。Harness 以受限独立运行环境操作单个项目；模型请求经过受控代理。缺少受限运行环境时禁止 AI 执行并显示原因，不能退化为主机任意命令。预览采用无同源权限的沙盒，并限制外联。

## S-C6 可追溯、可恢复、不越权

记录来源版本、课程版本、项目版本、提示策略、实际模型标识、操作人和运行状态。写入幂等且校验版本，超时结果未知不自动再调用。查看历史、刷新或后台保存配置不隐式消费模型额度。切换孩子、退出、撤权和配置暂停后须收敛旧请求、缓存和后台作业权限。

## S-C7 教学复核独立于管理员配置

课程草稿、技术核验、教研复核、试点观察和正式发布分别记录。系统管理员可以配置技术服务，但不能仅凭后台角色把模型生成内容标为科学认证或自动发布给全部孩子。机器字段检查只证明材料齐全；技术自动检查只证明相应行为。正式课程和家长报告需要既有授权的人工复核流程。

## S-C8 小范围交付与兼容

首轮真实编程限定浏览器网页和小游戏，保留原课程、团队比赛、作品和连接器流程。只有一个演示入口。使用上游源码须固定版本、保留许可证与版权；全部用户数据不进入上游源码。首次真实模型执行、隔离部署、真实儿童观察分别验收，未完成项明确列出。
