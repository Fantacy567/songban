# 分期与分会话任务

以下按验收关口排期，不以预估天数代替完成证据。主会话维护总状态，三个实现会话共享工作区但各有文件责任。

## S0 宪法、教学与接口冻结

主会话完成本目录、平台宪法更新、教学来源登记和三关草稿。落实用户指定管理员地址、真实编程范围、工作台 UI 层级、接口与任务状态。验收是前后端对同一契约达成可实施定义，旧课程与新工作台区别清楚，教学草稿不冒充已复核课程。

## S1 管理员与统一服务配置

会话 `s02_admin` 负责 `app/server_admin/`、`static/server-admin*` 和对应测试。实现真实邮箱准入、权限复核、配置读取保存、密钥只写、审计和安全运行时配置接口。主会话负责中央注册与启动配置。验收包含未登录、普通用户、伪邮箱、孩子模式、撤权、CSRF、版本冲突和敏感信息泄漏。

## S2 Harness 与项目运行层

会话 `s01_harness_backend` 负责 `app/creative_studio/`、Harness 源码锁定与部署材料、对应测试。实现有归属的项目、代码版本、作业、模型代理、受限执行、恢复和归档。接 S1 的统一配置。验收包括跨孩子越权、路径逃逸、文件限制、预算、重复执行、结果未知和历史版本。环境未就绪必须可用性明确，不用模拟调用充当真实运行。

## S3 儿童工作台

会话 `s03_child_studio` 负责 `frontend/creative-studio/`、单独构建脚本与前端测试。实现想法入口、项目文件、主对话、运行预览、孩子编辑、历史恢复和存作品集；逐步提示与教学观察融入任务。主会话负责学习路由、访谈和大厅接线。依赖 S2 契约，可并行用明确测试替身开发。

## S4 主会话集成与回归

主会话负责 `app/main.py`、共享路由/类型、统一导航、已有课程兼容、构建和实际 HTTP 浏览器验收。至少走孩子创建到归档、管理员拒绝及允许、身份切换、恢复、错误路径。检查原比赛、邀请卡、家庭权限、图片和连接器已有回归，记录本次实际跑了哪些检查，不借用旧测试数字。

## S5 真实运行与教学试点

具备隔离运行环境、模型配置和明确预算后，再运行限定真实 Harness 模型试验。随后由实际教师/内容负责人复核课程并做真实学习观察，分别记录技术可用性、理解证据和报告质量。真实供应商、教育效果、公网发布、学校合作与收费验收不能用前四期工程结果替代。当前继续暂不开售。

## 合并与交接

中央文件由主会话串行修改；子会话不删除他人未提交改动，不推送远端或变更运行服务。交接包括文件、入口、验证命令、结果、需要的配置及明确未验事项。完成模块后主会话读实现与测试再接线，最终报告按“完成、条件具备后可运行、尚未验证”区分。
