## 与现有项目的关系

三个一级导航仍为 AI 教学大厅、黑客松教学大厅、作品集。创作工作台属于 AI 教学内的项目工作区；服务端管理在独立管理入口。保持原邀请卡课次、家庭身份、访谈、课程授权、连接器、比赛状态机和所有历史作品。新工作台不能把原结构化邀请卡预览标成任意编程环境，也不能因采用新工作台删除原课程。

首轮支持 HTML、CSS、JavaScript 浏览器项目，限制为本项目内文件。Python、任意 npm 安装、外网服务部署、访问孩子电脑、自动操作个人 Agent 均不属于本轮。新增课程不自动获得正式发布或学会判定。

管理员初始地址由用户指定，部署私密配置中保存，不作为所有安装实例的公共默认。管理员仍需完成邮箱身份认证；邮件发件账号、输入的邮箱字符串或孩子身份不授予后台权限。
