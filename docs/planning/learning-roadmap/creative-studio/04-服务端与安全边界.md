# 服务端与安全边界

## 复用与新增

继续使用 Python Web 服务、现有 SQLite 数据库及学习身份边界，不为了工作台重写成另一套全站框架。新增创作域负责项目、文件快照、版本、消息、执行作业与作品集引用；新增管理域负责经验证邮箱准入、技术配置、密钥管理和审计。

Harness 采用上游源码固定 revision。其插件、工具和 SDK 实现按锁定源码核验，适配层不能仅靠模型输出 JSON 冒充 Harness。官方介绍其插件化服务、模型、文件与运行环境分层；本项目的受限运行方式是松伴的部署设计。[官方架构](https://github.com/deepseek-ai/deepseek-harness/blob/master/docs/architecture.md)

## 模型与运行层

浏览器仅发送当前孩子授权的项目意图。后端核对身份、用途、资源版本、调用开关及预算后创建作业；受限独立环境运行 Harness，源文件与工具限定到该项目。模型请求由服务端受控代理提供，供应商密钥不传入模型上下文、浏览器或生成项目。

容器使用固定镜像、非特权用户、资源限制、无宿主敏感目录挂载；不允许生成代码操纵 Docker socket 或访问后台数据库。仅允许的网页文件从运行结果回收，重新做路径、大小、文件类型和版本核验。主 API 进程不执行任意生成命令。环境缺失显示不可用，不能自动降级为宿主执行。

预览为浏览器独立沙盒，不具平台同源权限，不传入访问令牌、管理凭据及隐私。网络、嵌套框架、表单、弹窗、顶层导航等按任务最小允许。项目归档为私密作品版本，不能凭作品中的任意链接授予别人的项目读取权。

## 管理员与配置

初始管理员名单在受控服务端配置中设置，由用户提供的邮箱完成现有真实邮箱认证后进入。访问页面与 API 均核对服务器账号记录及白名单；孩子模式优先，不能借同浏览器旧成人 Bearer 绕过。修改配置需当前身份、同源和 CSRF 校验；撤权对后续请求生效。前端隐藏菜单不承担鉴权职责。

配置包含文字服务、图片服务、模型标识、启用状态、上限和超时。密钥只写不回传，存储在服务端私密目录或受控密钥存储，示例文件不含真值。后台保存不能重置已有消耗或伪造连接成功。服务端消费者只读取已验证的配置，公共状态不包含密钥。

## 作业、版本与恢复

同一 request id 的相同写入返回原结果；不同内容复用拒绝。预期版本不符须重新读取，避免多标签覆盖。派发后超时或崩溃标为结果未知；读取和刷新不重派发。只有核对已有结果或明确重新发起的操作才能继续，预算不自动归零。

服务端记录实际模式、来源 revision、项目版本、孩子与 AI 的不同贡献及执行状态。模型响应和项目内容均作为不可信数据；不直接混入系统指令。配置停用、学习授权撤销、身份失效和工程暂停后，不得继续写入已撤销资源。

## 兼容与部署

所有新模块由 `create_app` 的显式设置启用。未启用时现有路由和数据库行为不变；新迁移追加而不修改已冻结 checksum。统一演示仍是8895，真实账号服务8894；临时测试端口完成后关闭。部署时先备份现有数据库，按显式 settings 打开模块，不把演示账号配置成服务端管理员。
