# 创作工作台 UI 与完整路径

## 孩子如何进入

AI 教学大厅提供“从一个想法开始”的工作台入口，已发布课程仍展示原课程卡和继续进度。首次访谈本人确认后可进入创作准备；现有课次优先恢复，新增编程入口不强制替换孩子已经开始的邀请卡。工作台路由为 `#/learn/create`，可通过项目 id 恢复；账户缺少有效学习身份或必要授权时沿用家庭准备，不重复访谈。

## 桌面工作区

左边为我的作品、项目文件与当前小目标；中间为松伴对话，显示实际执行状态和改动说明；右边为可操作的作品预览。顶部只保留作品名、保存状态、回到大厅。文件编辑放在明确可切换的区域，默认展示孩子当前需要理解的一小段，不以命令行、模型选择、密钥或多 Agent 管理占据首屏。

一个任务通常为：说出想法 → 确定一个可测试的小行为 → 松伴帮助创建 → 孩子预测与运行 → 描述看到的结果 → 修改一处 → 保存至作品集。每次只突出一个主操作，同时保留取消、恢复、查看已保存版本的出口。

## 儿童适配

使用“想做什么”“试着运行”“我看到了”“改一处试试”等短句。复杂操作给具体示例、逐层提示和可撤回版本。适配年龄但不幼稚化职业学校学生；不强制拟人化长对话和奖励动画。键盘可操作，错误有文字说明；减少动画设置生效。

手机切换“聊想法／看作品／文件”，每个区域保留状态，主要操作保持可达。嵌入工作台后不再出现第二个悬浮松伴聊天。未保存草稿离开前提示，切换身份立即清除前一孩子资料。

## 预览与证据

“运行”代表运行当前显示的代码版本，不能代表课程通过。预览不访问平台凭据、网络或其他作品；错误说明保留原稿。保存记录本人贡献及版本，作品集默认私密，封面不是运行证明。

示例中的闯关奖励是内容反馈。例如按钮确实触发事件、计数确实改变可以显示“这一步运行了”；能否解释和独立改进需要另外收集证据。没有真实运行结果时不显示“已通过测试”。

## 服务端管理界面

独立 `/server-admin`，从账号辅助入口访问；不加入儿童三级主导航。未登录先进入邮箱认证，认证后后端核对白名单。界面包含：服务概况、文字模型、图片模型、用量限制、运行状态、配置审计。密钥字段只允许替换或清除，已配置只显示状态；读取、日志、报错和浏览器存储均不回显密钥。

保存配置与测试模型为两件事。本轮后台不自动发送试探请求；状态分别显示“配置已保存”“运行环境可用”“真实调用尚未验收”。并发修改显示冲突并允许重新读取，不能静默覆盖。未安装隔离运行环境时给运维明确说明，对孩子保留已有项目查看和手动编辑能力。
