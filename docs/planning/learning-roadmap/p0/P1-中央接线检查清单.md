# P1 中央接线检查清单

日期：2026-11-02；状态：本清单对应的P1工程接线已验收，实际证据见[中央联调报告](../handoffs/S00-P1联调.md)。以下保留实施约束，不把清单本身当证明；真实家庭/生产发布仍单列门槛。

## 接口、构建和开关

读取P0修订后schema，不能消费过期PUT起点/自动人工送审语义。新v2的最终访问地址需结合OpenAPI servers与paths解析，不按裸paths误注册到根路径。模块独立注册，默认关闭真实学习入口。核心模式/旧journey middleware不能误阻拦v2，也不能为绕过阻拦关闭生产比赛顺序检查。

新增React模块同源静态构建、独立CSS作用域、可卸载mount；共享package/build/壳由S00串行接线。新导航保持关闭，独立开发页面明确范围。旧work/tasks动态加载映射和workbench生命周期都纳入回归。

## 中央身份与在途请求

仅v2拒绝高权限操作不足以关闭G1。列出core、studio/account、materials、workbench、recap、parent-report以及兼容模式下旧API所有认证入口；孩子cookie附带旧Bearer/sbconn_不能越过限制。旧login/register/访客签发也不能恢复高权限，只允许新学习显式重新认证流程。

旧请求入口认证和DB提交前认证需共享可验证的epoch/fence。实际测试安排两种顺序：旧写入先提交后切换，事实保留；切换先提交旧写入后到，后者拒绝且无副作用。不能仅用前端AbortController、只在请求开头查一次或时间sleep宣称覆盖并发。

已到网络的旧响应不能撤回；返回学习/管理身份时清缓存、停轮询、卸载旧模块，响应携带的旧epoch不能重新填回当前状态。cookie轮换端点严格限制，普通响应不刷新高权限cookie。旧凭证墓碑轮换不返回新Bearer，不写明文密码/凭证到幂等、日志和交接。

## 功能与拒绝路径

新家长声明不自动verified；有效scope/案件分配由服务端配置，不能开放自授审核/运营。未核验关系、缺同意、失效课程和不支持认证方式给出明确拒绝。P1未实现课程与模型时不伪造学习已完成。

起点每题保存可恢复；未答、跳过、明确选择/采纳、推荐依据分别存在。真实年龄选项待配置，选择低年龄不限制挑战；无小尝试时不编造评估通过。

## 验证与范围

独立模块用临时DB通过后，再对create_app默认关闭/显式启用两种配置做集成测试。所有测试隔离私密.env、用户DB、发信和真实模型。记录旧业务文件hash与明确接线差异；已有未提交修复不清场。

通过条件：G1所有身份隔离、旧凭据、在途写入、逐题恢复和旧入口回归有实际证据。仅UI fixture、合同结构或模块单测通过时，G1仍未通过；未开放真实家庭和新导航。正式部署按P4处理。
