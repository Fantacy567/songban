# 验收、证据与发布规则

版本：1.1.0；日期：2026-11-02。E0–E4新增体验验收见本版故事和[各期门槛](experience/README.md)；本次只交付文档，不将历史通过数计为新体验通过。

## 1. 分层证明

文档审阅证明范围与契约清楚；fixture证明协议/界面；真实模型测试证明指定供应商与当时输入可工作；儿童试用证明观察到的可用性；真实履约证明本轮服务交付。任意一层不能替代其他层，历史通过数不能当作新功能验收。

## 2. 必须通过的完整故事

V01：新家庭登录、建立关系与授权、切换孩子态、确认简短起点、无团队进入首课。已有本人确认的访谈摘要只补必要缺项，小尝试融入任务，不重复完整问卷；帮助可以调整。

V02：三关各有产出；模型生成只算候选，孩子作选择/修改；保存作品、检查、补练、解释与小迁移，后端决定过关。

V03：家长生成/查看权限、老师审核、报告发布/撤销；来源有效、没有队友或无关隐私，报告失败不丢学习结果。

V04：两家庭/两孩子/老师/运营互不越权；进入孩子态后旧标签与管理凭证无效；重新认证恢复管理，迟到响应不污染当前身份。

V05：刷新、进程重启、重复请求、正文冲突、并发编辑、内容升级、作品重查可恢复；模型unknown有案件与预算处理，不能自动重放。

V06：三个视口、200%缩放、键盘/焦点、减少动效、长中文/链接、手机输入法；任务主行动可见且无主体横向溢出。

V07：旧比赛从选题到复盘完整走通，原书签、私人工作台、明确共享、连接器、资料库及旧报告接口无回归；学习不改变队伍正式状态。

V08：报价、核款、订单权益、重复核验、到期/退款与历史访问一致；孩子不能购买或核款；仅人工登记不冒充渠道支付成功。

新增体验还须通过以下故事，不能仅验证入口能打开：

- V09：AI学习和黑客松各自进入、返回和恢复。明确比赛书签不被课程拦截；学习用户不被送去选比赛或建队。
- V10：首次访谈确认后直接创建或恢复一次合法课次；缺授权时保留目标，有权限后继续；重复点击不重复建课，旧17题访谈可结束且保留已答内容。
- V11：孩子通过一个松伴完成表达、生成候选、本人选择/修改、保存、检查和补练；内部角色记录可追溯。聊天成功不自动成为作品或过关。
- V12：桌面分区与手机页签均能完成同一任务；切换不丢输入，草稿/候选/已保存版本可辨认，检查始终对应正确作品版本。断线、unknown、预算不足、身份切换和冲突都有可用出口。
- V13（E4）：课程卡展示有权使用、与实际课程一致的示例封面；替代文字和缺图回退有效。卡片状态与授权一致，首作流程无需经过大厅。

上述工程测试通过后，仍须分别记录真实模型、真实儿童理解度和正式使用的未验范围。使用[首课验收与交付](experience/phases/E3-首课验收与交付.md)的工程/真实试用分层门槛，不把自动化结果写成儿童已经学会。

## 3. 检查方法与环境

以现有 Python unittest、React typecheck/build、Playwright或当期可用浏览器工具为基础，命令以仓库实际配置为准。所有业务测试使用隔离DB、合成身份和测试配置，不运行真实邮件/短信发送；真实模型单独用虚构材料、明确预算测一条必要链路。

旧全量测试历史有兼容环境要求 `SONGBAN_CORE_ONLY=0`、`SONGBAN_ENFORCE_JOURNEY=0`；严格流程用例另行显式开启，不能为了让全量变绿关闭生产门槛。测试启动不得读取私人.env发信或误写正在使用的DB。未知影响先隔离环境再运行。

记录命令、版本、时间、环境、模式、输入性质、通过/失败、截图、具体回执及未测事项。Browser/Playwright截图保存在 `E:\松伴\outputs\learning-<phase>-<date>\` 或任务指定证据目录，不提交含真实孩子数据的图/日志。文档链接验证和静态语法检查不等于业务测试。

## 4. 问题处理与发布门槛

阻塞：越权、凭据泄露、丢作品、伪造成功/过关、重复扣额、付款未到账赋权、发布未审核报告、旧比赛不能继续。修复并重测后才能真实试点。

高优先：任务无法理解、手机关键按钮不可达、孩子卡住无人接手、旧版本无法恢复、错误没有出口。需要修复或明确降低范围，不能用运营口头安抚替代长期解决。

其他：非关键留白/文案/装饰问题登记负责人和计划，不能因美术未完善隐瞒业务缺口。每条问题需复现、影响、证据、原因/责任范围、修复状态及验证。

## 5. 试点与生产准备

真实家庭进入前，监护关系/同意、教研内容、教师值班、模型预算、报告复核、数据保留和故障联系均有负责人。开始收款前另确认服务包与退款/权益规则。价格、服务时间和招生阈值不能由研发猜测。

部署目标、域名、配置、数据库、静态资源、内容/提示词版本和开关列入发布清单。回滚先有实际备份与隔离恢复演练；不能将localhost或临时隧道称永久上线。生产迁移与对外发布按具体授权执行，准备工作应先完成到可审阅。

## 6. 儿童可用性与付费复核

真实试用按已授权范围观察，不收集无关身份细节。记录孩子是否知道下一步、哪里要成人解释、是否照抄、能否发现问题与修改；用具体行为而非满意度推断教学。对比不同起点时保留样本、帮助和未观察范围。

付费复核同时看交付结果、真人成本、模型用量、退款和下一期实际行动；未观察的复购/学校签约不计为零或成功。G5/G7决策需产品负责人根据证据收口。
