# 课程与接口契约 1

这是 C01/C02/C03 的共同边界。2026-11-03 冻结；需要改变字段先在此登记并由主会话整合。

## 目录文件

`curriculum/ai-courses/catalog.json`，顶层 `{ "version":"1", "courses":[...] }`。

每门课程字段：

```json
{
  "id":"ai-tools", "version":"1", "title":"认识 AI 工具与 Vibe Coding",
  "chapter":{"id":"tools","title":"AI 工具篇","order":1}, "order":1,
  "status":"trial", "goal":"具体可观察目标", "preparation":"开始前准备", "duration":"约 20 分钟，可分次做",
  "cover":{"src":"/static/platform/illustrations/course-ai-tools.svg","alt":"场景描述"},
  "intro":"儿童能读懂的介绍", "steps":[
    {"id":"understand","title":"先认识","instruction":"真实解释","example":"起步示例","prompt":"孩子要回答或操作的任务"},
    {"id":"try","title":"动手试","instruction":"操作指引","example":"示例","prompt":"记录观察"},
    {"id":"reflect","title":"说说发现","instruction":"复盘与迁移","example":"示例","prompt":"解释或调整"}
  ],
  "activity":{"kind":"tool-sort","title":"互动练习","instruction":"具体说明"},
  "sources":[{"title":"原始资料名","url":"https://...","supports":"支撑哪项事实"}],
  "review":{"technical":"draft","education":"pending","pilot":"pending"}
}
```

课程 ID、活动 kind、封面文件名必须一一对应：

- `ai-tools` / `tool-sort` / `course-ai-tools.svg`：区分目标描述、AI 生成、运行检查、亲自修改。
- `imagination` / `idea-builder` / `course-imagination.svg`：为谁、什么困难、一个功能、如何检查。
- `first-project` / `project` / `course-first-project.svg`：进创作工作台做可运行网页，记录自己改的一处。
- `plugins` / `plugin-lab` / `course-plugins.svg`：在可控画布启停一个具体扩展，对比前后；标明课程内插件体验。
- `models` / `model-compare` / `course-models.svg`：按同一任务比较固定模型输出样例，指出错误与取舍；标明非实时模型。
- `api` / `api-lab` / `course-api.svg`：实际调用本站教学接口，看输入、响应及校验错误；不需要用户密钥。
- `model-powered-app` / `model-app` / `course-model-powered-app.svg`：为作品定义输入、模型职责、输出与失败回退；固定样例验证，真实模型接入未配置时说明。

前四门 chapter tools order1；后三门 chapter advanced（进阶篇）order2。课程 order 1–7。三个 step ID 固定，内容每门不同。

## 服务端 API

C02 新模块 `app/learning_courses/`，复用 platform identity/perform/register_domain；新增独立迁移，不改旧学习/创作数据表定义。注册函数 `register_courses(api, platform_service)`，主会话接入 app/main.py（C02 不编辑 main）。

公开读取（不包含个人数据，仍检查 host/origin 与平台启用配置）：

- GET `/api/platform/v1/learning-catalog` 返回目录完整对象。
- GET `/api/platform/v1/learning-catalog/{course_id}` 返回一门课程对象；不存在 404。

学习者私有接口（只从 session 确定 learner，不接受调用方指定 learner）：

- GET `/api/platform/v1/learning-courses/{course_id}/progress`
- POST 相同路径。请求 `{request_id,expected_revision,answers:{understand:string,try:string,reflect:string},activity:object,project_id:string|null}`。
- 返回 `{course_id,course_version,learner_id,revision,answers,activity,project_id,updated_at,status}`；首次无保存 revision0，answers空三字段，activity空对象，project_id null，status `not_started`；保存后 `saved`，不授予掌握/人工通过。
- `answers` 每字段最多2000字符；activity只接受当前kind的白名单字段、有限值，允许空对象。非空活动对象如下（不得带额外字段）：ai-tools `{sequence:string[]}`只允许describe/generate/run/check/improve、至多5项且唯一；imagination `{audience,problem,feature,check}`各≤500字符；first-project `{change,observation}`各≤1000字符；plugins `{enabled:boolean,before,after}`文本各≤1000字符；models `{choice,reason}` choice只允许sample-a/sample-b/undecided、reason≤1000字符；api `{name,message}`分别≤40/200字符；model-powered-app `{input,role,output,fallback}`各≤500字符。
- project_id仅 first-project允许，必须验证创作项目属于当前学习者；可为空。课程界面先可不强制绑定项目，不能因还没建作品丢失练习记录。
- 幂等重放同内容同响应、不同内容409；并发版本冲突409；私有读写走统一身份终检。

教学接口：POST `/api/platform/v1/learning-courses/api/experiment`，请求 `{request_id,operation:"greet",name:string}`，name去空白1–40字符。返回 `{kind:"teaching-api",request:{operation,name},response:{message},notice:"这是固定规则的教学接口，没有调用大模型。"}`。有效请求真实经过服务器，错误参数返回422；不存私密输入/不调用供应商。

## 前端与创作联动

新课程地址 `/learning-prep#/learn/course?id=<course_id>`。公共可阅读，保存前使用现有学习入口；演示“开始体验”后应回到原课程。旧 `/learn/first`、`/learn/run` 保留，已有课次置于“以前的练习”区域或恢复入口。

C03 负责目录卡片、课程详情与七类简洁可操作练习、route 白名单、host/login return验证。first-project 的主按钮跳转既有 `/learn/create`，清楚提示要做的小作品；课内练习记录保持。不要虚构已创建项目、模型反馈或插件安装成功。

所有课程记录使用真实API；匿名阅读不请求私有进度。身份切换和请求过期清理私有状态。保存失败保留同身份输入，离开未保存课程有确认，刷新恢复服务器已保存状态。
