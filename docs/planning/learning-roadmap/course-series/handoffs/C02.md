## 冻结接口的实际行为

公开 GET：

- `/api/platform/v1/learning-catalog` 返回完整 `{version,courses}`。
- `/api/platform/v1/learning-catalog/{course_id}` 返回单门完整课程；不存在 404。
- 无需登录，不建立身份 cookie，不返回个人数据，响应 `Cache-Control: no-store`。
- 执行 learning.transport；另检查 base_url 精确命中 allowed_origins，存在 Origin 时执行 learning.origin。HTTPS 错误 host、跨源 Origin、跨站请求均拒绝。
- 平台 enabled=false 返回 423/platform_paused；学习 enabled=false 返回 423/learning_paused；不泄露目录。旧 learning-v2 的 catalog_enabled/course_enabled 不作为新增七课的额外开关。
- 缺失或损坏目录返回 503/course_catalog_unavailable，不伪造空目录。校验七个独立 ID、篇章/顺序、固定活动 kind、各自封面路径、三个 step ID、资料 URL 和 draft/pending 审阅状态。允许 C01 增加来源/版权 metadata。

私有 GET/POST `/api/platform/v1/learning-courses/{course_id}/progress`：

- 只接受当前有效 learner session；匿名、manager、staff、participant bearer 均不能访问学习者记录。
- 身份来自 platform.identity，经 learning.role、learner、learning_access 检查，最终 platform.perform 再次身份终检。
- 所有请求字段严格；不接受 body 的 learner_id，也拒绝 GET/POST 查询参数（含 learner_id）。没有按外部传入 learner_id 选记录的分支。
- POST 必须包含 request_id、expected_revision、answers、activity、project_id；answers 恰好 understand/try/reflect 三字段，每字段 0–2000 字符，可部分或全部为空。
- 首读无记录：revision=0，三个空答案，activity={}，project_id=null，updated_at=null，status=not_started。
- 保存后：revision 增一，status=saved，course_version=当前目录版本。只有 not_started/saved，不产生掌握、通过、课程 entitlement、模型权限或旧课程完成状态。
- 数据主键是 `(learner_id,course_id)`，七课和不同学习者各自独立。每次 POST 是完整草稿替换，不是字段合并。
- 使用原平台 CSRF/origin、epoch、事务、版本并发、HMAC 幂等与最后身份检查。相同请求号/内容返回原快照（即使后来已有新版本），不同内容 409/idempotency_conflict，新请求号旧版本 409/revision_conflict。
- 学习暂停或平台暂停时禁止新写和重放写；有效当前身份仍能读取已存历史。授权撤回不属于暂停：撤回后历史也不可读。
- 已保存进度可在目录文件暂时缺失/损坏时读取；没有历史记录的首次空进度依赖有效目录版本，目录不可用时返回 503。

project_id：只允许 first-project 使用非 null 值。必须同时匹配 `creative_projects.owner = learner:<当前 learner_id>` 和 `creative_projects.learner_id = 当前 learner_id`。不存在、异人、两个归属字段不一致、创作域表未安装时都返回 404/course_project_not_found；其他课程传非 null 项目为 422。幂等重放前也重新检查绑定归属。null 始终允许，未创建作品不会妨碍保存其他练习记录。

## 活动白名单（与冻结补充一致）

activity={} 对七门都有效。非空时必须具有该课的完整字段，不接受额外字段、null 或类型强转；字符串允许为空。

- ai-tools：`sequence:string[]`；元素仅 describe/generate/run/check/improve，最多 5 项且唯一，允许空数组。
- imagination：`audience,problem,feature,check`，各 string、最多 500 字符。
- first-project：`change,observation`，各 string、最多 1000 字符。
- plugins：`enabled:boolean`、`before:string`、`after:string`；文本各最多 1000 字符，enabled 不接受 0/1 或字符串。
- models：`choice:string` 仅 sample-a/sample-b/undecided；`reason:string` 最多 1000 字符。
- api：`name:string` 最多 40 字符；`message:string` 最多 200 字符。这里是孩子主动保存的课程观察，不会触发实验或模型调用。
- model-powered-app：`input,role,output,fallback`，各 string、最多 500 字符。

只读检查 C03 的 CourseSeriesPage 已提供对应 defaults，并补齐非空 activity 的完整字段，与此校验兼容。

## 真实本地教学实验与隐私

POST `/api/platform/v1/learning-courses/api/experiment`：

请求 `{request_id,operation:"greet",name:string}`，name 去首尾空白后 1–40 字符。有效输入真实经过 HTTP 路由、共享身份检查、CSRF 和数据库幂等事务，固定规则响应为：

```json
{"kind":"teaching-api","request":{"operation":"greet","name":"小松"},"response":{"message":"你好，小松！"},"notice":"这是固定规则的教学接口，没有调用大模型。"}
```

无效字段、操作、空白名字、超长或错误类型返回 422；错误中不回显输入。不调用模型、不计供应商用量、不产生课程进度。

该路由使用 platform.perform，与 register_domain 保存进度共用身份、并发、幂等与终检。为避免存下实验输入，其 domain.write 仅返回 `{kind,notice}` 作为 platform_requests 的持久化结果；指纹沿用平台 HMAC。实际 request/response 由 response_factory 在最终身份检查之后、同一事务内，使用本次已校验 body 重建。重复请求不再次执行 domain.write；不同名字同请求号 409。数据库和审计不保存实验名字或问候文本。若孩子随后主动把观察保存进 api 课程的 activity，则按普通课程记录保存其 name/message。
