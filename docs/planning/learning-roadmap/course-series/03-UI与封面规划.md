# UI 与封面规划

一级导航维持左侧“AI 教学、黑客松、作品集”。AI 大厅内分两组带图课程：AI 工具篇四张、进阶篇三张。按2026-11-03用户最新反馈“卡片太大，一排至少4个”，桌面宽度≥1100px每排四列；进阶篇三张占前三列，不拉伸为三张大卡。平板两列、手机一列；不增加一级导航。黑客松大厅原两张主入口布局保持。

卡片内容顺序：独立场景插画 → 课程名 → 一句“学完能做什么” → 时长参考/试学 → 一个开始按钮。图片文字不承担全部信息，正文可读、键盘可操作、图片有 alt。课程可直接选择，不用锁图标制造强制前置条件。

七幅原创 SVG 封面延续米白、紫色、嫩绿，900×600、3:2；每幅主体不同：

1. 工具与 Vibe Coding：想法气泡连到电脑中的小网页与检查符号。
2. 想象：打开的画册里展开校园、星球、植物等，聚焦一个目标。
3. 小项目：真实感的网页画布、按钮与积木搭建桥梁。
4. 插件：基础小机器接入可拆卸功能模块，连接前后变化可见。
5. 大模型：同一任务纸分别进入不同形状的模型装置，输出供比较。
6. API：客户端与服务端之间请求/响应小包的桥梁。
7. 模型增强：孩子的小应用接入语言/图像能力，旁边保留检查与回退开关。

插画不使用真实儿童照片、不画真实供应商排名或未经验证产品界面。C01 提供来源 metadata 和可视预览，不为本轮封面调用真实生图供应商。

课程页保持“认识 → 动手试 → 说说发现”的三段提示，但七门内容和实际练习不同。当前步骤一个主动作，已保存状态靠近按钮。显示返回大厅和已保存课程记录；创作课程进入既有 Codex 样式工作台，不建第二套编辑器。

普通页面不再次显示家长账号密码认证。若缺学习身份，解释需登录/准备学习身份； demo 用现有一键体验。未配置模型时显示准确的配置状态，固定样例始终就近标注。
