# 课程宪法增量 C-20261103

本增量为项目宪法 3.1.0 的课程规则，覆盖旧“只建设一门首课”的目录范围，不改变已确认的首包售卖范围。尚不开售。

1. **七门独立课程。** AI 工具篇包含认识 AI 工具与 Vibe Coding、把想象变成小目标、做第一个小项目、认识与使用插件；进阶篇包含认识大模型、认识并调用 API、用不同模型增强作品。每门必须有独立 ID、封面、目标、课程地址、练习和进度。不得将七个入口全部导向同一首课。
2. **真实知识，游戏呈现。** 工具、模型、插件、API 是不同概念。Vibe Coding 必须包含运行、检查与修改；生成即正确、作品漂亮即掌握、软件有意识等表述禁止。技术事实引用一手资料，教学方法依据与平台自身效果验证分开。未完成教师审阅和儿童试点时标注试学，不伪造审阅签名。
3. **小步指导与可观察产出。** 每课说明要做什么、怎么试、留下什么、怎么检查。提供具体起步内容，允许修改。保存记录和完成练习不等于掌握；不能仅凭点击下一步生成能力评价。孩子自己的解释与操作记录分别保存。
4. **独立学习与可选延续。** 篇章顺序为推荐，不新增强制年龄分班、家长重新认证、组队或比赛门槛。普通平台登录及已有学习身份验证保留。可以把先前作品带入后续课，也可以独立尝试；不能串用其他孩子或其他课程记录。
5. **图片是教学插画。** 七幅插画主体与构图各不相同，服务课程理解，含替代文本与原创来源标记。不将静态插画称作孩子成果、真实项目截图或豆包生成结果；缺图提供文字回退。
6. **练习边界诚实。** API 教学可调用真实的本地教学接口，但明确其返回由固定规则产生。模型对比样例标注固定示例，不能冒充在线调用。真实模型、图片服务缺配置时如实显示。未经额外明确预算不新增外部付费调用。
7. **插件可控。** 本轮先体验工作台课程内的白名单功能扩展；不静默安装外部 Agent 插件或执行任意代码。不混淆网页体验与 Codex、WorkBuddy 的原生插件部署。外部工具插件教学另行确认。
8. **服务端保护。** API 密钥统一在服务端；课程输入限制长度与允许字段。学习记录沿用身份、CSRF、模式 epoch、版本并发与幂等保护。课程内容不得绕过统一身份或扩大模型权限。
9. **兼容与版权。** 不迁移删除旧课程、作品或比赛记录，不改已有数据库迁移校验。保留 AI 工作台 2292576833 署名及三方共同所有权。演示仍只有 8895，真实环境仍为 8894；只在验收后更新运行进程。
