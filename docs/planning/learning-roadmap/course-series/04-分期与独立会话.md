# 分期与独立会话

按依赖分工期，不承诺未验证的日历工时。

## C0 规则与契约冻结 — 主会话

写入宪法增量、七门目录、图片规划、接口与文件归属。保留在制改动；不提交、不推送、不新增外部调用费用。

## C1 内容与封面 — 独立会话 C01

仅负责 curriculum/ai-courses、七个 course-*.svg、内容校验脚本与测试、handoffs/C01.md。逐课事实查证引用一手资料，完成七个不同场景的完整插画。不得将技术自动校验写为教研审阅。

## C2 课程记录与实验 API — 独立会话 C02

仅负责 app/learning_courses、tests/test_learning_courses.py、handoffs/C02.md。目录校验与公开读取；学习者隔离、CSRF、epoch、并发幂等保存；真实本地 API 实验。不要修改 main、其他域的迁移或端口服务。

## C3 大厅与课程练习 — 独立会话 C03

负责课程前端、路由白名单、Hall 适配及前端测试、handoffs/C03.md。每课独立内容和课程内操作；接真实课程API。可编辑 frontend/learning、frontend/platform/halls、static/learning-host.js、static/songban.js 的路由允许列表；不得改旧比赛逻辑。暂不更新生成包，由主会话统一构建。

## C4 整合验收 — 主会话

接入注册、构建产物、真实 HTTP 浏览器验收七课进入/保存/刷新/不同课程隔离/创作往返/移动版/旧课与比赛导航。无供应商调用。安全快照后只重启8895演示，必要时同步8894真实入口，避免新增长期端口。

## C5 教研与真实模型验收 — 外部条件单列

需要真实教师审阅及儿童试学证据；真实模型增强练习需已配置可用运行环境、限额与新调用预算。没有这些条件不写“已验证教学效果”或“真实模型已接通”。本轮工程可交付独立试学课程、真实教学API、规则示例及原有创作基础能力。
