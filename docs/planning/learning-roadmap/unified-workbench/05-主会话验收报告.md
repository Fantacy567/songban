## 发现并修复的问题

1. **课程进入后仍是长表单。** 改为老师对话、固定输入区和成果区；旧活动显式折叠，保留原记录和工具。
2. **宿主与新工作台重复缩进。** 原宿主108px边距叠加新240px侧栏，导致桌面浪费空间。改为宿主不再加边距，由内层处理240/205px和手机底栏。
3. **手机消息区被挤到约35px。** 压缩头部和输入区，把长目标/模式说明收起、建议移入消息滚动区。新增390×844尺寸断言，可见消息区至少180px，控件至少44px；已检查实际HTTP截图。
4. **真实API课程返回坏JSON。** 该次请求保留失败和调用计数。DeepSeek精确适配端点增加结构化输出、关闭思考和短回复约束，检查finish_reason。已收到的截断/坏格式记failed，网络未知仍为unknown；没有自动重试。修复后API和软件赋能课程真实回复通过。
5. **两个文字模块各自计算预算。** 编程入队、预留调用、并发派发改用共享计数；补反向测试，已预留/未知请求仍占额度，不会各自花掉最后一次。
6. **未知课程任务没有管理出口。** 新增workbench-jobs管理接口与页面；关闭保留调用和证据，释放并发位，经过权限及事务回滚测试。
7. **Harness清理失败可能被忽略。** 容器清理非零退出/异常明确报失败；代理重定向拒绝，新增环境诊断与回归。不因没有容器而宣称真实运行成功。

测试脚本自身也修正了无障碍同名按钮定位、登录后额外历史课程数量、异步注销完成时点及学习身份不能直接冒充比赛身份等假设；未放松实际权限或删除保存/恢复断言来让测试通过。
