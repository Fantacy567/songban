## 实现行为

冻结契约全部 10 条 HTTP 路由已实现。七课程一身份一稳定私有会话；身份来自 platform.perform，支持当前学习身份及现有 manager/participant 个人空间。家长本人空间和孩子聊天完全隔离，本轮没有家长摘要读取接口。CSRF、同源、epoch、旧 bearer fence、有效学习/live_model 授权复用现有组件，未新增家长认证步骤。

消息保存 pending 任务后返回；worker 原子 claim running 再释放事务进行一次请求，写回会话 revision。GET 只读任务与本地回收过期租约，不发模型请求。重放 request_id 返回当前可见 SessionView，不能复活旧权限或重复派发。unknown 阻止本人新消息；编程域也按共享并发位等待人工核对。应用重启继续 pending、回收过期 running 为 unknown，成功/失败/unknown 都不重派发。每条 live 输出最多 800 tokens；收到完整 HTTP 成功响应但内容被截断、JSON 非法或结构不符合契约时标记 failed 并保留累计预算，网络结果未知和失效租约仍为 unknown。输出只允许 reply 与可选 title/content 文字候选，不运行输出。

demo_mode 显式允许 mock 并禁用 live；正式站 mock 禁用，未配置 live 返回可理解原因。mock 回复标记模拟，不声称实际模型；候选成果不自动保存。`runner(payload)` 可注入隔离测试，payload 含 teacher、input、mode、max_output_tokens、timeout_seconds，不含密钥或完整配置。返回 `{reply, artifact?, actual_model?, usage?, provider_request_id?}`，live 成功必须有 actual_model。

按主会话补充要求，mock 已替换空白表单为七课独立预制成果：三行角色卡、石头船想象片段、按钮说台词的代码文字候选、虚构资料分类插件方案、明确非真实模型对比的两句样例、greet 接口请求/响应样例、故事开头小助手方案。全部标明固定模拟，不声称语义推理、插件安装、代码执行或真实接口调用。工具课支持“请给会潜水的小狐狸写三行角色介绍卡”→“保留名字爱好，把本领改成给海星讲笑话”；最新历史候选维持原名字/爱好，若已有用户选中成果，则优先保留选中成果中本人编辑的值。文字字段有明确修改规则，其他要求提示用户直接编辑或使用在线老师，不假装理解任意要求。历史 live 授权撤回后，mock 上下文也不能复活不可见的旧回复/候选。

成果每次保存形成不可变版本；选择旧版本只改 selected_artifact_id。source_message_id 必须指向同会话 succeeded 消息；跨会话版本和来源拒绝。

记录使用 evidence 规则整理本人提问与当前文字成果，不推断兴趣/天赋、执行或掌握。无证据不能生成。草稿可由孩子改标题/摘要/下一步确认，确认前不进入 records 列表。一个会话一个稳定 record id；重生成草稿和再次确认都追加历史版本，records 始终取最近一次已确认版本，保留上次确认文字。

老师材料读取 U03 `curriculum/ai-courses/teachers.json`，七课程必须齐全，缺失或非法返回 teachers_unavailable，不造默认老师。公开只投影冻结 Teacher 字段；模型获得对应老师完整教学材料。已用 U03 实际文件验证兼容。
