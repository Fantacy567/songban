# U0 UI与接口契约

日期：2026-11-04；供U01/U02/U03共同实现。需要改共享字段时先在交接说明，再由主会话协调，避免各自定义。

## 页面

保留 `#/learn/course?id=<原七个course_id>`，进入即对话工作台。课程列表原四列、独立封面保留。`#/learn/first` 新用户主行动指向 ai-tools，旧邀请卡仍可从历史作品进入。侧栏有三个业务入口及最近会话。作品集在现有作品旁展示确认后的探索记录；点击可回到对应课程继续。

桌面采用侧栏、对话、可收起成果预览，输入框在工作区底部；窄屏可切换对话/成果。提示短而可展开，无连续必填问卷。模型模式与状态可识别，发送失败保留输入；源身份变化后丢弃迟到响应。所有写操作使用LearningApi.platform及request_id。

## 新增服务域

实现目录 `app/learning_workbench/`；公共导出 `register_workbench(api, platform_service, settings_provider=None, runner=None)` 返回域服务，状态挂在 `api.state.learning_workbench`。复用平台perform/身份/事务。注册和管理员配置provider由主会话写app/main.py。配置provider沿用admin.runtime_config('text', con=...)，没有真实配置时禁用live；明确demo允许mock。

统一前缀 `/api/platform/v1/learning-workbench`。私有写入所有权来自session，不接受客户端指定owner；幂等与expected_revision均在服务端检查。GET不产生付费调用。消息调用通过持久任务在事务外执行，有上限、unknown、故障恢复和结果记录，不盲目重试。

## HTTP契约

- GET `/teachers`：公共 `{version, teachers:[Teacher]}`；Teacher含course_id、name、opening、suggestions、goal、sources、tools，来源为U03manifest。
- GET `/sessions`：本人 `{items:[SessionSummary]}`，summary含id、course_id、title、revision、updated_at。
- POST `/sessions`：`{request_id, course_id}`，恢复本人此课程的会话，首次则建立；返回SessionView。
- GET `/sessions/{session_id}`：返回SessionView，兼作任务轮询和恢复。
- POST `/sessions/{session_id}/messages`：`{request_id, expected_revision, content, mode:'mock'|'live'}`；返回SessionView，异步消息可为pending。
- POST `/sessions/{session_id}/artifacts`：`{request_id, expected_revision, title, content, source_message_id:null|string}`；保存真实文本成果的不可变版本，返回SessionView。
- POST `/sessions/{session_id}/select-artifact`：`{request_id, expected_revision, version_id}`；选择已有版本，不删除其他版本，返回SessionView。
- POST `/sessions/{session_id}/record-draft`：`{request_id, expected_revision}`；根据已有消息/成果生成有来源的可编辑草稿，返回SessionView。基于规则的摘要必须标明method:'evidence'，不得假称模型评价。
- POST `/sessions/{session_id}/record-confirm`：`{request_id, expected_revision, title, summary, next_step}`；确认当前草稿，返回SessionView；后续生成不能直接覆盖确认稿。
- GET `/records`：本人 `{items:[Record]}`，只返回确认记录；家长读取若本轮实现，须另有明确学习者路径和摘要授权检查，不复用孩子的全量会话。

SessionView：`{id, course_id, title, revision, updated_at, teacher:Teacher, capabilities:{mock:boolean,live:boolean,reason:string|null}, messages:Message[], artifact_versions:ArtifactVersion[], selected_artifact_id:string|null, record:Record|null}`。

Message：`{id, user_text, assistant_text:string|null, mode, status:'pending'|'running'|'succeeded'|'failed'|'unknown', actual_model:string|null, artifact:{title,content}|null, created_at}`。Worker状态改变更新会话revision。用户可将模型返回的候选artifact手工修改保存；assistant文字本身不直接写作品。

ArtifactVersion：`{id, title, content, source_message_id:string|null, created_at}`；仅纯文本，前端按文本渲染。编程仍用现有CreativeStudio，禁止将模型输出直接注入HTML执行。

Record：`{id, session_id, course_id, title, summary, next_step, status:'draft'|'confirmed', method:'evidence'|'model', source_message_ids:string[], artifact_version_id:string|null, updated_at}`。可额外返回历史版本字段；修改需按版本保留证据。一个会话一个稳定记录id；确认前不进入公开作品清单；确认也不等于公开发布。

## 课程老师manifest

`curriculum/ai-courses/teachers.json` 格式 `{version:'1',teachers:[...]}`。每项包括上述Teacher字段以及后台专用 `system_prompt`、`help_strategy`、`artifact_instruction`、`knowledge_points`、`misconceptions`、`review`。公开投影不暴露system_prompt。七个course_id沿用ai-tools、imagination、first-project、plugins、models、api、model-powered-app。

teacher.tools使用语义动作：`text-artifact`、`creative-studio`、`plugin-lab`、`model-compare`、`api-lab`、`model-app`。工具动作复用已授权模块，不由模型输出任意URL或调用任意代码。课程详情旧练习可作为“动手试/参考材料”折叠面板，主界面必须是老师对话。
