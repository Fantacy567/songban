# 首个服务包与待定规则

版本：`offer-design 0.2.0-draft`，2026-11-02。用户已确认首包服务范围用于准备，并明确“暂不开售”；正式报价、人员及其余政策仍待定。确认边界见[服务范围确认与接续](07-服务范围确认与接续.md)。不包含法律条款或市场定价结论。

## 先交付什么

建议首包叫“做出第一张活动邀请卡”：一个主题、三关、一个学习者、一个可保存并修改的作品、一次换材料尝试、作品人工反馈及一份审核后家长报告。孩子学习如何提出要求、操作工具、判断与改进；不承诺学会所有AI工具，也不承诺比赛获奖或能力认证。

三关本身已有实现。四角色帮助使用受控工作流；正式模型是否开放及额度必须另有配置和家长用途同意，不能把购买课程等同于同意上传到模型。先使用现有账号，不增加儿童付款入口。

## 已确认用于准备的服务范围

用户确认：一个主题三关、两次每次约30分钟练习、两次每次至多10分钟人工答疑、一份经过审核的家长报告、服务期7天、送审后3个工作日反馈。按此范围继续准备，不再作为未确认建议。实际开课日期、服务期起算方式、工作日历、服务时段、负责人员及替补仍未确定；补练后额外复核范围也尚未确认，因此不开放报名或对外承诺可立即交付。

首批建议不超过5个家庭，实际名额取“教研可观察人数、支持可交付人数、模型预算可承受人数”的最小值，不将5写成系统默认容量。没有指定支持人员则容量为未配置，不能开售。样本量只是运营上限建议，不是市场验证样本标准。

正式价格、币种、付款渠道与收款主体均未定。原型中的¥99为虚构状态展示金额，**不是建议售价、已定报价或实际收款金额**。不按模型内部unit直接换算零售价；报价至少考虑人工、供应商、基础设施、渠道成本和退款风险，缺账单时保留未知。

## 到期、退款与历史资料

建议将“能继续练习”和“能看已有成果”分开。服务到期后暂停新增生成/编辑，保留已保存作品及已发布报告的受权只读；可见性仍受监护关系、用途同意、资料保留期限约束。历史保留天数、删除/导出范围待确认，不能承诺永久保存。

退款由真实收款渠道按已确认规则办理。后台只登记已核实的渠道结果；点击申请、上传截图或工作人员点按钮均不等于实际退款。结果不明时为待核对，不自动重复退款；只撤回对应订单未履行权益，不删除作品、审计或仍需核对的模型费用。

建议退款规则单独覆盖：开课前取消、已部分交付、平台无法交付、已发布报告、退款在途未知。具体可退金额/比例、办理期限和部分退款是否支持尚未定。P5-B可先只支持全额退款的真实结果登记，部分退款明确转人工处理，不用自由文本改账绕过状态。

## offer_version必须冻结的字段

课程和内容版本、金额最小货币单位/币种、服务开始/结束规则、场次与名额、答疑次数/分钟/时段、作品与报告处理期限、补练范围、真实模型预算配置、退款规则版本、历史访问/保留规则、负责人员/替补、支持联系出口。家长确认的文本与订单快照绑定同一版本。

修改报价只产生新版本；已有订单继续引用当时版本。订单请求只传offer_version和本人学习者等标识，由服务端取金额，不接受客户端随意金额。未定字段不能以0或空文案作为可售默认值。

## 用户需收口的内容

已确认的服务结构不再重复询问。接续填写价格、可交付日期和真实支持人员；若尚未具备人员，保持准备和内部试讲，不设置倒计时或收款入口。正式发布前还需收口退款/保留规则和真实试点条件。

确认范围单独保存于[service-scope.confirmed.json](service-scope.confirmed.json)，由[offer.draft.json](offer.draft.json)引用。报价仍为`approval_status=draft`、`sales_enabled=false`，实际价格/容量/人员/政策均为null。`proposal`只保留未确认的首批人数建议，不混入已确认的服务量。
