# 首批交付与观察口径

更新：2026-11-02。没有真实招生或履约数据，本文件定义将来如何记录；阈值尚未批准，不填转化率和营收预测。

## 责任与排期

开售前指定关系核验、排课/支持、作品复核、报告复核/发布、到账核验、退款核对、模型用量核对和故障值班人员。可一人兼任获准岗位，但每个动作按权限留痕；代录写明操作人与事实来源。工作量按真人可服务时段确定，不用AI生成回复数冒充教师工时。

每名家庭的记录依次包括：有效关系/用途授权、服务版本、订单状态、实际核款证据引用、权益、约定体验时段、实际到课、学习过程/帮助、卡点、教师处理、报告发布/阅读、家长反馈、下一期意向及实际订单。日期区分约定与发生，不从登录直接推断到课。

## 最小指标

- 报名：已创建的有效订单数，重复请求只算一次；关闭订单单列。家庭数与订单数分别报告。
- 到款：经受控渠道证据核验的订单及金额，分币种；付款声明、截图、意向不计入。退款按实际核实结果另列，未知不算0。
- 到课：工作人员有依据登记的实际体验记录；登录/打开页面只算访问。记录取消、未到和无法确认。
- 完成：服务端学习run当前人工结论为通过，保留内容/规则版本；生成候选或支付成功不计完成。
- 报告：已发布、已撤回、待审核分别统计。打开报告只算已打开，不声称家长已理解；当前代码尚未提供可审计阅读事件，P5-B需补。
- 下一期：口头意向、报名、已核实付款分开，只有最后一项能计下一期付费。没有后续观察时写未观察。
- 人工：按支持/作品复核/报告复核/核款等岗位记录开始结束或实际分钟、对应家庭与事项；未知工时不填0，不能用案件创建到完成的时差当投入时间。
- 成本：供应商已核实账单、人工实际分钟×约定成本、已发生基础设施/渠道成本分别列来源；模型unit不直接等于人民币。未核实标未知，不能因此计算看似精确的利润。
- 退款与卡点：申请、待办理、结果未知、已核实退款及原因分开；卡点按看不懂任务、找不到操作、教学帮助、服务故障归类，保留脱敏事实。

计算比率必须同时显示分子、分母、观察截止时间、窗口和排除条件。例如报告打开率只在本观察窗口已发布且仍可见的本人报告中计算；分母为0显示“不适用”，没有数据来源显示“未测”。退款撤回后的历史事件不能被删除来美化完成率。

## 观察与决策

建议先做少量获准试讲，确认孩子能独立找到下一步、保存作品并解释修改；记录实际成人帮助，不给虚构样本打分。然后在服务人员和规则具备后，开展获准首批收费履约。

在招生前由产品负责人填写继续/缩小/暂停的决策标准，至少覆盖是否按承诺交付、主要卡点能否处理、人工负担、真实成本和下一期真实行动。当前没有可用阈值，不以“多少家庭满意”自行判G5通过。

暂停新招生后保留已有订单、支持、退款与历史出口。不可通过下线页面逃避未完成服务；未配置真实联系人时不对外招募。发生越权、丢记录、未核实到账赋权或重复退款迹象时停止相关新交易并核对，仍保留已有证据。

## P5交付后的检查顺序

先隔离验证订单幂等、权限、容量、金额、证据唯一、账权原子性、退款unknown、旧授权/预算兼容及历史读取；再验证完整家长/工作人员页面和备份恢复。真实支付仅在具体收款主体、渠道和任务明确后单独进行，不能把原型或mock回执当到账验收。
