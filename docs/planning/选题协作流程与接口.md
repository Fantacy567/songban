# 选题协作流程与接口

日期：2026-10-31。依据本轮用户要求及已确认的投票规则。

## 已确认行为

组队后先在“方向”开启一轮限时选题讨论。每位成员连接自己的 Agent，在明确选用松伴连接器的对话中共享本人输入和 AI 可见回复。团队页面按成员、候选题目展示已收到的回合。

队长口头核对后，每人自行点击“已上传完毕，确认进入排名”。进度显示已确认人数 / 当前成员总人数，队长和插件都不能代确认。最后一位成员确认后，系统对本轮材料生成一次排名；失败或结果未知必须显示真实状态，不自动重复调用。

排名综合团队能力、赛道符合性、特殊优势、评分维度及时间可行性。每项提供依据、优势、风险和待验证事项；AI 排名是建议，不能直接决定方向。

每人一票，全员投完，由队长确认唯一最高票方向。平票只针对并列最高项重新投票，全员重新投一轮。确认后沿用原方向和任务事实，队长生成并发布任务，成员自行领取。

## 状态和一致性

- discussion：收集回合和本人确认；截止后拒绝新回合，队长可延长。新回合撤回该作者的完成确认。
- ranking：已冻结成员和材料版本；一次模型请求，重复点击不再生成。
- failed / unknown：保存原因，队长明确重试或重新开放讨论。超时或失联不冒充完成。
- voting：排名可追溯，每人每轮一票；平票开启新轮并保留之前票据。
- awaiting_selection：全员投完，等待队长确认唯一最高票方向。
- selected：主方向写入原 core_settings；之后才允许生成、发布和领取任务。

排名开始后成员名单或共享能力资料变化，旧结果不能继续确认；队长重新开放讨论，由当前全员确认。退出、账号切换或迟到响应不能显示其他范围的内容。

老团队没有选题轮时保留原接口兼容；新方向页面引导进入本流程。有已发布任务的团队不会静默清空任务重开选题。

## 接入边界

复用 Codex 原生安装器及 Codex、Cursor、WorkBuddy 项目 MCP 安装器。界面分开说明注册、客户端加载和真实回合入库；只有收到服务端记录号才确认上传。远程网页不能直接改访问者电脑，安装失败或客户端未验收不能显示完成。

选择连接器仅授权当前回合或本人明确授权的当前对话，不扩大为所有私聊，不读取隐藏思考。完整可见回复作为新字段保存，旧摘要不伪装成全文。超限明确拒绝、保留原文，不静默丢弃；发送到模型的上下文若缩短须记录覆盖范围。安装不修改用户模型配置。

参考：[OpenAI 插件](https://developers.openai.com/plugins/build/plugins)、[Cursor 插件](https://cursor.com/docs/plugins)、[Cursor MCP](https://cursor.com/docs/mcp)、[WorkBuddy 连接器](https://open.workbuddy.cn/docs/connector)。不同客户端的原生插件入口需分别实测，不能统一承诺加号内可见。

## 实施与验收

1. 增加持久化选题轮、共享回合、确认、排名请求、票据和领取记录；管理动作限网页登录本人。
2. 连接器增加本轮共享工具；方向页完成安装引导、回合查看、确认进度、排名和投票。
3. 保留原任务发布、报告、同伴检查和导出，领取人作为任务负责人。
4. 隔离数据库验证多人、重复请求、版本冲突、越权、名单变化、超时恢复、平票、队长确认及领取争抢；桌面和手机跑完整链路。

现有未提交的兴趣引导、访客入口、演示与任务进度改动保留，不重置或覆盖。测试不发送真实短信、不调用付费模型、不写正常用户数据。

## 已实现接口

前缀 `/api/core/teams/{sid}/topic-selection`：GET 读取本轮；POST `/rounds` 开启；POST `/turns` 上传；POST `/ready` 本人确认或撤回；POST `/reopen` 队长重开并重置确认；POST `/retry` 明确重试排名；POST `/votes` 本人投票；POST `/select` 队长确认最高票方向。任务领取复用 `/api/core/teams/{sid}/tasks/{task_key}/claim`。

上传使用 `selected`、`round_id`、稳定 `event_id`、`topic_title`、`user_message`、`assistant_message`，模型名与会话标签可选。管理操作带稳定 `request_id` 和 `expected_revision`；投票还带 `ballot`。服务端验证本人、团队、连接有效期、当前轮次与版本。初次开启和任务领取使用核心资料版本，其他选题操作使用选题轮版本。

一轮最多 24 个候选、200 个共享回合；单回合用户原话最多 16000 字符、AI 可见回复最多 50000 字符。超限返回错误，不伪装保存。完整回合留存，排名和任务模型仅接收有覆盖说明的有限摘录。

交付与未实测范围见[验收报告](../reviews/选题协作与页面清理验收-2026-10-31.md)。
