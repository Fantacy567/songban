# 05演示脚本｜从会问AI，到能做出作品
最终时长与赛制以主办方最新通知为准。

## 3分钟版（含40秒真实demo）
0:00—0:25：“孩子会问AI作业，却不知道能不能用它做一个自己的游戏。家长想让他低成本接触AI创造，也想看见他真正喜欢、擅长和做成了什么。”这是情境叙述，不冒充调研统计。
0:25—0:50：“松伴用黑客松把学习放进真实实践。从兴趣出发，找到适合的比赛和队友，再把命题、评分和时间约束变成能照着做的小任务。”
0:50—1:30：40秒实机演示。
1:30—1:55：“难点不是写出一张待办，而是让初学者真的做得下去。每一步都有操作、产物和验收；卡住就继续拆小，团队能看见进度。”
1:55—2:20：“指导是主线，协作是基础。个人工具的重要进展回到团队，队长确认安排，队友验收成果，避免AI各说各话。”
2:20—2:45：“拟十几元/月，让普通家庭以较低门槛尝试AI创造实践。我们希望通过赛中指导、作品迭代和赛后记忆提供持续价值；付费与长期留存仍要验证。”
2:45—3:00：“每场比赛不只留下一份作品，也留下下次能用上的经验。松伴，陪你把想法做出来。”

## 5分钟版
教育情境与证据40秒；方案35秒；demo40秒；任务拆解与研发50秒；团队协作35秒；商业成本与验证35秒；赛后记忆/迭代25秒；团队与结尾20秒。合计280秒，余20秒缓冲。
技术最多一页：目标和约束→结构化拆解→依赖/完整性检查→成员实际执行→验收与反馈→调整。不得把规则校验说成科学最优分工。

## 40秒demo（以实际完成能力调整）
0—8秒：输入一个具体想法并展示已核实赛事约束（若手工准备就说手工）。
8—18秒：生成少量任务，打开一项，看到具体步骤、可复制AI指令和验收方法。
18—28秒：在团队板看到两名成员分工与进度；展示授权同步的真实新记录。
28—35秒：提交小成果，由另一人验收或退回，状态变化。
35—40秒：显示复盘草稿/下一步；若未开发，明确转到规划图，不伪造现场成功。
本场若只跑通协作底座，应明确说“已完成底座，指导闭环正在验证”，不得把规划串成假实机。

## 数据页的要求
可用数据必须给来源、日期、样本、问题口径。AI用户数不等于AI创造者少；培训报价不等于成交量或不合理；竞品存在不等于教育有效。缺失数据保留待补，不自动填百分比。

## 失败备用
真实录屏注明版本；剪等待不伪造推理；模型不可用可展示人工确认路径并说明限制；无官方提交回执不能宣称已提交成功。

品牌愿景统一落版：让每个家庭走进AI原生时代。支持句：让AI不只回答问题，也帮助每个孩子把想法变成作品。
