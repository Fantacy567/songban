# 06宣传片脚本与素材清单｜一次想法的旅程
定位：讲清低成本AI实践与指导价值，协作作为支撑，不剪成纯团队工具广告。

|时段|画面|短文案|素材标识|
|---|---|---|---|
|0—5秒|孩子在纸上画一个想做的游戏/工具|有个想法，然后呢？|情境镜头，不冒充试用证据|
|5—11秒|指导对话澄清兴趣与目标，出现合适比赛卡|找到适合你的起点。|真实已实现界面；未实现用规划示意|
|11—18秒|大目标展开成少量清晰步骤，打开一项|把大想法，变成下一小步。|重点展示操作、AI指令、产物和验收|
|18—25秒|两位成员看同一任务板，进度回传|各自推进，一起看见。|真实团队板、授权同步|
|25—31秒|交付小作品、同伴验收、复盘|做出来，也看见成长。|真实成果，复盘规划标明|
|31—36秒|品牌Logo与下一场入口|松伴，陪你把想法做出来。|Logo与简短落版|

不要让生成模型重绘中文实机界面，录屏和字幕后期叠加。每个镜头一个主动作，关键信息停留。规划部分明确标注，避免镜头暗示未完成能力已可用。

素材清单：Logo源文件；兴趣情境；核实过的赛事卡；指导与任务拆解；任务详情；团队进度；连接与停止；交付验收；复盘草稿；备用错误路径。
每项记录来源、版本、授权、隐私检查和是否实机。音乐需授权。家长/孩子出镜需相应同意，不录入私人通知与凭据。
交付MP4、无音乐版、字幕、剪辑工程、素材表。

品牌愿景统一落版：让每个家庭走进AI原生时代。支持句：让AI不只回答问题，也帮助每个孩子把想法变成作品。
