# 00项目导航｜松伴：从一个想法，到一次真实创造
## 终极愿景
让每个家庭走进AI原生时代。让AI不只回答问题，也帮助每个孩子把想法变成作品。

## 一句话定位
松伴是面向AI创造新人的低成本黑客松实践指导平台：帮助孩子从兴趣或社会问题出发，用AI完成作品与参赛；以团队协作为基础，贯穿比赛指导、任务执行、赛后复盘和下一次成长。

## 产品的两部分
**黑客松指导是主线**：找适合的比赛与队友、理解命题和评分、澄清想法、拆解任务、逐步完成与提交、赛后总结。
**团队协同是基础**：个人工具重要进展回到团队空间，任务分工与进度全员可见，智能体根据真实进展继续指导，重要安排由人确认。

## 完整闭环
兴趣/想解决的问题→引导探索→匹配比赛与队友→理解赛规→把想法拆成能照做的小任务→团队执行和验收→完成作品与参赛提交→复盘与经确认的成长记忆→下一次更合适的指导。

## 商业与持续使用
家长是主要拟付费方，孩子是核心使用者，拟十几元/月订阅（具体价格和额度待定）。购买理由是低成本AI创造实践与可见成果；持续使用理由是赛中指导协作、作品继续推进、赛后总结与跨赛事记忆。它们是产品机制与商业假设，尚不等于已证明续费。
机构合作不再作为本版主叙事；不沿用800—1500元/人或四周机构交付作为核心定价。
